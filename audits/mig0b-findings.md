**Adversarial checks.** These are mathematical source checks, not newly executed Lean tests.

1. **Zero segments versus first exits.** `Segment.zero` permits duration zero even when the starting state belongs to the forbidden set: its strict cut has no queried time. `SafeSegment.zero` additionally excludes that membership. For an admissible first-exit contract,
   \[
   C.time\,i\,c=0
   \iff \mathrm{some}(entry)\in exits.
   \]
   Forward: the endpoint is the start, so apply `exit_mem`. Reverse: a positive time would let `cut` at zero contradict membership. The layers therefore have deliberately different zero-time behavior.

2. **Stationary positive segments.** Choose distinct live states `q` and `a`, start the supplied idle machine at `q`, and take duration two. Every queried state is `some q`, so the run is a `SafeSegment` avoiding `some a`. A first-exit contract with exit `some a` cannot admit this start: its endpoint would have to be both states. A duration-two round anchored at `q` fails its cut at time one. The new layers remove the prior gate's obstruction rather than hiding it in a bridge.

3. **Live interior and a halting escape.** Start at `a` and halt after one step, with escape set `{none}`. A duration-one round is valid. A duration-two run has the same allowed endpoint but has interior state `none` at time one, which belongs to `roundStop`; it is rejected. Without liveness, this padded duration could pass. Release of the valid round still halts, establishing finding 4.

4. **Empty counter and zero body tapes.**
   \[
   counterValue\,[]=0,\qquad
   counterOverhead\,[]\,1=2\cdot0+2=2.
   \]
   Body-round premises and duration sum are empty, yet the done contract runs its two-step underflow. The body hull is the initial vector and the shared witness can be `r = 0`, `u = 0`. With zero body tapes the body equality is vacuous, but the counter tape and interval remain. An escape contract correctly cannot satisfy `r₀ < 0`.

5. **Joint witness.** Vectors `(0,0)` and `(1,1)` satisfy coordinate equality. Their coordinate hull admits `(0,1)`, which does not. The counter-loop conclusions put one existential round/offset before the universal tape quantifier, retaining the original correlation.

6. **Transport qualifications.** For the identity simulation of a one-step source run `a → e`, choose target entry `b ≠ a`: the target entry and precondition contradict each other, as in finding 3. Zero cost is separately consistent: a constant encoding into a target exit makes off-exit zero-step simulation equations true and interior cuts empty. A positive source contract can then transport to a valid zero-time target contract. `Lockstep` does not implicitly preserve positivity.

7. **No blank writes.** Put a rich symbol outside the bit embedding on a cell; its Boolean shadow is blank. If the source explicitly writes blank, the lifted action erases the rich cell, while the endpoint overlay sees an unchanged blank shadow and restores the foreign symbol. These disagree. Removing the no-blank-write premise from this overlay transport would therefore be wrong.

**The admitted theorem, literally stated.** Choose the attached block encoder and private `arTM`, with cycle length \(3(|\Gamma|+1)+2\), and take `arCfg` and the injective ready-state constructor as witnesses. `arCfg_cycle` supplies the step equation, and `arCfg.state` supplies exit preservation for every exit set. From a live source, strictly intermediate cycle controls are live read/write/move controls outside the ready-state image; offset zero uses injectivity and source nonmembership. If the source is already halted and lies outside the exit set, `none` lies outside that set and its mapped image, and both configurations remain halted. This gives a concrete proof route, including zero work tapes, but the intermediate-control lemma has **not** been formally discharged by this audit.
