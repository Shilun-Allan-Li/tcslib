# MIG-1 statement gate: named witnesses, their spec theorems, the rows as corollaries

**Status: the statement-gate unit of backlog row MIG-1; not a library file.** It elaborates
against the campaign snapshot, in which today's rows are public and today's witnesses private.
The unit has eight parts, one per home file, each opened by a section comment beginning `════`
and by `-- @landing` and `-- @imports` lines. Landing is a set of edits to the existing home
modules, not a new module:

* **Witness definitions.** A witness that is today a private definition of its home file
  (`idTM`, `constTM`, `ifEqTM`, `condTM`, `timedCondTM`, `Turing.pairDiagTM`, `lengthBitsTM`,
  `prependTM`, `incFixedTM`, `pairValidTM`, `pairExtractTM`, `unaryTokenTM`, `appendBitTM`,
  `loopHostTM`, `callTM`) lands by an asserted scripted rename **in place**: the `private`
  keyword goes, the name changes by the rename map of the pack, the body is unchanged, and the
  docstring becomes the one given here. Every other witness (`toCodeTM`, `polyUnaryTM`,
  `polyBitsTM`, `pairLenCheckTM`, `stripLastTM`, `pairMapSndTM`, `splitSolveTM`,
  `splitSolveWithTM`, `emitLoopTM`, `callEntry`, `callExit`) is a new definition whose body is
  today's witness term, from the row proof named in its docstring. `pairMapSndTM` alone lands
  at the fill stage, with the forwarding-controller family that moves from Catalog. The bodies
  here are the source bodies verbatim modulo the rename map
  (`audits/logs/mig1-statements-identity.log`).
* **Gate shims** (blocks between `-- @shim begin` and `-- @shim end`) are verbatim copies of
  private definitions that a witness body uses. They exist only because a private declaration
  cannot be named from another module; on landing they are dropped, since the originals are
  already in the home file (or, for the forwarding controller, move there with their family).
  They are checked verbatim by the same script.
* **Spec theorems and supporting lemmas** are new public statements, inserted in the home file
  before the first row they serve. A spec whose proof needs a private lemma of its home file is
  `sorry` here, under a proof sketch that names the existing proof it comes from; a spec whose
  proof needs only public declarations is proved here, and lands with that proof.
* **Row corollaries** `MIG1Gate.row_X` are stated as `type_of% @X`, the landed row's own type,
  so this unit elaborates only if every row keeps its statement while becoming a corollary of
  the specs. They are not landed in the statement PR: at the fill stage each row's proof becomes
  the proof given here, and the row's statement, name and home stay as they are. The other
  `MIG1Gate` declarations are evidence too: the two head lemmas that move from Catalog to
  Simulation, and the two retired canonical rows re-derived as their consumers will be.

The spec theorems use the library's existing style (`ComputesInTime`, `ComputesFunInTime`,
`spaceUsed` from `initCfg`, `Cfg.ofWords` seams), not `Turing.Contract` instances (user decision
of 2026-10-13; `audits/evidence/mig1/MIG1-design.md` §2). The decision rests on the shape of the
facts (whole-machine runs from `initCfg`, judged by the output, with no exact endpoint) and on the
order of work (a contract needs a named machine, so named witnesses come first, for MIG-11 and
MIG-17); the layering obstacle of design §2, reason 1, lasts only until MIG-0b splits
`Build/Contract.lean` into a core that does not import Catalog.

/-- **Head displacement along a run** (landing:
`Turing.MultiTapeTM.abs_workTapePos_runFrom_sub_le`, new in `TuringMachine/Simulation.lean`,
namespace `Turing.MultiTapeTM`; statement and proof verbatim from the H2 statement-gate draft
`audits/evidence/h2/StepBlockDraft.lean.txt:729`, whose proof is `CodeSimulator`'s private
`h1Run_headBound`). After `t` steps of any machine, every work head is within `t` cells of where
it started: the run form of `Turing.MultiTapeTM.workTapePos_step_le`. [AB09, §1.2: a step moves
each head by at most one cell.] One lemma serves MIG-1, where it replaces Catalog's private
`f2_head_steps` (the same fact as two inequalities, retired with MIG-1 by backlog F6-1(g)), and
H2, whose design note O9 moves it below `Build/StepBlock.lean` with MIG-1. Whichever of the two
PRs lands first introduces it; the other cites it.

**Proof sketch.** Telescope the displacement into its `t` one-step differences; the triangle
inequality and the one-step bound give `t`. -/
theorem abs_workTapePos_runFrom_sub_le {m : ℕ} {S : Type} {x : List Bool}
    (M : MultiTapeTM m Bool S) (d : Cfg m Bool S x) (t : ℕ) (j : Fin m) :
    |(M.runFrom d t).workTapePos j - d.workTapePos j| ≤ (t : ℤ) := by
  let height (u : ℕ) := (M.runFrom d u).workTapePos j
  have unit (u : ℕ) : |height (u + 1) - height u| ≤ 1 := by
    simpa only [height, MultiTapeTM.runFrom_succ_eq_step'] using
      MultiTapeTM.workTapePos_step_le (tm := M) (M.runFrom d u) j
  calc
    |(M.runFrom d t).workTapePos j - d.workTapePos j| =
        |∑ u ∈ Finset.range t, (height (u + 1) - height u)| := by
      rw [Finset.sum_range_sub]; rfl
    _ ≤ ∑ u ∈ Finset.range t, |height (u + 1) - height u| := Finset.abs_sum_le_sum_abs _ _
    _ ≤ ∑ _u ∈ Finset.range t, (1 : ℤ) := Finset.sum_le_sum (fun u _ => unit u)
    _ = (t : ℤ) := by simp

end Turing.MultiTapeTM

/-- **Space from time** (landing: `Turing.FinTM.ComputesInTime.spaceUsed_le`, new in
`TuringMachine/Simulation.lean`; statement and proof are Catalog's private `f2_space_of_time`,
moved). If `M` halts on `x` with output `y` within `T` steps, then at every time `t` its work
tapes have visited at most `M.k · (T + 1)` cells in all. [AB09, Definition 4.1, and the remark
opening the proof of Theorem 4.2: a machine running in time `T` visits at most `T + 1` cells of
each tape.]

**Proof sketch.** After the halt the configuration no longer changes, so every head position at
any time `t` already occurs at some time `u ≤ T`. Each tape's visited set is therefore contained
in the image of `{0, …, T}`, which has at most `T + 1` elements; sum over the `k` tapes. -/
theorem ComputesInTime.spaceUsed_le {M : FinTM Bool} {x y : List Bool} {T : ℕ}
    (h : M.ComputesInTime x y T) (t : ℕ) :
    M.tm.spaceUsed (M.tm.initCfg x) t ≤ M.k * (T + 1) := by
  have hh := ((computesInTime_iff _ _ _ _).mp h).1
  have hsub (i : Fin M.k) :
      M.tm.visitedByTapeHead (M.tm.initCfg x) t i ⊆
        M.tm.visitedByTapeHead (M.tm.initCfg x) T i := by
    intro z hz
    obtain ⟨u, _, rfl⟩ := Finset.mem_image.mp hz
    by_cases hu : u ≤ T
    · exact Finset.mem_image.mpr ⟨u, Finset.mem_range.mpr (by omega), rfl⟩
    · have hr : M.tm.runFrom (M.tm.initCfg x) u =
          M.tm.runFrom (M.tm.initCfg x) T := by
        rw [show u = T + (u - T) by omega, MultiTapeTM.runFrom_add,
          MultiTapeTM.runFrom_of_halt _ hh]
      exact Finset.mem_image.mpr ⟨T, Finset.mem_range.mpr (by omega),
        congrArg (fun c => c.workTapePos i) hr.symm⟩
  calc
    _ ≤ ∑ _i : Fin M.k, (T + 1) := by
      apply Finset.sum_le_sum
      intro i _
      exact (Finset.card_le_card (hsub i)).trans (by
        unfold MultiTapeTM.visitedByTapeHead
        exact (Finset.card_image_le).trans (by rw [Finset.card_range]))
    _ = _ := by simp

/-- **The branch union's space** (landing: `Turing.FinTM.branchTM_spaceUsed`, new in
`TuringMachine/Simulation.lean` after `branchTM_computes`; statement verbatim from Catalog's
private `f2_branch_space`, whose proof moves with it). The branch union selecting `b` uses
exactly the selected machine's space plus one origin cell for each tape of the idle bank.

**Proof sketch.** Catalog's `f2_branch_space`: the branch union runs the selected machine on its
own bank (`leftCfg_run`, `rightCfg_run`) and never moves the other bank's heads, whose visited
sets stay the origin singletons; split the sum over the two banks with `Fin.sum_univ_add`, which

      else M₂.tm.spaceUsed (M₂.tm.initCfg x) t + M₁.k := by

namespace MIG1Gate

/-- **Moved head lemma** (landing: `Turing.FinTM.rewind_scan_heads`, moved verbatim, name and
statement unchanged, from `Build/Catalog.lean:10376` to `TuringMachine/Simulation.lean` after
`Turing.FinTM.timed_rewind`; here inside `MIG1Gate` to avoid the clash with the Catalog
original). A native input rewind keeps every work head fixed, at every prefix, including its
dispatch step.

**Proof sketch.** Induct on the input position; each step is a `controlAction`. -/
theorem rewind_scan_heads {k : ℕ} {S : Type} {x : List Bool}
    (tm : MultiTapeTM k Bool S) (scan : S) (dest : Option S)
    (htr : ∀ inp work, tm.tr scan inp work = match inp with
      | some _ => controlAction .neg (some scan)
      | none => controlAction .pos dest) :
    ∀ (j : ℕ) (cfg : Cfg k Bool S x), cfg.state = some scan →
      cfg.inputPos.val = j → j ≤ x.length →
      ∀ u ≤ j + 1, (tm.runFrom cfg u).workTapePos = cfg.workTapePos := by
  intro j
  induction j with
  | zero =>
    intro cfg hs hj hp u hu
    rcases Nat.le_one_iff_eq_zero_or_eq_one.mp hu with rfl | rfl
    · rfl
    · have hz : cfg.inputPos = 0 := Fin.ext hj
      have hi : cfg.inputSymbol = none := by simp [Cfg.inputSymbol, hz]
      change (tm.step cfg).workTapePos = _
      simp only [MultiTapeTM.step, hs, htr, hi, controlAction_apply]
  | succ j ih =>
    intro cfg hs hj hp u hu
    cases u with
    | zero => rfl
    | succ u =>
      have hi : cfg.inputSymbol = some (x[j]'(by omega)) :=
        inputSymbolInner j (by omega) (by omega)
      have he : tm.step cfg =
          {cfg with state := some scan, inputPos := moveInputPos cfg.inputPos .neg} := by
        simp only [MultiTapeTM.step, hs, htr, hi, controlAction_apply]
      rw [MultiTapeTM.runFrom_succ_eq_step, he]
      apply ih _ rfl _ (by omega) u (by omega)
      simp only [moveInputPos_neg_val]
      omega

/-- **Moved head lemma** (landing: `Turing.FinTM.rewind_heads`, moved verbatim from
`Build/Catalog.lean:10415`, name and statement unchanged; here inside `MIG1Gate`). The bounded
rewind reaches its destination with the input head at `1` within `pos + 2` steps, and every work
head stays put throughout. (Copied verbatim except that one line of 109 characters is wrapped.)

**Proof sketch.** One start step, then `Turing.FinTM.rewind_scan` for the run and
`Turing.FinTM.rewind_scan_heads` for the heads. -/
theorem rewind_heads {k : ℕ} {S : Type} {x : List Bool}
    (tm : MultiTapeTM k Bool S) (start scan : S) (dest : Option S)
    (hstart : ∀ inp work, tm.tr start inp work = controlAction .neg (some scan))
    (hscan : ∀ inp work, tm.tr scan inp work = match inp with
      | some _ => controlAction .neg (some scan)
      | none => controlAction .pos dest)
    (c : Cfg k Bool S x) (hs : c.state = some start) :
    ∃ r ≤ c.inputPos.val + 2,
      tm.runFrom c r = {c with state := dest, inputPos := 1} ∧
      ∀ u ≤ r, (tm.runFrom c u).workTapePos = c.workTapePos := by
  have hstep : tm.step c =
      {c with state := some scan, inputPos := moveInputPos c.inputPos .neg} := by
    simp only [MultiTapeTM.step, hs, hstart, controlAction_apply]
  have hp : (moveInputPos c.inputPos .neg).val ≤ x.length := by
    rw [moveInputPos_neg_val]
    have := c.inputPos.isLt
    omega
  refine ⟨1 + ((moveInputPos c.inputPos .neg).val + 1), ?_, ?_, ?_⟩
  · rw [moveInputPos_neg_val]; omega
  · rw [MultiTapeTM.runFrom_add]
    change tm.runFrom (tm.step c) _ = _
    rw [hstep, rewind_scan tm scan dest hscan _ rfl hp]
  · intro u hu
    cases u with
    | zero => rfl
    | succ u =>
      rw [MultiTapeTM.runFrom_succ_eq_step, hstep]
      exact rewind_scan_heads tm scan dest hscan (moveInputPos c.inputPos .neg).val _ rfl rfl hp u
        (by omega)

end MIG1Gate

end Turing.FinTM

/-- **The copy machine** (landing: `Turing.FinTM.idTM`, made public in place at
`TuringMachine/Composition.lean:88`, body unchanged). A machine with no work tapes and one state
that writes each input symbol to its output while moving right, and halts on the blank after
the input. [AB09, §1.2] -/
def idTM : FinTM Bool where
  k := 0
  State := Unit
  tm :=
    { q₀ := ()
      tr := fun _ inp _ =>
        match inp with
        | some b => ⟨SignType.pos, fun i => i.elim0, some b, some ()⟩
        | none => ⟨SignType.zero, fun i => i.elim0, none, none⟩ }

/-- **The copy machine's time** (landing: `Turing.FinTM.idTM_computes`, new in `Composition`
before `computesFunInTime_id`). On every input `x` the copy machine halts within `|x| + 1`
steps with output `x`. [AB09, §1.2]

**Proof sketch.** The body of today's `computesFunInTime_id` (`Composition.lean:137`) up to its
final weakening: by the private run invariant `idTM_run`, after `|x|` steps the machine is live,
its input head is at cell `|x| + 1` and it has written `x`; there it reads the blank, and the
next step halts without writing. -/
theorem idTM_computes (x : List Bool) : idTM.ComputesInTime x x (x.length + 1) := by
  sorry

/-- **The constant machine** (landing: `Turing.FinTM.constTM`, made public in place at
`Composition.lean:168`, body unchanged). A machine with no work tapes whose `|w| + 1` states
form the emission chain of the fixed word `w`: it writes `w`, one symbol per step, ignoring its
input, and halts. [AB09, §1.2] -/
def constTM (w : List Bool) : FinTM Bool where
  k := 0
  State := Fin (w.length + 1)
  tm := { q₀ := 0, tr := fun i _ _ => emitAction w id i }

/-- **The constant machine's time** (landing: `Turing.FinTM.constTM_computes`, new in
`Composition` before `computesFunInTime_const`; proved, the row's body moved). On every input
the constant machine halts within `|w| + 1` steps with output `w`. [AB09, §1.2]

**Proof sketch.** The emission chain writes `w` in `|w|` steps and halts on the next
(`Turing.FinTM.emit_halts`), appending to the initially empty output. -/
theorem constTM_computes (w x : List Bool) :
    (constTM w).ComputesInTime x w (w.length + 1) := by
  obtain ⟨hs, ho⟩ := emit_halts (constTM w).tm w id (fun _ _ _ => rfl)
    ((constTM w).tm.initCfg x) rfl
  exact ⟨_, hs, by simpa only [MultiTapeTM.initCfg, Cfg.init, List.nil_append] using ho, rfl⟩

/-- **The fixed-word comparator** (landing: `Turing.FinTM.ifEqTM`, made public in place at
`Composition.lean:189`, body unchanged). A machine with no work tapes that compares its input
with the fixed word `w₀` symbol by symbol and then runs the emission chain of `u` (on an exact
match followed by the blank) or of `v` (on the first mismatch, an early blank, or a symbol past
the end of `w₀`). [AB09, §1.2] -/
def ifEqTM (w₀ u v : List Bool) : FinTM Bool where
  k := 0
  State := Fin (w₀.length + 1) ⊕ (Fin (u.length + 1) ⊕ Fin (v.length + 1))
  tm :=
    { q₀ := .inl 0
      tr := fun q inp _ => match q with
        | .inl i =>
          if h : i.val < w₀.length then
            if inp = some w₀[i.val] then
              controlAction .pos (some (.inl ⟨i.val + 1, by omega⟩))
            else controlAction 0 (some (.inr (.inr 0)))
          else if inp = none then controlAction 0 (some (.inr (.inl 0)))
            else controlAction 0 (some (.inr (.inr 0)))
        | .inr (.inl i) => emitAction u (fun j => .inr (.inl j)) i
        | .inr (.inr i) => emitAction v (fun j => .inr (.inr j)) i }

/-- **The comparator's time** (landing: `Turing.FinTM.ifEqTM_computes`, new in `Composition`
before `computesFunInTime_ifEq`). The comparator computes `w ↦ if w = w₀ then u else v` within
`(|w₀| + max |u| |v| + 3)·(n + 1)` steps, the constant of today's row made explicit.

**Proof sketch.** The body of today's `computesFunInTime_ifEq` (`Composition.lean:335`): the
private comparison run `ifEq_run` reaches the halt within `|w₀| + max |u| |v| + 3` steps with
the selected word as output, and that constant is at most its product with `n + 1`. -/
theorem ifEqTM_computes (w₀ u v : List Bool) :
    (ifEqTM w₀ u v).ComputesFunInTime (fun w => if w = w₀ then u else v)
      (fun n => (w₀.length + max u.length v.length + 3) * (n + 1)) := by
  sorry

/-- **The buffered composition computes the composite** (landing:
`Turing.FinTM.bufferedCompTM_computesFunInTime`, new in `Composition` before
`computesFunInTime_comp`; proved, the row's body moved). If `M₁` computes `f` within `T₁` and
`M₂` computes `g` within a monotone `T₂`, then `bufferedCompTM M₁ M₂` computes `g ∘ f` within
`2·(T₁ n + T₂ (T₁ n) + 1)` steps. [AB09, §1.2; the composition that [AB09] leaves to
high-level descriptions.]

**Proof sketch.** `bufferedCompTM_computesInTime` gives `T₁ |x| + |f x| + 2 + T₂ |f x|`; the
intermediate word is no longer than the time that produced it (`output_length_le`), and
monotonicity of `T₂` turns `T₂ |f x|` into `T₂ (T₁ |x|)`. -/
theorem bufferedCompTM_computesFunInTime {M₁ M₂ : FinTM Bool} {f g : List Bool → List Bool}
    {T₁ T₂ : ℕ → ℕ}
    (h₁ : M₁.ComputesFunInTime f T₁) (h₂ : M₂.ComputesFunInTime g T₂)
    (hT₂ : Monotone T₂) :
    (bufferedCompTM M₁ M₂).ComputesFunInTime (g ∘ f) fun n => 2 * (T₁ n + T₂ (T₁ n) + 1) := by
  intro x
  have hlen : (f x).length ≤ T₁ x.length := by
    have ho := ((computesInTime_iff _ _ _ _).mp (h₁ x)).2
    simpa only [ho] using M₁.tm.output_length_le x (T₁ x.length)
  have htime : T₂ (f x).length ≤ T₂ (T₁ x.length) := hT₂ hlen
  exact (bufferedCompTM_computesInTime M₁ M₂ (h₁ x) (h₂ (f x))).mono
    (by dsimp only; omega)

/-- **The buffered composition on the first machine's image** (landing:
`Turing.FinTM.bufferedCompTM_computesFunInTime_on_image`, new in `Composition` before
`exists_comp_on_image`; proved, the row's body moved). If `M` computes `f` within `T₁` and, for
every input `x`, `U` maps `f x` to `g x` within `T₂ |x|` steps, then `bufferedCompTM M U`
computes `g` within `2·T₁ n + T₂ n + 2` steps. No totality of `U` and no monotonicity is
assumed.

**Proof sketch.** As `bufferedCompTM_computesFunInTime`, with the second phase's budget
measured at the original input length. -/
theorem bufferedCompTM_computesFunInTime_on_image (M U : FinTM Bool)
    (f g : List Bool → List Bool) (T₁ T₂ : ℕ → ℕ) (hM : M.ComputesFunInTime f T₁)
    (hU : ∀ x, U.ComputesInTime (f x) (g x) (T₂ x.length)) :
    (bufferedCompTM M U).ComputesFunInTime g (fun n => 2 * T₁ n + T₂ n + 2) := by
  intro x
  have hlen : (f x).length ≤ T₁ x.length := by
    have ho := ((computesInTime_iff _ _ _ _).mp (hM x)).2
    simpa only [ho] using M.tm.output_length_le x (T₁ x.length)
  exact (bufferedCompTM_computesInTime M U (hM x) (hU x)).mono (by dsimp only; omega)

/-- **The buffered composition's halting relation** (landing:
`Turing.FinTM.bufferedCompTM_computes_iff`, new in `Composition` before `exists_comp_partial`;
proved, the row's body moved). For all machines `M₁`, `M₂` and words `x`, `w`: the buffered
composition halts on `x` with output `w` if and only if `M₁` halts on `x` with some output `y`
and `M₂` halts on `y` with output `w`. No totality or time hypotheses.

**Proof sketch.** The body of today's `exists_comp_partial` (`Composition.lean:474`): a
divergent first phase keeps every composite configuration live (`bufferedFirstCfg_run`);
otherwise `bufferedComp_start` reaches the second phase with `M₂`'s initial configuration on the
virtual input `y`, and `bufferedSecondCfg_run` tracks `M₂` step for step in both directions. -/
theorem bufferedCompTM_computes_iff (M₁ M₂ : FinTM Bool) (x w : List Bool) :
    (∃ t, (bufferedCompTM M₁ M₂).ComputesInTime x w t) ↔
      ∃ y : List Bool, (∃ t, M₁.ComputesInTime x y t) ∧ ∃ t, M₂.ComputesInTime y w t := by
  classical
  constructor
  · rintro ⟨t, ht⟩
    -- A divergent first component would keep every composite configuration live.
    have hh : ∃ s, (M₁.tm.runFrom (M₁.tm.initCfg x) s).state = none := by
      by_contra h

/-- **The untimed conditional** (landing: `Turing.FinTM.condTM`, made public in place at
`Composition.lean:517`, body unchanged). Run `D` with its first emission captured in a state
register, rewind the input, then enter `M₁` or `M₂` on disjoint fresh tapes according to the
register; an empty register at dispatch halts. -/
def condTM (D M₁ M₂ : FinTM Bool) : FinTM Bool where
  k := D.k + (M₁.k + M₂.k)
  State := (Option D.State × Option Bool) ⊕ (Option Bool ⊕ (M₁.State ⊕ M₂.State))
  tm :=
    { q₀ := .inl (some D.tm.q₀, none)
      tr := fun q inp work => match q with
        | .inl (some q, reg) =>
          let a := D.tm.tr q inp (fun i => work (Fin.castAdd (M₁.k + M₂.k) i))
          ⟨a.inputTape, Fin.addCases a.workTapes (fun _ => (none, 0)), none,
            some (.inl (a.state, reg.or a.output))⟩
        | .inl (none, reg) => controlAction .neg (some (.inr (.inl reg)))
        | .inr (.inl reg) => match inp with
          | some _ => controlAction .neg (some (.inr (.inl reg)))
          | none => controlAction .pos
              (reg.map (fun b => .inr (.inr (branchTM M₁ M₂ b).tm.q₀)))
        | .inr (.inr q) => rightAction D.k (fun s => .inr (.inr s))
            ((branchTM M₁ M₂ false).tm.tr q inp (fun i => work (Fin.natAdd D.k i))) }

private def timedPadTM (D : FinTM Bool) (r : ℕ) : MultiTapeTM (D.k + r) Bool D.State where
  q₀ := D.tm.q₀
  tr q inp work := leftAction r id (D.tm.tr q inp (fun i => work (Fin.castAdd r i)))

/-- **The timed conditional** (landing: `Turing.FinTM.timedCondTM`, made public in place at
`Build/Wrappers.lean:479`, body unchanged; today also copied into Catalog as `f2_timedCondTM`).
Run the decider `D` with its output captured on the last tape, step back to read the verdict,
rewind the input, then run `M₁` or `M₂`, as the verdict says, from its genuine initial
configuration on its own untouched tape bank (W3). The branch tapes are idle while `D` runs. -/
def timedCondTM (D M₁ M₂ : FinTM Bool) : FinTM Bool where
  k := (D.k + (M₁.k + M₂.k)) + 1
  State := D.State ⊕ (Bool ⊕ ((Bool × Bool) ⊕ (M₁.State ⊕ M₂.State)))
  tm :=
    { q₀ := .inl D.tm.q₀
      tr := fun q inp work => match q with
        | .inl q => captureAction Sum.inl (.inr (.inl false))
            ((timedPadTM D (M₁.k + M₂.k)).tr q inp (fun i => work i.castSucc))
        | .inr (.inl false) =>
          ⟨0, (fun i => if (i : ℕ) < D.k + (M₁.k + M₂.k) then (none, 0)
            else (none, .neg)), none, some (.inr (.inl true))⟩
        | .inr (.inl true) => controlAction 0
            (some (.inr (.inr (.inl ((work (Fin.last _)).getD false, false)))))
        | .inr (.inr (.inl (b, false))) =>
            controlAction .neg (some (.inr (.inr (.inl (b, true)))))
        | .inr (.inr (.inl (b, true))) => match inp with
          | some _ => controlAction .neg (some (.inr (.inr (.inl (b, true)))))
          | none => controlAction .pos
              (some (.inr (.inr (.inr (branchTM M₁ M₂ b).tm.q₀))))
        | .inr (.inr (.inr q)) => leftAction 1 id
            (rightAction D.k (fun s => .inr (.inr (.inr s)))
              ((branchTM M₁ M₂ false).tm.tr q inp
                (fun i => work (Fin.natAdd D.k i).castSucc))) }

/-- **The timed conditional's time** (landing: `Turing.FinTM.timedCondTM_computes`, new in
`Build/Wrappers.lean` before `computesFunInTime_cond`; statement verbatim from Catalog's private

runs on the same physical input.

which `f2_cond_time` copies: the captured decider run, the two-step verdict read and the input

  sorry

/-- **The timed conditional's space** (landing: `Turing.FinTM.timedCondTM_spaceUsed`, new in

/-- **The diagonal pairing machine** (landing: `Turing.pairDiagTM`, made public in place at
`TuringMachine/Encoding.lean:299`, body unchanged). A six-state machine with no work tapes that,

private def loopBodyTM (body : FinTM Bool) (anchor : body.State) : FinTM Bool where
  k := body.k + 1
  State := body.State × Bool
  tm :=
    { q₀ := (body.tm.q₀, false)
      tr := fun q inp work =>
        if q.1 = anchor ∧ q.2 = false then
          { inputTape := 0
            workTapes := fun i =>
              if (i : ℕ) < body.k then (none, 0) else (some (some false), 0)
            output := none
            state := none }
        else
          let a := body.tm.tr q.1 inp (fun i => work i.castSucc)
          { inputTape := a.inputTape
            workTapes := fun i =>
              if h : (i : ℕ) < body.k then a.workTapes ⟨i, h⟩
              else (if a.state = none then some (some true) else none, 0)
            output := a.output
            state := a.state.map (fun s => (s, false)) } }

private abbrev LoopHostState (body F : FinTM Bool) :=
  F.State ⊕ ((Bool × (body.State × Bool)) ⊕ Fin 14)

private def loopFuelSource (body F : FinTM Bool) :
    MultiTapeTM (body.k + 1 + (1 + F.k)) Bool F.State where
  q₀ := F.tm.q₀
  tr := fun q inp work =>
    rightAction (body.k + 1) id (rightAction 1 id
      (F.tm.tr q inp fun i => work (Fin.natAdd (body.k + 1) (Fin.natAdd 1 i))))

private def loopBodySource (body F : FinTM Bool) (anchor : body.State) :
    MultiTapeTM (body.k + 1 + (1 + F.k)) Bool (body.State × Bool) where
  q₀ := (body.tm.q₀, false)
  tr := fun q inp work => leftAction (1 + F.k) id
    ((loopBodyTM body anchor).tm.tr q inp fun i => work (Fin.castAdd (1 + F.k) i))

private def loopControlAction (body F : FinTM Bool) (inp : SignType)
    (flag : Option (Option Bool)) (counter payload : Option (Option Bool) × SignType)
    (out : Option Bool) (next : Option (LoopHostState body F)) :
    Action (body.k + 1 + (1 + F.k) + 1) Bool (LoopHostState body F) where
  inputTape := inp
  workTapes := fun i =>
    if (i : ℕ) = body.k then (flag, 0)
    else if (i : ℕ) = body.k + 1 then counter
    else if (i : ℕ) = body.k + 1 + (1 + F.k) then payload
    else (none, 0)
  output := out
  state := next

private def loopBodyDispatch (body F : FinTM Bool) (anchor : body.State) (forward : Bool)
    (startup : Bool) (s : body.State × Bool) (inp : Option Bool)
    (work : Fin (body.k + 1 + (1 + F.k) + 1) → Option Bool) :
    Action (body.k + 1 + (1 + F.k) + 1) Bool (LoopHostState body F) :=
  bif forward then
    leftAction 1 id (Turing.emitAction (fun s => .inr (.inl (startup, s)))
      (.inr (.inr (if startup then 6 else 7)))
      ((loopBodySource body F anchor).tr s inp (fun i => work i.castSucc)))
  else
    captureAction (fun s => .inr (.inl (startup, s)))
      (.inr (.inr (if startup then 6 else 7)))
      ((loopBodySource body F anchor).tr s inp fun i => work i.castSucc)

      | _ => controlAction 0 (some (2, q.2)) }

private def splitRewindTM (k : ℕ) : FinTM Bool where
  k := k + 1
  State := Fin 3
  tm := {
    q₀ := 0
    tr := fun q inp _ => match q.val with
      | 0 => controlAction .neg (some 1)
      | 1 => match inp with
        | some _ => controlAction .neg (some 1)
        | none => controlAction .pos (some 2)
      | _ => controlAction 0 (some 2) }

private def splitEmitTM (k : ℕ) : FinTM Bool where
  k := k + 1
  State := Fin 4
  tm := {
    q₀ := 0
    tr := fun q inp work => match q.val with
      | 0 => match work 0 with
        | none => ⟨0, fun _ => (none, 0), some false, some 2⟩
        | some _ => ⟨0, fun _ => (none, 0), inp, some 1⟩
      | 1 => ⟨.pos, Fin.cases (none, .pos) (fun _ => (none, 0)), inp, some 0⟩
      | 2 => ⟨0, fun _ => (none, 0), some true, some 3⟩
      | _ => match inp with
        | some b => ⟨.pos, fun _ => (none, 0), some b, some 3⟩
        | none => controlAction 0 none }

private inductive SplitBodyState (S : Type) where
  | anchor
  | prepare (q : Fin 3 × Bool)
  | count (q : S) (over : Bool)
  | check (over : Bool)
  | rewind (accept : Bool) (q : Fin 3)
  | restore (q : Fin 5 × Bool)
  | emit (q : Fin 4)

private instance splitBodyStateFintype (S : Type) [Fintype S] :
    Fintype (SplitBodyState S) := derive_fintype% _

private instance splitBodyStateDecidableEq (S : Type) [DecidableEq S] :
    DecidableEq (SplitBodyState S) := by
  intro a b
  cases a <;> cases b
  all_goals try (solve | apply isFalse; intro h; cases h)
  · exact isTrue rfl
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (SplitBodyState.prepare.injEq _ _)))
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (SplitBodyState.count.injEq _ _ _ _)))
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (SplitBodyState.check.injEq _ _)))
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (SplitBodyState.rewind.injEq _ _ _ _)))
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (SplitBodyState.restore.injEq _ _)))
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (SplitBodyState.emit.injEq _ _)))

private def splitBodyTM (M : FinTM Bool) (start : M.State) : FinTM Bool where
  k := M.k + 1
  State := SplitBodyState M.State
  tm := {
    q₀ := .anchor
    tr := fun q inp work => match q with
      | .anchor => controlAction 0 (some (.prepare (0, false)))
      | .prepare p =>
        if p.1 = 2 then controlAction 0 (some (.count start p.2))
        else ((splitPrepareTM M.k).tm.tr p inp work).mapState .prepare
      | .count q over => splitCountAction .count .check over inp
          (M.tm.tr q none (fun i => work i.succ))
      | .check over => controlAction 0 (some (.rewind (!over && inp.isNone) 0))
      | .rewind ok p =>
        if p = 2 then controlAction 0 (some (if ok then .emit 0 else .restore (0, false)))
        else ((splitRewindTM M.k).tm.tr p inp work).mapState (.rewind ok)
      | .restore p =>
        if p = (4, false) then controlAction 0 (some .anchor)
        else ((splitRestoreTM M.k).tm.tr p inp work).mapState .restore
      | .emit p => ((splitEmitTM M.k).tm.tr p inp work).mapState .emit }

private def emitterCompareTM : FinTM Bool where
  k := 2
  State := Fin 3 × Bool
  tm := {
    q₀ := (0, true)
    tr := fun q _ work => match q.1.val with
      | 0 =>
        if work 0 = none ∧ work 1 = none then
          ⟨0, fun _ => (none, .neg), none, some (1, q.2)⟩
        else
          ⟨0, fun _ => (none, .pos), none,
            some (0, q.2 && decide (work 0 = work 1))⟩
      | 1 =>
        if work 0 = none ∧ work 1 = none then
          ⟨0, fun _ => (none, .pos), none, some (2, q.2)⟩
        else ⟨0, fun _ => (none, .neg), none, some (1, q.2)⟩
      | _ => controlAction 0 (some (2, q.2)) }

private def emitterP2EraseTM : FinTM Bool where
  k := 1
  State := Fin 3
  tm := {
    q₀ := 0
    tr := fun q _ work => match q.val with
      | 0 => match work 0 with
        | some _ => ⟨0, fun _ => (none, .pos), none, some 0⟩
        | none => ⟨0, fun _ => (none, .neg), none, some 1⟩
      | 1 => match work 0 with
        | some _ => ⟨0, fun _ => (some none, .neg), none, some 1⟩
        | none => ⟨0, fun _ => (none, .pos), none, some 2⟩
      | _ => controlAction 0 (some 2) }

private def emitterP2PrepareTM : FinTM Bool where
  k := 3
  State := Fin 9 × Bool
  tm := {
    q₀ := (0, false)
    tr := fun q inp work => match q.1.val with
      | 0 => match work 0 with
        | some b => ⟨.pos, fun i =>
            (if i = 1 then some (some b) else none, if i = 2 then 0 else .pos),
            none, some (0, q.2 || inp.isNone)⟩
        | none => controlAction 0 (some (1, q.2))
      | 1 => match inp with
        | some b => ⟨.pos, fun i =>
            (if i = 2 then some (some b) else none, if i = 2 then .pos else 0),
            none, some (1, q.2)⟩
        | none => controlAction 0 (some (2, q.2))
      | 2 => ⟨0, fun i => (none, if i = 2 then 0 else .neg), none, some (3, q.2)⟩
      | 3 => match work 0 with
        | some _ => ⟨0, fun i => (none, if i = 2 then 0 else .neg), none, some (3, q.2)⟩
        | none => ⟨0, fun i => (none, if i = 2 then 0 else .pos), none, some (4, q.2)⟩
      | 4 => ⟨0, fun i => (none, if i = 2 then .neg else 0), none, some (5, q.2)⟩
      | 5 => match work 2 with
        | some _ => ⟨0, fun i => (none, if i = 2 then .neg else 0), none, some (5, q.2)⟩
        | none => ⟨0, fun i => (none, if i = 2 then .pos else 0), none, some (6, q.2)⟩
      | 6 => controlAction .neg (some (7, q.2))
      | 7 => match inp with
        | some _ => controlAction .neg (some (7, q.2))
        | none => controlAction .pos (some (8, q.2))
      | _ => controlAction 0 (some (8, q.2)) }

private def emitterP2LeftIndex (k l : ℕ) : Fin k ↪ Fin (k + l + 1) :=
  (Fin.castAddEmb l).trans (Fin.succEmb (k + l))

private def emitterP2RightIndex (k l : ℕ) : Fin l ↪ Fin (k + l + 1) :=
  (Fin.natAddEmb k).trans (Fin.succEmb (k + l))

private def emitterP2OneIndex {l : ℕ} (slot : Fin l) : Fin 1 ↪ Fin l where
  toFun _ := slot
  inj' := fun _ _ _ => Subsingleton.elim _ _

private def emitterP2SmallIndex (k l : ℕ) (hk : 0 < k) (hl : 0 < l) :
    Fin 3 ↪ Fin (k + l + 1) where
  toFun i := if i = 0 then 0 else if i = 1 then emitterP2LeftIndex k l ⟨0, hk⟩
    else emitterP2RightIndex k l ⟨0, hl⟩
  inj' := by
    intro a b h
    fin_cases a <;> fin_cases b <;> try rfl
    all_goals have hv := congrArg Fin.val h
    all_goals simp [emitterP2LeftIndex, emitterP2RightIndex] at hv <;> omega

private def emitterP2PairIndex (k l : ℕ) (hk : 0 < k) (hl : 0 < l) :
    Fin 2 ↪ Fin (k + l + 1) where
  toFun i := if i = 0 then emitterP2LeftIndex k l ⟨0, hk⟩
    else emitterP2RightIndex k l ⟨0, hl⟩
  inj' := by
    intro a b h
    fin_cases a <;> fin_cases b <;> try rfl
    all_goals have hv := congrArg Fin.val h
    all_goals simp [emitterP2LeftIndex, emitterP2RightIndex] at hv <;> omega

private inductive EmitterP2State (S T : Type) where
  | anchor
  | prepare (q : Fin 9 × Bool)
  | widthStart
  | width (q : S)
  | lengthStart
  | length (q : T)
  | compare (q : Fin 3 × Bool)
  | eraseLeft (ok : Bool) (q : Fin 3)
  | eraseRight (ok : Bool) (q : Fin 3)
  | advance (q : Fin 5 × Bool)
  | emit (q : Fin 4)

private instance emitterP2StateFintype (S T : Type) [Fintype S] [Fintype T] :
    Fintype (EmitterP2State S T) := derive_fintype% _

private instance emitterP2StateDecidableEq (S T : Type) [DecidableEq S] [DecidableEq T] :
    DecidableEq (EmitterP2State S T) := by
  intro a b
  cases a <;> cases b
  all_goals try (solve | apply isFalse; intro h; cases h)
  · exact isTrue rfl
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (EmitterP2State.prepare.injEq _ _)))
  · exact isTrue rfl
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (EmitterP2State.width.injEq _ _)))
  · exact isTrue rfl
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (EmitterP2State.length.injEq _ _)))
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (EmitterP2State.compare.injEq _ _)))
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (EmitterP2State.eraseLeft.injEq _ _ _ _)))
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (EmitterP2State.eraseRight.injEq _ _ _ _)))
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (EmitterP2State.advance.injEq _ _)))
  · exact decidable_of_iff _ (Iff.symm (iff_of_eq (EmitterP2State.emit.injEq _ _)))

private def emitterP2BodyTM (C D : FinTM Bool) (hk : 0 < C.k) (hl : 0 < D.k)
    (ce cx : C.State) (de dx : D.State) : FinTM Bool where
  k := C.k + D.k + 1
  State := EmitterP2State C.State D.State
  tm := {
    q₀ := .anchor
    tr := fun q inp work => match q with
      | .anchor => controlAction 0 (some (.prepare (0, false)))
      | .prepare p =>
        if p.1 = 8 then controlAction 0 (some (if p.2 then .eraseLeft false 0 else .widthStart))
        else ((embedEmitTM (emitterP2SmallIndex C.k D.k hk hl)
            emitterP2PrepareTM.tm).tr p inp work).mapState .prepare
      | .widthStart => ((embedEmitTM (emitterP2LeftIndex C.k D.k)
          C.tm).tr ce inp work).mapState .width
      | .width p =>
        if p = cx then controlAction 0 (some .lengthStart)
        else ((embedEmitTM (emitterP2LeftIndex C.k D.k) C.tm).tr p inp work).mapState .width
      | .lengthStart => ((embedEmitTM (emitterP2RightIndex C.k D.k)
          D.tm).tr de inp work).mapState .length
      | .length p =>
        if p = dx then controlAction 0 (some (.compare (0, true)))
        else ((embedEmitTM (emitterP2RightIndex C.k D.k) D.tm).tr p inp work).mapState .length
      | .compare p =>
        if p.1 = 2 then controlAction 0 (some (.eraseLeft p.2 0))
        else ((embedEmitTM (emitterP2PairIndex C.k D.k hk hl)
            emitterCompareTM.tm).tr p inp work).mapState .compare
      | .eraseLeft ok p =>
        if p = 2 then controlAction 0 (some (.eraseRight ok 0))
        else ((embedEmitTM (emitterP2OneIndex (emitterP2LeftIndex C.k D.k ⟨0, hk⟩))
          emitterP2EraseTM.tm).tr p inp work).mapState (.eraseLeft ok)
      | .eraseRight ok p =>
        if p = 2 then controlAction 0 (some (if ok then .emit 0 else .advance (0, false)))
        else ((embedEmitTM (emitterP2OneIndex (emitterP2RightIndex C.k D.k ⟨0, hl⟩))
          emitterP2EraseTM.tm).tr p inp work).mapState (.eraseRight ok)
      | .advance p =>
        if p = (4, false) then controlAction 0 (some .anchor)
        else ((embedEmitTM (emitterP2OneIndex (0 : Fin (C.k + D.k + 1)))
          (splitRestoreTM 0).tm).tr p inp work).mapState .advance
      | .emit p => ((embedEmitTM (emitterP2OneIndex (0 : Fin (C.k + D.k + 1)))
          (splitEmitTM 0).tm).tr p inp work).mapState .emit }

/-- **The pair extractor** (landing: `Turing.FinTM.pairExtractTM`, made public in place at
`Primitives.lean:665`, body unchanged). On `pairEncode a b` it validates the doubled prefix while
buffering `a` on its single work tape, then emits `a` if `first` and the suffix `b` if
`second`; on a malformed input it halts with empty output. One machine serves the
first-component, second-component and concatenation rows. -/

  k := 1
  State := Option Bool ⊕ Fin 3
  tm :=
    { q₀ := .inl none
      tr := fun q inp work => match q with
        | .inl none => match inp with
          | some b => ⟨.pos, fun _ => (none, 0), none, some (.inl (some b))⟩
          | none => ⟨0, fun _ => (none, 0), none, none⟩
        | .inl (some b) => match inp with
          | none => ⟨0, fun _ => (none, 0), none, none⟩
          | some c =>
            if b = c then
              ⟨.pos, fun _ => (some (some b), .pos), none, some (.inl none)⟩
            else if b then ⟨.pos, fun _ => (none, 0), none, none⟩
            else ⟨.pos, fun _ => (none, .neg), none, some (.inr 0)⟩

          | 0 => match work 0 with
            | some _ => ⟨0, fun _ => (none, .neg), none, some (.inr 0)⟩
            | none => ⟨0, fun _ => (none, .pos), none, some (.inr 1)⟩
          | 1 => match work 0 with
            | some b => ⟨0, fun _ => (none, .pos), if first then some b else none, some (.inr 1)⟩
            | none => ⟨0, fun _ => (none, 0), none, some (.inr 2)⟩

private inductive FwdMapState (Q : Type) where
  | parse (pending : Option Bool)
  | copyB | backB | backA | emitA | emitAgain (b : Bool) | separator
  | run (q : Q) (tag : Bool)
  deriving DecidableEq

private instance fwdMapStateFintype (Q : Type) [Fintype Q] : Fintype (FwdMapState Q) :=
  derive_fintype% _

private def fwdMapAct (M : FinTM Bool) (inp : SignType)
    (a b : Option (Option Bool) × SignType) (out : Option Bool)
    (next : Option (FwdMapState M.State)) : Action (1 + (1 + M.k)) Bool (FwdMapState M.State) :=
  ⟨inp, tapeBlocks (fun _ => a) b (fun _ => (none, 0)), out, next⟩

private def fwdMapTM (M : FinTM Bool) (forward : Bool) : FinTM Bool where
  k := 1 + (1 + M.k)
  State := FwdMapState M.State
  tm := {
    q₀ := .parse none
    tr := fun q inp work =>
      let act := fwdMapAct M
      let first := work (Fin.castAdd (1 + M.k) (0 : Fin 1))
      let second := work (Fin.natAdd 1 (Fin.castAdd M.k (0 : Fin 1)))
      match q with
      | .parse none => match inp with
        | none => act 0 (none, 0) (none, 0) none none
        | some b => act .pos (none, 0) (none, 0) none (some (.parse (some b)))
      | .parse (some b) => match inp with
        | none => act 0 (none, 0) (none, 0) none none
        | some d => if b = d then
            act .pos (some (some b), .pos) (none, 0) none (some (.parse none))
          else if b then act .pos (none, 0) (none, 0) none none
          else act .pos (none, .neg) (none, 0) none (some .copyB)
      | .copyB => match inp with
        | some b => act .pos (none, 0) (some (some b), .pos) none (some .copyB)
        | none => act 0 (none, 0) (none, .neg) none (some .backB)
      | .backB => match second with
        | some _ => act 0 (none, 0) (none, .neg) none (some .backB)
        | none => act 0 (none, 0) (none, .pos) none (some .backA)
      | .backA => match first with
        | some _ => act 0 (none, .neg) (none, 0) none (some .backA)
        | none => act 0 (none, .pos) (none, 0) none (some .emitA)
      | .emitA => match first with
        | some b => act 0 (none, 0) (none, 0) (some b) (some (.emitAgain b))
        | none => act 0 (none, 0) (none, 0) (some false) (some .separator)
      | .emitAgain b => act 0 (none, .pos) (none, 0) (some b) (some .emitA)
      | .separator => act 0 (none, 0) (none, 0) (some true) (some (.run M.tm.q₀ true))
      | .run q b => if forward then
          let a := M.tm.tr q second (fun i => work (Fin.natAdd 1 (Fin.natAdd 1 i)))

/-- **The copy endpoint from a canonical seam** (landing: `Turing.Cfg.ofWords_copy_endpoint`, new
in `Build/Catalog.lean`, Part 1, after `copyTM_run_ofCfg`). If the destination word of the seam
`Cfg.ofWords q w` is empty, then the framed copy endpoint of `Turing.copyTM_run_ofCfg` started
there (state `q'`, the destination interval overwritten with `w src`, every other cell, head and
the output unchanged) is the seam `Cfg.ofWords q' (Function.update w dst (w src))`.

**Proof sketch.** Today's `Cfg.ext` computation in the proof of `Turing.copyTM_run`
(`Build/Catalog.lean:1382`): at the origin heads of `Cfg.ofWords` the destination interval is
`[0, |w src|)`, which `bufferTape (w src)` fills exactly, and outside it the blank destination
word agrees with `bufferTape (w src)`'s blanks; every other tape is untouched. -/
theorem Cfg.ofWords_copy_endpoint {k : ℕ} {S : Type*} {x : List Bool} (q q' : S)
    (w : Fin k → List Bool) (src dst : Fin k) (hdst : w dst = []) :
    ({ (Cfg.ofWords (input := x) q w) with
        state := some q'
        workTapes := fun j p =>
          if j = dst ∧ (Cfg.ofWords (input := x) q w).workTapePos j ≤ p ∧
              p < (Cfg.ofWords (input := x) q w).workTapePos j + ((w src).length : ℤ)
            then FinTM.bufferTape (w src) (p - (Cfg.ofWords (input := x) q w).workTapePos j)
          else (Cfg.ofWords (input := x) q w).workTapes j p } : Cfg k Bool S x) =
      Cfg.ofWords q' (Function.update w dst (w src)) := by
  apply Cfg.ext <;> simp [Cfg.ofWords]
  funext j q
  by_cases hj : j = dst
  · subst j
    simp only [Function.update_self, hdst, FinTM.bufferTape_nil, true_and]
    split_ifs with hq
    · rfl
    · by_cases h0 : 0 ≤ q
      · simp [FinTM.bufferTape, h0, List.getElem?_eq_none]
        omega
      · simp [FinTM.bufferTape, h0]
  · simp [hj]
