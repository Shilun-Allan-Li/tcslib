`Turing.MultiTapeTM.abs_workTapePos_runFrom_sub_le`, new in `TuringMachine/Simulation.lean`,

`audits/evidence/h2/StepBlockDraft.lean.txt:729`, whose proof is `CodeSimulator`'s private

each head by at most one cell.] One lemma serves MIG-1, where it replaces Catalog's private

H2, whose design note O9 moves it below `Build/StepBlock.lean` with MIG-1. Whichever of the two
PRs lands first introduces it; the other cites it.

**Proof sketch.** Telescope the displacement into its `t` one-step differences; the triangle
inequality and the one-step bound give `t`. -/

namespace Turing.FinTM

/-- **Space from time** (landing: `Turing.FinTM.ComputesInTime.spaceUsed_le`, new in
`TuringMachine/Simulation.lean`; statement and proof are Catalog's private `f2_space_of_time`,
moved). If `M` halts on `x` with output `y` within `T` steps, then at every time `t` its work
tapes have visited at most `M.k · (T + 1)` cells in all. [AB09, Definition 4.1, and the remark
opening the proof of Theorem 4.2: a machine running in time `T` visits at most `T + 1` cells of
each tape.]

**Proof sketch.** After the halt the configuration no longer changes, so every head position at
any time `t` already occurs at some time `u ≤ T`. Each tape's visited set is therefore contained
in the image of `{0, …, T}`, which has at most `T + 1` elements; sum over the `k` tapes. -/
-- @@verbatim Catalog Space --public --nodoc f2_space_of_time

/-- **The branch union's space** (landing: `Turing.FinTM.branchTM_spaceUsed`, new in
`TuringMachine/Simulation.lean` after `branchTM_computes`; statement verbatim from Catalog's
private `f2_branch_space`, whose proof moves with it). The branch union selecting `b` uses
exactly the selected machine's space plus one origin cell for each tape of the idle bank.

**Proof sketch.** Catalog's `f2_branch_space`: the branch union runs the selected machine on its
own bank (`leftCfg_run`, `rightCfg_run`) and never moves the other bank's heads, whose visited
sets stay the origin singletons; split the sum over the two banks with `Fin.sum_univ_add`, which
replaces the copied `f2_sum_add`. -/
-- @@verbatim Catalog Branch --public --nodoc --stmt f2_branch_space

/-- **Moved head lemma** (landing: `Turing.FinTM.rewind_heads`, moved verbatim from
`Build/Catalog.lean:10415`, name and statement unchanged; here inside `MIG1Gate`). The bounded
rewind reaches its destination with the input head at `1` within `pos + 2` steps, and every work
head stays put throughout. (Copied verbatim except that one line of 109 characters is wrapped.)

**Proof sketch.** One start step, then `Turing.FinTM.rewind_scan` for the run and
`Turing.FinTM.rewind_scan_heads` for the heads. -/
theorem rewind_heads {k : ℕ} {S : Type} {x : List Bool}
    (tm : MultiTapeTM k Bool S) (start scan : S) (dest : Option S)
    (hstart : ∀ inp work, tm.tr start inp work = controlAction .neg (some scan))
    (hscan : ∀ inp work, tm.tr scan inp work = match inp with
      | some _ => controlAction .neg (some scan)
      | none => controlAction .pos dest)
    (c : Cfg k Bool S x) (hs : c.state = some start) :
    ∃ r ≤ c.inputPos.val + 2,
      tm.runFrom c r = {c with state := dest, inputPos := 1} ∧
      ∀ u ≤ r, (tm.runFrom c u).workTapePos = c.workTapePos := by
  have hstep : tm.step c =
      {c with state := some scan, inputPos := moveInputPos c.inputPos .neg} := by
    simp only [MultiTapeTM.step, hs, hstart, controlAction_apply]
  have hp : (moveInputPos c.inputPos .neg).val ≤ x.length := by
    rw [moveInputPos_neg_val]
    have := c.inputPos.isLt
    omega
  refine ⟨1 + ((moveInputPos c.inputPos .neg).val + 1), ?_, ?_, ?_⟩
  · rw [moveInputPos_neg_val]; omega
  · rw [MultiTapeTM.runFrom_add]
    change tm.runFrom (tm.step c) _ = _
    rw [hstep, rewind_scan tm scan dest hscan _ rfl hp]
  · intro u hu
    cases u with
    | zero => rfl
    | succ u =>
      rw [MultiTapeTM.runFrom_succ_eq_step, hstep]
      exact rewind_scan_heads tm scan dest hscan (moveInputPos c.inputPos .neg).val _ rfl rfl hp u
        (by omega)

end MIG1Gate
