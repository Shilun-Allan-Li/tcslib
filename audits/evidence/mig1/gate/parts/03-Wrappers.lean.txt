/-- **The timed conditional** (landing: `Turing.FinTM.timedCondTM`, made public in place at
`Build/Wrappers.lean:479`, body unchanged; today also copied into Catalog as `f2_timedCondTM`).
Run the decider `D` with its output captured on the last tape, step back to read the verdict,
rewind the input, then run `M₁` or `M₂`, as the verdict says, from its genuine initial
configuration on its own untouched tape bank (W3). The branch tapes are idle while `D` runs. -/
-- @@verbatim Wrappers - --public --nodoc timedCondTM

/-- **The timed conditional's time** (landing: `Turing.FinTM.timedCondTM_computes`, new in
`Build/Wrappers.lean` before `computesFunInTime_cond`; statement verbatim from Catalog's private
`f2_cond_time`). If `D` computes the verdict `[p x]` within `T₀` and `M₁`, `M₂` compute `f₁`,
`f₂` within `T₁`, `T₂`, the timed conditional computes `if p x then f₁ x else f₂ x` within
`5·(T₀ n + max (T₁ n) (T₂ n) + 1)` steps; no monotonicity is needed, since the selected branch
runs on the same physical input.

**Proof sketch.** The body of today's `computesFunInTime_cond` (`Build/Wrappers.lean:711`),
which `f2_cond_time` copies: the captured decider run, the two-step verdict read and the input
rewind take at most `2·T₀ + 5` steps (the private `timed_start`; the input head has moved at
most once per decider step), and the selected branch then runs from its own initial
configuration (`timed_branch_run`, `branchTM_computes`). -/
-- @@verbatim Catalog Cond --public --nodoc --stmt f2_cond_time

/-- **The timed conditional's space** (landing: `Turing.FinTM.timedCondTM_spaceUsed`, new in
`Wrappers` after `timedCondTM_computes`; statement verbatim from Catalog's private
`f2_cond_space`, whose proof moves with its ledger). If `D` outputs `[b]` on `x` within `T`
steps, then at every time `t` the conditional's space is at most `D`'s space at time `T`, plus
the branch union's space at time `t`, plus two cells for the capture tape.

**Proof sketch.** Catalog's `f2_cond_space`: the three tape groups are disjoint. The decider
bank is touched only during the captured run, which halts by `T`; the branch bank only after
the dispatch, along the branch union's own trajectory; the capture head stays in `{0, 1}`. The
ledger `f2_cond_ledger` (moved with it) gives the head positions of the three groups at every
time. -/
-- @@verbatim Catalog Cond --public --nodoc --stmt f2_cond_space

/-- **The redirect correspondence** (landing: `Turing.FinTM.redirectTM_runFrom`, new in
`Wrappers` after `redirectTM_live`; the public field form of today's private `redirect_run`).
At every time `t`, the redirected machine's configuration on `x` has the source run's input
position, work tapes and work heads, an empty output, and the state that the source state and
the source's last emitted bit determine: the source state with that bit while the source is
live; after the source halts, halted if the bit is `haltOn`, and the stationary live loop
otherwise.

**Proof sketch.** Rewrite with the private `redirect_run`, which states that the run is the
image of the source run under the private `redirectCfg`; each conjunct is then a field of that
image, by `rfl`. -/
theorem redirectTM_runFrom (M : FinTM Bool) (haltOn : Bool) (x : List Bool) (t : ℕ) :
    ((redirectTM M haltOn).tm.runFrom ((redirectTM M haltOn).tm.initCfg x) t).state =
        (match (M.tm.runFrom (M.tm.initCfg x) t).state with
          | some s => some (.inl (s, (M.tm.runFrom (M.tm.initCfg x) t).output.getLast?))
          | none =>
            if (M.tm.runFrom (M.tm.initCfg x) t).output.getLast? = some haltOn then none
            else some (.inr ())) ∧
      ((redirectTM M haltOn).tm.runFrom ((redirectTM M haltOn).tm.initCfg x) t).inputPos =
        (M.tm.runFrom (M.tm.initCfg x) t).inputPos ∧
      ((redirectTM M haltOn).tm.runFrom ((redirectTM M haltOn).tm.initCfg x) t).workTapes =
        (M.tm.runFrom (M.tm.initCfg x) t).workTapes ∧
      ((redirectTM M haltOn).tm.runFrom ((redirectTM M haltOn).tm.initCfg x) t).workTapePos =
        (M.tm.runFrom (M.tm.initCfg x) t).workTapePos ∧
      ((redirectTM M haltOn).tm.runFrom ((redirectTM M haltOn).tm.initCfg x) t).output = [] := by
  sorry
