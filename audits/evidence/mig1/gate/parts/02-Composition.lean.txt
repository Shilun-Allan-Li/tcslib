/-- **The copy machine** (landing: `Turing.FinTM.idTM`, made public in place at
`TuringMachine/Composition.lean:88`, body unchanged). A machine with no work tapes and one state
that writes each input symbol to its output while moving right, and halts on the blank after
the input. [AB09, §1.2] -/
-- @@verbatim Composition - --public --nodoc idTM

/-- **The copy machine's time** (landing: `Turing.FinTM.idTM_computes`, new in `Composition`
before `computesFunInTime_id`). On every input `x` the copy machine halts within `|x| + 1`
steps with output `x`. [AB09, §1.2]

**Proof sketch.** The body of today's `computesFunInTime_id` (`Composition.lean:137`) up to its
final weakening: by the private run invariant `idTM_run`, after `|x|` steps the machine is live,
its input head is at cell `|x| + 1` and it has written `x`; there it reads the blank, and the
next step halts without writing. -/
theorem idTM_computes (x : List Bool) : idTM.ComputesInTime x x (x.length + 1) := by
  sorry

/-- **The constant machine** (landing: `Turing.FinTM.constTM`, made public in place at
`Composition.lean:168`, body unchanged). A machine with no work tapes whose `|w| + 1` states
form the emission chain of the fixed word `w`: it writes `w`, one symbol per step, ignoring its
input, and halts. [AB09, §1.2] -/
-- @@verbatim Composition - --public --nodoc constTM

/-- **The constant machine's time** (landing: `Turing.FinTM.constTM_computes`, new in
`Composition` before `computesFunInTime_const`; proved, the row's body moved). On every input
the constant machine halts within `|w| + 1` steps with output `w`. [AB09, §1.2]

**Proof sketch.** The emission chain writes `w` in `|w|` steps and halts on the next
(`Turing.FinTM.emit_halts`), appending to the initially empty output. -/
theorem constTM_computes (w x : List Bool) :
    (constTM w).ComputesInTime x w (w.length + 1) := by
  obtain ⟨hs, ho⟩ := emit_halts (constTM w).tm w id (fun _ _ _ => rfl)
    ((constTM w).tm.initCfg x) rfl
  exact ⟨_, hs, by simpa only [MultiTapeTM.initCfg, Cfg.init, List.nil_append] using ho, rfl⟩

/-- **The fixed-word comparator** (landing: `Turing.FinTM.ifEqTM`, made public in place at
`Composition.lean:189`, body unchanged). A machine with no work tapes that compares its input
with the fixed word `w₀` symbol by symbol and then runs the emission chain of `u` (on an exact
match followed by the blank) or of `v` (on the first mismatch, an early blank, or a symbol past
the end of `w₀`). [AB09, §1.2] -/
-- @@verbatim Composition - --public --nodoc ifEqTM

/-- **The comparator's time** (landing: `Turing.FinTM.ifEqTM_computes`, new in `Composition`
before `computesFunInTime_ifEq`). The comparator computes `w ↦ if w = w₀ then u else v` within
`(|w₀| + max |u| |v| + 3)·(n + 1)` steps, the constant of today's row made explicit.

**Proof sketch.** The body of today's `computesFunInTime_ifEq` (`Composition.lean:335`): the
private comparison run `ifEq_run` reaches the halt within `|w₀| + max |u| |v| + 3` steps with
the selected word as output, and that constant is at most its product with `n + 1`. -/
theorem ifEqTM_computes (w₀ u v : List Bool) :
    (ifEqTM w₀ u v).ComputesFunInTime (fun w => if w = w₀ then u else v)
      (fun n => (w₀.length + max u.length v.length + 3) * (n + 1)) := by
  sorry

/-- **The buffered composition computes the composite** (landing:
`Turing.FinTM.bufferedCompTM_computesFunInTime`, new in `Composition` before
`computesFunInTime_comp`; proved, the row's body moved). If `M₁` computes `f` within `T₁` and
`M₂` computes `g` within a monotone `T₂`, then `bufferedCompTM M₁ M₂` computes `g ∘ f` within
`2·(T₁ n + T₂ (T₁ n) + 1)` steps. [AB09, §1.2; the composition that [AB09] leaves to
high-level descriptions.]

**Proof sketch.** `bufferedCompTM_computesInTime` gives `T₁ |x| + |f x| + 2 + T₂ |f x|`; the
intermediate word is no longer than the time that produced it (`output_length_le`), and
monotonicity of `T₂` turns `T₂ |f x|` into `T₂ (T₁ |x|)`. -/
theorem bufferedCompTM_computesFunInTime {M₁ M₂ : FinTM Bool} {f g : List Bool → List Bool}
    {T₁ T₂ : ℕ → ℕ}
    (h₁ : M₁.ComputesFunInTime f T₁) (h₂ : M₂.ComputesFunInTime g T₂)
    (hT₂ : Monotone T₂) :
    (bufferedCompTM M₁ M₂).ComputesFunInTime (g ∘ f) fun n => 2 * (T₁ n + T₂ (T₁ n) + 1) := by
  intro x
  have hlen : (f x).length ≤ T₁ x.length := by
    have ho := ((computesInTime_iff _ _ _ _).mp (h₁ x)).2
    simpa only [ho] using M₁.tm.output_length_le x (T₁ x.length)
  have htime : T₂ (f x).length ≤ T₂ (T₁ x.length) := hT₂ hlen
  exact (bufferedCompTM_computesInTime M₁ M₂ (h₁ x) (h₂ (f x))).mono
    (by dsimp only; omega)

/-- **The buffered composition on the first machine's image** (landing:
`Turing.FinTM.bufferedCompTM_computesFunInTime_on_image`, new in `Composition` before
`exists_comp_on_image`; proved, the row's body moved). If `M` computes `f` within `T₁` and, for
every input `x`, `U` maps `f x` to `g x` within `T₂ |x|` steps, then `bufferedCompTM M U`
computes `g` within `2·T₁ n + T₂ n + 2` steps. No totality of `U` and no monotonicity is
assumed.

**Proof sketch.** As `bufferedCompTM_computesFunInTime`, with the second phase's budget
measured at the original input length. -/
theorem bufferedCompTM_computesFunInTime_on_image (M U : FinTM Bool)
    (f g : List Bool → List Bool) (T₁ T₂ : ℕ → ℕ) (hM : M.ComputesFunInTime f T₁)
    (hU : ∀ x, U.ComputesInTime (f x) (g x) (T₂ x.length)) :
    (bufferedCompTM M U).ComputesFunInTime g (fun n => 2 * T₁ n + T₂ n + 2) := by
  intro x
  have hlen : (f x).length ≤ T₁ x.length := by
    have ho := ((computesInTime_iff _ _ _ _).mp (hM x)).2
    simpa only [ho] using M.tm.output_length_le x (T₁ x.length)
  exact (bufferedCompTM_computesInTime M U (hM x) (hU x)).mono (by dsimp only; omega)

/-- **The buffered composition's halting relation** (landing:
`Turing.FinTM.bufferedCompTM_computes_iff`, new in `Composition` before `exists_comp_partial`;
proved, the row's body moved). For all machines `M₁`, `M₂` and words `x`, `w`: the buffered
composition halts on `x` with output `w` if and only if `M₁` halts on `x` with some output `y`
and `M₂` halts on `y` with output `w`. No totality or time hypotheses.

**Proof sketch.** The body of today's `exists_comp_partial` (`Composition.lean:474`): a
divergent first phase keeps every composite configuration live (`bufferedFirstCfg_run`);
otherwise `bufferedComp_start` reaches the second phase with `M₂`'s initial configuration on the
virtual input `y`, and `bufferedSecondCfg_run` tracks `M₂` step for step in both directions. -/
theorem bufferedCompTM_computes_iff (M₁ M₂ : FinTM Bool) (x w : List Bool) :
    (∃ t, (bufferedCompTM M₁ M₂).ComputesInTime x w t) ↔
      ∃ y : List Bool, (∃ t, M₁.ComputesInTime x y t) ∧ ∃ t, M₂.ComputesInTime y w t := by
  classical
  constructor
  · rintro ⟨t, ht⟩
    -- A divergent first component would keep every composite configuration live.
    have hh : ∃ s, (M₁.tm.runFrom (M₁.tm.initCfg x) s).state = none := by
      by_contra h
      have hr := bufferedFirstCfg_run M₁ M₂ (M₁.tm.initCfg x) t
        (fun s _ hs => h ⟨s, hs⟩)
      rw [← bufferedFirstCfg_init] at hr
      have hc := ((computesInTime_iff _ _ _ _).mp ht).1
      rw [hr] at hc
      simp only [bufferedFirstCfg, Option.some_ne_none] at hc
    obtain ⟨s, hs⟩ := hh
    let y := (M₁.tm.runFrom (M₁.tm.initCfg x) s).output
    have hy : M₁.ComputesInTime x y s := (computesInTime_iff _ _ _ _).mpr ⟨hs, rfl⟩
    obtain ⟨a, p, tapes, heads, _, ha⟩ := bufferedComp_start M₁ M₂ x y s hy
    -- Extend a completed run past the verified administrative prefix.
    have hc := (computesInTime_iff _ x w (a + t)).mp (ht.mono (by omega))
    rw [MultiTapeTM.runFrom_add, ha] at hc
    obtain ⟨b, _, hr⟩ := bufferedSecondCfg_run M₁ M₂ (M₂.tm.initCfg y) true
      (by simp [VirtualTag, MultiTapeTM.initCfg, Cfg.init]) p tapes heads t
    rw [hr] at hc
    refine ⟨y, ⟨s, hy⟩, t, (computesInTime_iff _ _ _ _).mpr ?_⟩
    exact ⟨by simpa only [bufferedSecondCfg, Option.map_eq_none_iff] using hc.1, hc.2⟩
  · rintro ⟨y, ⟨s, hs⟩, ⟨t, ht⟩⟩
    obtain ⟨a, p, tapes, heads, _, ha⟩ := bufferedComp_start M₁ M₂ x y s hs
    obtain ⟨b, _, hr⟩ := bufferedSecondCfg_run M₁ M₂ (M₂.tm.initCfg y) true
      (by simp [VirtualTag, MultiTapeTM.initCfg, Cfg.init]) p tapes heads t
    have hc := (computesInTime_iff _ _ _ _).mp ht
    refine ⟨a + t, (computesInTime_iff _ _ _ _).mpr ?_⟩
    rw [MultiTapeTM.runFrom_add, ha, hr]
    exact ⟨by simpa only [bufferedSecondCfg, Option.map_eq_none_iff] using hc.1, hc.2⟩

/-- **The untimed conditional's halting relation** (landing: `Turing.FinTM.condTM_computes_iff`,
new in `Composition` before `exists_cond`). If `D` computes `x ↦ [p x]`, then on every input
`x` the conditional halts with output `w` if and only if the branch `cond (p x) M₁ M₂` halts on
`x` with output `w`.

**Proof sketch.** The body of today's `exists_cond` (`Composition.lean:654`): the private
`condTM_start` reaches the selected branch's initial configuration, after which `rightCfg_run`
tracks the branch union step for step and `branchTM_computes` identifies the selected branch. -/
theorem condTM_computes_iff (D M₁ M₂ : FinTM Bool) (p : List Bool → Bool)
    (hD : D.Computes fun x => [p x]) (x w : List Bool) :
    (∃ t, (condTM D M₁ M₂).ComputesInTime x w t) ↔
      ∃ t, (cond (p x) M₁ M₂).ComputesInTime x w t := by
  sorry
