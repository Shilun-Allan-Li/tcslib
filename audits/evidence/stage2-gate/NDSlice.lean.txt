# Stage 2 statement gate: the deterministic slice of a nondeterministic run

**Gate evidence: an elaboration unit for two additions to existing core files.** Part A is
appended to `TCSlib/Complexity/TuringMachine/Nondeterministic.lean`, after
`Turing.NDTM.stepWith_eq_fixChoice_step` (`:163`); Part B to
`TCSlib/Complexity/TuringMachine/NondeterministicSpace.lean`, after
`Turing.MultiTapeTM.toNDTM_spaceUsedWith` (`:146`). Neither file is vendored. The cut changes no
declaration.

Stage 2's nondeterministic form (`WordRAM.exists_ndSimulation`) needs them before its fill: on
the stretches of a branch where the two transition functions agree, the branch is a run of the
deterministic slice `Turing.NDTM.fixChoice`, so the deterministic phases, and their framed
contracts, apply to it. They generalize `Turing.MultiTapeTM.toNDTM_runWith`
(`Nondeterministic.lean:251`) and `Turing.MultiTapeTM.toNDTM_spaceUsedWith`
(`NondeterministicSpace.lean:146`), where the two transition functions agree everywhere. This is the
nondeterministic contract variant that design §16 lists as later for MIG-0, at the level of runs.

## Main results (sorried at the statement gate)

* `Turing.NDTM.runWith_eq_fixChoice_runFrom`.
* `Turing.NDTM.spaceUsedWith_eq_fixChoice_spaceUsed`.

## References

* [AB09] S. Arora, B. Barak, *Computational Complexity: A Modern Approach*,
  Cambridge University Press, 2009. (§2.1.2: an NDTM has two transition functions, and a choice
  bit selects one at each step.)
-/

/-! ════════════════════════════════════════════════════════════════════════════════════════════
Part A · appended to `TCSlib/Complexity/TuringMachine/Nondeterministic.lean`. -/

namespace Turing.NDTM

variable {k : ℕ} {Symbol State : Type*} {input : List Symbol}

/-- **A branch that meets no real choice is a deterministic run.** If, at each of the first
`|w|` configurations of the run of the slice `tm.fixChoice b` from `cfg`, the machine is halted
or in a state at which its two transition functions agree, then the run of `tm` under the choice
word `w` is that deterministic run: `tm.runWith w cfg = (tm.fixChoice b).runFrom cfg |w|`.
[AB09, §2.1.2]

**Proof sketch.** Induction on `w`, generalizing `cfg`. For `w = b' :: w'`: if `cfg` is halted,
both sides fix it (`stepWith_of_halt`, `MultiTapeTM.step_of_halt`); otherwise its state `q`
satisfies `tm.tr false q = tm.tr true q` (the hypothesis at `j = 0`), so `tm.tr b' q = tm.tr b q`
and `stepWith b' cfg = (tm.fixChoice b).step cfg` (`stepWith_eq_fixChoice_step`). The hypothesis
shifts to the next configuration (`MultiTapeTM.runFrom_succ_eq_step`), and the induction
hypothesis finishes with `runWith_cons`. -/
theorem runWith_eq_fixChoice_runFrom (tm : NDTM k Symbol State) (b : Bool) (w : List Bool)
    (cfg : Cfg k Symbol State input)
    (hagree : ∀ j < w.length, ∀ q : State, ((tm.fixChoice b).runFrom cfg j).state = some q →
      tm.tr false q = tm.tr true q) :
    tm.runWith w cfg = (tm.fixChoice b).runFrom cfg w.length := by
  sorry

end Turing.NDTM

Part B · appended to `TCSlib/Complexity/TuringMachine/NondeterministicSpace.lean`. -/

namespace Turing.NDTM

variable {k : ℕ} {Symbol State : Type*} {input : List Symbol}

/-- **The space of such a branch is the deterministic space.** Under the hypothesis of
`runWith_eq_fixChoice_runFrom`, the branch of `tm` under `w` visits exactly the cells that the
slice `tm.fixChoice b` visits in `|w|` steps: `spaceUsedWith w cfg` is
`(tm.fixChoice b).spaceUsed cfg |w|`. [AB09, Definition 4.1, nondeterministic clause]

**Proof sketch.** `visitedWith w cfg i` is the image of the runs under the prefixes `w.take j`,
`j ≤ |w|`; each prefix satisfies the hypothesis, so by `runWith_eq_fixChoice_runFrom` its run is
`(tm.fixChoice b).runFrom cfg j` (`List.length_take`). That is the image defining
`MultiTapeTM.visitedByTapeHead cfg |w| i`; sum over the tapes (`spaceUsed`). -/
theorem spaceUsedWith_eq_fixChoice_spaceUsed (tm : NDTM k Symbol State) (b : Bool)
    (w : List Bool) (cfg : Cfg k Symbol State input)
    (hagree : ∀ j < w.length, ∀ q : State, ((tm.fixChoice b).runFrom cfg j).state = some q →
      tm.tr false q = tm.tr true q) :
    tm.spaceUsedWith w cfg = (tm.fixChoice b).spaceUsed cfg w.length := by
  sorry

end Turing.NDTM
