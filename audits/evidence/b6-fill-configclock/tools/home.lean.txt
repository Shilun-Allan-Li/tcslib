/-- **The clock writer** (Recommended shape; you may restate it). From a layout `fs` of `m`
fields at the head of tape `0` and a blank tape `1`, write `c` passes over `fs`'s field cells as
one contiguous word of `e`s at the head of tape `1`, of width `c` times the total field length
(the separators are skipped, so the passes join), and return both heads, silently, within a
constant times the layout's length plus one. Generic in the alphabet, like
`Turing.exists_fieldsCopyTM`.

**Proof sketch.** Per field and pass: the mapped copy `Turing.copyMapTM_run_ofCfg` (source tape
`0`, every cell to `e`) writes the field's length in `e`s at the head of tape `1`;
`Turing.skipTM_run_ofCfg` moves tape `0` to the next field and tape `1` past the written word;
a one-cell left move on tape `1` puts its head on the word's right delimiter, where the next copy
continues it. After a pass, `Turing.skipBackTM_run_ofCfg` returns tape `0` to the first field;
after the last, it returns tape `1` to the word's start. Phases by R2 seams or one phase host. -/
private lemma exists_clockWriterTM {Γ : Type} (e : Γ) (m c : ℕ) :
    ∃ (P : Type) (_ : Fintype P) (_ : DecidableEq P) (R : MultiTapeTM 2 Γ P) (entry exit : P)
      (C : ℕ), entry ≠ exit ∧
      ∀ {x : List Γ} (fs : List (List Γ)), fs.length = m → (∀ f ∈ fs, f ≠ []) →
      ∀ d : Cfg 2 Γ P x, d.state = some entry → RecordAt d 0 fs → (∀ p, d.workTapes 1 p = none) →
        ∃ t ≤ C * ((joinFields fs).length + 1),
          (∀ u < t, (R.runFrom d u).state ≠ some exit) ∧
          (∀ u ≤ t, ∀ j : Fin 2, |(R.runFrom d u).workTapePos j - d.workTapePos j| ≤
            ((C * ((joinFields fs).length + 1) : ℕ) : ℤ)) ∧
          (∀ u ≤ t, (R.runFrom d u).output = d.output) ∧
          R.runFrom d t =
            { d with
              state := some exit
              workTapes := fun j q =>
                if j = 1 ∧ d.workTapePos 1 ≤ q ∧
                    q < d.workTapePos 1 + ((c * (fs.map List.length).sum : ℕ) : ℤ)
                  then some e
                else d.workTapes j q } := by
  sorry
