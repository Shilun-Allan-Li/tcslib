**Each current sorried theorem: truth assessment.** Each entry below gives a mathematical argument for the literal statement, not a claim that its Lean proof has been filled.

1. **`ndWriterTM_run_block` — true.** For each `u < m`, the designated head is at its original position plus u, that cell is still its original nonblank cell, and trivial control cannot stop, so the next step writes bit u and advances. The next cell at time m is blank, so step `m + 1` silently enters `done` without advancing. Induction gives the stated overwrite interval and leaves every other field unchanged, including arbitrary pre-existing output and off-block tape contents. No earlier state is `done`, and at `m = 0` precisely the single dispatch step remains.

2. **`exists_inputWindowCopyTM` — true.** Use the existing decrement loop on tape j and a one-step body that copies a native input symbol to dst and advances both heads, or escapes without advancing when it reads the right blank. Exclude j from the body's tape bank and use the existing embedding/permutation machinery, so no additional scratch tape is required and the untouched tape/head frame is available. If the counter exhausts after d copies, the entire counter overhead is at most `4d + 2|w| + 2`; if the input ends after y symbols with `|y| < d`, at most `|y| + 1` successful decrements and body steps occur, giving the same stated shape with one uniform C. Counter operations preserve width and return their head, and merging the loop's live exits into the public `done` needs at most a fixed extra cost, so empty/padded-zero counters and starting on the right blank are covered.

3. **`exists_replayCanonizer` — true.** The effective scheme already provides a total finite-machine canonizer into the fixed ND serialization. From that canonical finite list, a primitive recursive transformation retains the state-count and initial-state header, selects the appropriate one of the two tables for each three-tape read tuple, and re-emits the action in the correct three-tape field order. Blank and `false` choice reads select the same old action, while the added work action never writes and always moves right. Compile this transformation and compose it with the canonizer; the arbitrary length-dependent time function can absorb the composition, including the canonizer output length.

4. **`exists_ndInterpreterCore` — true.** For a fixed code, header processing and replay-table installation cost a constant depending on that code plus `O(|bits t| + 1)`, while copying and rewinding the window costs `O(min(t, |x|) + |bits t| + 1)`. Interpret the replay machine with the preloaded stream as its mirrored third tape, using the H1/H2 loop generalized to an arbitrary represented live start and to its early-escape time; each represented step then costs a code-dependent constant and the fused counter is amortized. If the branch first halts at r, or r is t when it has not halted earlier, one construction has cost bounded by a code-dependent multiple of `r + min(t, |x|) + |bits t| + 1`, which gives both required bounds at the same exit time. Decode the exact output summary into distinct live verdict states and enter neither earlier; do not traverse or clear the unused tail of s, and at `t = 0` select rejection because the simulated initial configuration is live.

5. **`FinNDTM.exists_exhaustiveDecider` — true.** A fixed machine can enumerate all words of lengths `L = 0, 1, ...`, replay each for L steps, and stop at the first length at which every replay has halted, which is at most any T satisfying the hypothesis. At that length, halting absorption and truncation identify acceptance with acceptance at T, without computing T or a bound on it. Capture the simulated emissions on work tape, retain the exact singleton-output test, reset the bounded touched work region, and restore the native input head between trials; the actual machine emits only the final Boolean answer. Each replay and reset costs at most a fixed-machine polynomial in `L + 1` (the advertised linear ledger is also feasible), no full-input scan is needed, and the sum over at most T levels fits `C * 2^(C * (T + 1))` after enlarging a constant depending only on N.

**Quantitative checks.**

For the window copier write `d = value(w)` and `q = |y|`. There are two ledgers, not one sum of two worst-case width charges:

- If `q = d`, the whole-run counter theorem already includes underflow: counter cost is at most `4d + 2|w| + 2`. Adding d one-step copies and fixed entry/exit work gives `C(q + 1) + 2|w|` for one uniform C.
- If `q < d`, the input-end test is an additional body round. Put `r = q + 1 ≤ d`; the prefix counter cost is at most `4r + 2|w|`, and r body steps plus fixed entry/exit work fit the same form.

This explains why M2 is a local sketch correction and why the statement need not change. The left and right delimiter convention is exactly `bufferTape w` at offsets `-1` through `|w|`; high zero padding is allowed. The destination is a buffer for R once R starts it blank and rewinds after copying; the copier is intentionally not required to erase unrelated destination cells.

For R, a witness construction may satisfy the stronger schematic bound

\[
T_R \le B_\alpha\bigl(r+\min(t,|x|)+|\operatorname{bits}(t)|+1\bigr),
\]

where r is the earlier of t and the branch's first halting time. Since `r ≤ t`, `min(t,|x|) ≤ t`, and binary width is at most `t + 1`, enlarging the code-dependent constant gives the full-budget clause. If a prefix at `t' ≤ t` is halted, then `r ≤ t'` and `min(t,|x|) ≤ |x|`, giving the prefix clause for that same T. Thus the two clauses do not require different runs or different exit witnesses. Arbitrary preprocessing of the fixed code is absorbed because every parenthesis contains the constant addend 1.

For UN, expansion, writing, and rewind are `O(t + 1)`; the window contributes `O(min(t,|x|) + |bits t| + 1) = O(t + 1)`. R adds a code-dependent multiple of `t + 1`. Its start configuration can be established using fresh/cleared work banks, a rewound native header position, and the guessed tape; startup touches the header and bounded regions, not the entire suffix x. Capture intermediate emissions if needed and emit one final answer when converting live verdicts to halts. A fixed number of embeddings and dispatches changes only the per-code constant.

For D's revised mid-rung inequality, put `F = f(n + 1)`, `N = n + 1 ≥ 1`, and `b = |bits (g n)|`. Expanding the claimed cost gives

\[
C_\alpha\bigl(C_1(c_0F+1)+N+b+1\bigr)
=C_\alpha C_1c_0F+C_\alpha N+C_\alpha(C_1+1)+C_\alpha b.
\]

With `A* = Cα(C₁c₀ + C₁ + 2) + 1`, the coefficient of F is at most A*, and

\[
C_\alpha N+C_\alpha(C_1+1)
\le C_\alpha(C_1+2)N
\le A^*N.
\]

Hence the displayed bound is at most `A*(F + N) + Cα b`, as claimed. The quantified domination hypothesis absorbs every fixed multiple of `F + N`; because `g n ≥ n` and g grows without bound, binary width is `o(g n)`. These facts allow the cost to fit the remaining simulation share, not just the whole nominal cap. The fixed physical slowdown of a step-clock implementation is another fixed factor to include in that share. The genuine branch's simulated length `C₁(c₀F + 1)` is itself eventually at most `g n`, so its choice prefix can be padded to the guessed length `g n`.

The rest of the P3.3 chain remains intact: repeat each fixed code infinitely often, retain the seed `ℓ₀ = 2`, and use the capped locator with its independent amortized ledger. At a stage bottom `a = ℓᵢ + 1`, `T* = (f a + a + 1)²` eventually exceeds the fixed linear transfer budget `C₁(c₀ f a + 1)`. At the top, `n = 2^((T*)²)` and `g n ≥ n`; the ratio of `C_BF * 2^(C_BF(T* + 1))` to n tends to zero, so it fits any fixed positive remaining share eventually. No comparison of `T*` with `g a` is needed. Backward acceptance uses the unbounded normal-form transfer followed by truncation at N's own all-branch halting budget, exactly as the carried ruling requires.

For E's advertised linear-per-replay ledger,

\[
\sum_{L=0}^{T}2^L(L+1)=T2^{T+1}+1
\le (T+1)2^{T+1}\le 2^{2(T+1)}.
\]

A multiplicative implementation constant is absorbed by choosing the final C large enough. Work reset must cover the bounded visited interval even if it contains blank holes; scanning until the first blank would not suffice. Likewise, preserving the singleton-output predicate requires capture, not simply discarding emissions. `embedSilentTM` provides capture onto a work tape, so the cited route can satisfy this requirement.

Finally, let E's constant be `C_E` and UN's per-code constant be `Cα`. Substituting `h = Cα(t + 1)` into E yields

\[
C_E2^{C_E(C_\alpha(t+1)+1)}.
\]

Since `Cα(t + 1) + 1 ≤ (Cα + 1)(t + 1)` and `C_E ≤ C_E(Cα + 1)`, monotonicity gives the target with `C = C_E(Cα + 1)`. This calculation needs no division or unstated positivity assumption; it is valid even for zero-valued constants as an arithmetic implication.
