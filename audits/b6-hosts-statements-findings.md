For the step clock, put `m=length(w)` and let `d` be its binary value. The successful decrement-prefix bound is `counterOverhead(w,r) ≤ 4r+2m`. Thus `r` source actions and, if needed, one terminal stop dispatch cost at most `5r+2m+1`, within the promised `5r+2m+2`. For timeout, use the **whole** decrement-plus-underflow bound `counterOverhead(w,d+1) ≤ 4d+2m+2`; adding `d` source actions gives precisely `5d+2m+2`. Do not add a second `2m` term to that whole bound. The input head and output remain at source time `v` during each debit and move atomically to source time `v+1` with the source action. No extra dispatch is required for the clock itself; the window runner's separate timeout-to-exhausted dispatch explains its `+3`.

As a finite arithmetic cross-check, I checked every word value of widths 0 through 9 and all its successful debit prefixes: 175,274 prefix checks, plus their final-underflow inequalities, passed. I also checked header lengths 1 through 7, payload lengths 0 through 7, every legal input position, and all three moves: 308 position checks passed. These are independent finite arithmetic checks, not Lean executions or substitutes for the general arguments.

For the configuration clock, write `n=length(x)` and use the packet's record length

`L = k*(2*s+1) + posWidth(n) + k + 4`.

Its four-factor count is

`configBound = (card(Q)+1)*(n+2)*3^(k*(2*s+1))*(2*s+1)^k`.

The proved exponential majorant has exponent

`E = card(Q) + posWidth(n) + 3*k*(2*s+1) ≤ card(Q)+3L`.

Also `L+n+1 ≤ 2^(L+1)`. In Route A, if the loop coefficient is `C₀`, then its sufficient physical budget is at most `C₀*2^(card(Q)+4L+2)`. Choose a fixed integer `a` with `C₀≤2^a` and a fixed multiplier `c_M` such that `c_M*L ≥ a+card(Q)+4L+3`; this is possible uniformly since `L≥4`. The all-ones width `c_M*L` then gives more than the required budget. In Route B, width `E+1` gives value `2^(E+1)-1 ≥ configBound+1`; `E≥1` already suffices for this inequality. The multiplicative per-round input-scan cost is exponential in `L`, so both routes, including cleanup, fit `C*2^(C*(L+1))` for one enlarged constant depending only on `M` and `upd`. The output tag is finite control and does not require storing the emitted word; the core count need not acquire an output-word factor.

For the addend-free universal bound, the qualifying coded run gives `s≥1`, including on `x=[]`. Consequently

`ℓ = 2*length(bits s)+2*length(α)+4 ≤ 2s+2*length(α)+4 ≤ (2*length(α)+6)*s`.

For the displayed ledger `B_α+s+ℓ+2`, one may take `C=B_α+2*length(α)+9`; any fixed extra coefficient for header-processing space can likewise be absorbed. This does not assume that canonization has space linear in code length: its cost is an arbitrary constant once `α` is fixed. The weakening probe uses the same `SU` and `C`, followed by `C*s ≤ C*(s+logSpace(length(x))+1)`.
