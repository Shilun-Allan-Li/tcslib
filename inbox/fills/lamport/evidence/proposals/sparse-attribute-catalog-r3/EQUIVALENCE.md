For an immutable enumeration E of actual Lean Names and each requested spelling s in the wanted set W, the old ordered catalog array is [n in E | home(n) is TCSlib and n.toString=s]. The sparse array adds the predicate n.toString in W. The added predicate is true for every element with n.toString=s, so the arrays are equal, including order, multiplicity and all collisions. Every later lookup spelling belongs to W by the exact two-field parse. No injectivity of Name.toString is assumed. The original request row list remains unchanged, so duplicate worklist entries retain their validation/log/count behavior. Malformed rows fail earlier but never become accepted. No trimming, prefix guessing, name reconstruction, selection or census filtering is introduced. Native performance remains empirical. The pure moduleNames-cache proposal is the preferred next benchmark; this sparse alternative is preserved only as a source-only proposal.
