# All-occurrence enumeration and symbolic no-dependence

Worker `/root/evaluation` proved `GateOccurrences.lean`. The row enumerations are arbitrary
lists of Boolean assignments. Each gate also has an explicit assignment permutation,
so the contracts cover the seed's point-and-permute ordering.

`selectedPosition_eq_some_iff` proves that every argument with vertex `u` and actual bit
`true` is selected when the gate arguments are distinct. `mem_rowSlots_iff` and
`mem_occurrences_iff` characterize every gate/row/argument triple. `exhaustive` covers every
actual assignment, using completeness of the enumeration and the inverse permutation.
`per_row_unique` uses argument distinctness. `rowSlots_nodup` and `occurrences_nodup`
also certify that the enumeration itself never repeats a slot.

For duplicate-free assignment rows and a fan-in-two circuit, `length_occurrences_le`
bounds the entire list by four times the gate count. It counts uses across all gates,
not merely the gate whose output is currently being switched. `padded` provides exactly
`q+1` optional positions, with exact lookup, some-membership, and none-tail readers.
`padded_occurrences_some_iff` combines the count with a supplied `4G ≤ q+1` budget.

The final five label lemmas concern symbolic `(vertex,bit)` pairs. A selected input wire
precedes the selected gate's output. Earlier hybrid plaintexts have bit false; subsequent
plaintexts have later vertices. Sink outputs cannot be read by the selected gate, covering
both entries in every decoding pair. Every active `(v,false)` label differs from `(u,true)`.
These facts do not assert unequal key values; label collisions remain permitted.
