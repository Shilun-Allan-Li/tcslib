# Scratch provenance

This snapshot preserves every top-level worker scratch file, the header-test control,
and the complete unaccepted SR-02 prototype. These are historical development material,
not additional source changes. The accepted source is exclusively `src/` and the patches.
Clones, package trees, issued inputs (preserved separately), and generated delivery
payloads are excluded. All raw verification logs stay in their original evidence roots.
The inventory gives original absolute paths and SHA256 values. Later delivery-only
generators are also preserved in `worker/generators/`.
