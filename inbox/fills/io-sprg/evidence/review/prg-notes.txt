Final API:
- P.PRGChal N is G.Idx N times the Boolean output vector, with explicit cardinal and
  Fin equivalence. prgEnc is exactly G.challengeStr N x.1 x.2 (no modulus is added to
  the existing Boolean assumption challenge).
- P.PRGAdvice pi N is a record of buckets, public LPN matrix and uniform public
  vectors, all at kappaOfN N. PRGAdvice.Data and prodEquiv expose the record as a
  product; prgAdviceCard/prgAdviceEquiv explicitly compose approved Fin function /
  matrix / product maps. Fintype is transported from Fin through that supplied map.
  An explicit all-zero Inhabited instance exists at every N, including N=0.
- encPRGAdvice starts with (pi(kappaOfN N)).enc, then unary N, the bucket code, the
  LPN matrix code, and the uniform public vectors as a kappa-by-n modular matrix.
  All fields are retained; no random value is generated by the encoder or reduction.
  The arbitrary prime schedule is read as public typed data; no prime is computed.
- prgAdviceDataBound is idxBound+seedBound+mBound+nBound+ellBound+var+1.
  prgAdviceBound is the explicit PolyExpr 100*(var+1)*dataBound^3. The named
  encPRGAdvice_length_le statement quantifies all pi,N and all advice values.
- prgPre guards N=n(kappaOfN N). On-image, cast(congrArg G.Idx h) transports the
  challenge index; finCongr(congrArg G.outLen h).symm transports the output after
  the existing P.outputIndex map. This reuses the foreign m_eq cast reader wrapper
  instead of unfolding P.m. It calls P.challengeStr with the supplied index,
  fixed buckets/matrix, P.publicSeed uniform false, and the supplied output.
  Off-image it returns []. There is no G.eval, sampling, or Classical.choose.
- prgRed is exactly A.runAtL (kappaOfN N) (prgPre ...) with r.take(A.coinLen(...)).
  The coin polynomial in every realiser is A.coins.subst .var, as specified.
- PRGRealizable and its proved iff reader quantify every A and every advice family,
  followed by existence of a NUPPT satisfying the shared RealizesOn. No variant of
  the predicate is defined. Its docstring discloses layout-length-only constraints.
- prg_hop first chooses one entire advice family, then quantifies EVERY realiser B,
  then EVERY kappa. Its LHS is advantage(chainGame A true kappa kappa pi(kappa),
  chainGame A false kappa kappa pi(kappa)); RHS is G.adv B (n kappa). No assumption
  or additional input restriction was silently added.

Bound check (mathematical sanity, not a Lean proof):
The four nested pair separators and fields yield length
2*N+2*kappa+12+2*bucketCodeLength+2*matrixCodeLength+uniformMatrixCodeLength.
The first two data lengths are bounded using idxBound; the last is at most
(kappa+1)*seedBound(kappa). Since kappaOfN N<=N and syntactic polynomial evaluation
is monotone, the stated cubic bound is a generous uniform majorant.
