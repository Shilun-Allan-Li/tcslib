## First exact obligation

Compression requires identifying the index generated by `dlHashIdx`. After its own
`dlHashIdx_eq` and the published NUPPT/layout readers, the missing behavior is:

```lean
-- V : List Bool → Prop; G : ExpGroupGen V
-- n : ℕ; hn : G.n₀ ≤ n; r : G.gen.Coins n
pairFstD
  (expGenFun G
    (NUPPT.layout (List.replicate n true) [] [] (List.ofFn r))) =
  G.gen.runAt n [] r
```

This is needed to apply `G.valid` and `G.wellFormed` at `n ≥ G.n₀`.
`expGenFun_poly` asserts efficiency, not output behavior. The published
`expGen_runAt` describes `expGen G`; applying it to the raw call requires an
unpublished representation equation for `expGen` (or unfolding that foreign
definition). That definitional bridge is prohibited by Rule 10.

## Requested provider-side equations

Publish these in `TCSlib/Cryptography/Candidates/DiscreteLog.lean`, or provide
equivalent raw-layout behavior readers. The declarations below are a request,
not compiled proof output. They reproduce the provider bodies and can be proved
there by `rfl`; the provider is frozen for this worker.

```lean

    (z : List Bool) :

      if G.n₀ ≤ (NUPPT.inParam z).length then
        pairEncode
          (G.gen.output (NUPPT.layout (NUPPT.inParam z) [] [] (NUPPT.inCoins z))) []
      else pairEncode dlDefaultIndex [] := rfl

theorem expSampleRaw_eq (z : List Bool) :
    expSampleRaw z =
      natToList (dlW (NUPPT.inArg z))
        ((sampleBelowL (dlM (NUPPT.inArg z)) (Nat.size (dlM (NUPPT.inArg z)))
          (NUPPT.inParam z).length (NUPPT.inParam z).length
          (NUPPT.inCoins z)).getD 0) := rfl
```

The sampler request covers the second gap: `dlHashGenFun_eq` directly calls
`expSampleRaw`. `polyTimeComputable_expSampleRaw` supplies no output semantics;
`expSampler_runAt` concerns a different, bundled term, and no published equation
connects it to the raw function. A semantic equation is needed to show sampled
`w < m`, to show `y = g^w` is a unit, and to connect the key law to
`statClose_sampleBelowL`.

No theorem falsehood is claimed. These requests remove the first two identified
interface obstacles; later steps have not been certified complete. Merely
authorizing a helper to unfold these definitions would change the binding Rule
10 discipline, so no such helper was added.
