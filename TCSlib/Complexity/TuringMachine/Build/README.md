# The machine-construction library

Complexity proofs routinely assert that some Turing machine computes a function within a time or
space bound. This directory provides verified machine components with exact costs, and the
combinators that compose them, so that such a machine is assembled from proved parts and its
bound follows from theirs. Everything is stated over the multi-tape model of
`TuringMachine/Deterministic` and `TuringMachine/Finite` (a read-only input tape, `k` work tapes
and an append-only output), and most components are generic in the work-tape alphabet.

Import `TCSlib.Complexity.TuringMachine` for the whole library, or a single module below.

## Specifying a machine

Three forms, from the least to the most structured:

- **Function level.** `Turing.FinTM.ComputesFunInTime`: a finite machine computes `f` within a
  time bound from its initial configuration. The primitive catalog is stated this way, and
  `TuringMachine/Composition` composes such statements. A function-level statement says nothing
  about the configuration a run ends in, so constructions with several phases use the next two
  forms.
- **Framed runs** (the `_run_ofCfg` theorems): from an arbitrary configuration meeting stated
  conditions, the machine reaches a stated endpoint at exactly a stated time and not earlier,
  with the trajectory of every head given and everything else unchanged.
- **Contracts** (`Turing.Contract`, in `Contract/`): a framed run packaged as a structure, with a
  precondition, an entry state, an exact time, an endpoint, a set of exits reached first at the
  endpoint, and head envelopes. Time bounds and per-tape space follow from it. Contracts compose
  by `trans`, `seq`, `branch`, `inPhase`, `embed`, `mapState` and `lockstep`, and iterate as
  rounds (`Turing.Round.iterate`). New components are stated as contracts.

Conventions:

- **Seams.** Between phases, the canonical configuration is `Turing.Cfg.ofWords q w`: control
  `q`, the input head at `1`, work tape `i` holding the word `w i` from cell `0` with its head
  there, and an empty output. `Turing.seamCompTM` joins two machines with one dispatch step, so
  the composite takes `T₁ + 1 + T₂`.
- **Costs are exact.** Times are equalities with a no-earlier-exit clause; space is counted per
  tape (`visitedByTapeHead`, `spaceUsedByTape`) or derived from the head envelopes.
- **Definitions come with their lemmas.** Every definition here is published with the lemmas that
  read it: equations, an `_iff` characterization, or field equations (often generated by
  `simps`, without `@[simp]`). Other files read a definition only through these lemmas, never by
  unfolding it, so that its implementation can change without breaking its users.
- **Alphabets.** A `Bool` machine runs on a richer alphabet through the symbol lift
  (`TuringMachine/SymbolLift`, `Contract/Lift`), with time and space unchanged.

## Components

### Primitives: single routines with exact costs

| Module | Provides |
| --- | --- |
| `Convention` | The seam `Cfg.ofWords` with its field equations, and the word functions the primitives are stated against (`incFixed`, `splitAtLastTrue`, `solveSplit`). |
| `Primitives` | The catalog of timed string functions, as function-level statements (`Turing.FinTM.computesFunInTime_*`); several arguments travel through the self-delimiting pairing `Turing.pairEncode`. |
| `WordTests` | Two linear-time one-bit tests, in the form the timed conditional takes: equality with a fixed word (`FinTM.computesFunInTime_decideEq`) and the all-`true` word (`FinTM.computesFunInTime_allTrue`), with the increment's output facts `incFixed_ne_some_nil` and `incFixed_getD_eq_nil_iff`. |
| `Catalog` | Tape routines with exact time and space: `transferTM`, `copyTM`, `clearTM`, `compareTM`, `incrementTM`; the blank-separated field layout (`joinFields`, `fieldsTape`, `fieldOffset`); the seek family `skipTM`, `skipBackTM`, `seekEndTM`, `seekStartTM`; the lockstep walk `walkTM`; the mapped sweeps `copyMapTM` and `transferMapTM`; the finite-state sweep `scanTM`; the space bounds of the primitive catalog. |
| `Scan` | Writers of a fixed word (`writeConstTM`, `writeAdvTM`) and sweeps of the native input (`inputCopyTM`, `inputFoldTM`). |
| `Rewind`, `InputRewind` | Return a work-tape head (`rewindTM`) or the input head (`inputRewindTM`) to the start of its word, at an exact time. |
| `InputLength` | Write `Nat.bits` of the input length on a tape (`exists_inputLengthTM`). |
| `InputWindow` | Copy the window `x.take t` of the input onto a tape (`exists_inputWindowCopyTM`). |
| `InputCall` | Compute a function of the native input at a clean seam (`FinTM.exists_inputCallTM`); move the input head to a position held in binary (`exists_inputSeekTM`). |

### Combinators: larger machines from smaller ones

| Module | Provides |
| --- | --- |
| `Seam` | Sequencing: `seamCompTM` (`seamCompTM_run`, `seamCompTM_run_ofCfg`, `seamCompTM_firstReturn`), two exits (`seamCompTM₂`), and the release adapter `seamReleaseTM` for a call that returns to its own entry state. The **phase host** `phaseHostTM`: a finite family of phase machines with a redirect table, read through `phaseHostTM_run`, `phaseHostTM_run_le`, `phaseHostTM_q₀`, `phaseHostTM_tr_of_red_none` and `phaseHostTM_tr_of_red_some`. |
| `Embed` | Run an `m`-tape machine on any `m` chosen work tapes of a `k`-tape host at unchanged cost, the other tapes untouched: `embedSilentTM`, `embedEmitTM`, and the returning forms `embedSilentRetTM`, `embedEmitRetTM`. |
| `Wrappers` | Output isolation: capture a machine's output onto a tape (`capture_run`), redirect its halt (`FinTM.redirectTM`), and the timed branch (`FinTM.computesFunInTime_cond`). |
| `Loop` | Bounded loops with tape-resident round state (`loop_run`, `FinTM.exists_loopCfgTM`, `FinTM.exists_loopTM`, `FinTM.exists_emitLoopTM`), and the clean calls that run a function-level machine on a tape-resident argument and install its result (`FinTM.exists_installCallTM`) or emit it (`FinTM.exists_emitCallTM`). |
| `CounterLoop` | Loops whose number of rounds is a binary counter on a tape (`counterLoopTM`, `counterLoopTMVia`), the decrement row, and the pattern expansion `expandTM`. |
| `EmitIterEmbed`, `EmitIterBody` | Iterate a step function, emitting a chunk of each iterate (`FinTM.exists_emitIterTM`). |

### The zone layer (Hennie–Stearns)

The data and machine rows of the Hennie–Stearns simulation of `k` work tapes by two [AB09, §1.7].
Each simulated tape is a track laid out in zones of size `2^i` on both sides of a fixed home
cell; the simulated heads stay at home, and the data moves past them.

| Module | Provides |
| --- | --- |
| `Zone` | The per-track zone contents and their pure operations: the shifts, the cascade and its mirror, the scanned index, the rebalance, and the extension by one level. No machines. |
| `ZoneTape` | `k` tracks on one work tape over the alphabet `ZoneSym k` (`zonedTape`). |
| `ZoneRebalance` | The machine rows, as contracts: the rebalance from the home in either direction (`exists_zoneRebalanceTM`) and the extension by one level (`exists_zoneExtendTM`). |

The zone layer has no consumer yet. It is built for the two-tape simulation with logarithmic
overhead, which gives the deterministic time hierarchy at its book strength [AB09, Theorem 3.1].

## Extending the library

- State a new component as a `Turing.Contract`, or as a framed `_run_ofCfg` theorem, with exact
  time and head envelopes.
- Publish every new definition with the lemmas that read it (equations, `_iff`, field equations
  by `simps` without `@[simp]`).
- Build from published components, and cite them rather than re-proving them. When a
  construction proved privately in one file is needed by a second, promote it into a module here
  instead of copying it.
- Each module's header gives its status and main results. This file describes roles only and
  carries no status.
