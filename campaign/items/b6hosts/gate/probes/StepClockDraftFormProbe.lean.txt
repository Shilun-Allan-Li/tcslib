/-! ### Relabelling preserves space -/

/-- **State relabelling preserves every head trajectory.** For any machine `tm` and any state
equivalence `e`, head `i` of the relabelled machine visits, in its first `t` steps from its
initial configuration, exactly the cells that head `i` of `tm` visits. This is the space
clause that the coding step `Turing.exists_codeTM` does not state. [AB09, §1.4: the coding
step of the normal form]

**Proof sketch.** The relabelled run is the original run with its states renamed
(`Turing.MultiTapeTM.relabelState_runFrom_init`), and renaming changes no head position. -/
theorem MultiTapeTM.relabelState_visitedByTapeHead {k : ℕ} {Symbol : Type*}
    {State State' : Type*} (tm : MultiTapeTM k Symbol State) (e : State ≃ State')
    (input : List Symbol) (t : ℕ) (i : Fin k) :
    (tm.relabelState e).visitedByTapeHead ((tm.relabelState e).initCfg input) t i =
      tm.visitedByTapeHead (tm.initCfg input) t i := by
  simp only [MultiTapeTM.visitedByTapeHead, MultiTapeTM.relabelState_runFrom_init,
    Cfg.mapState]

/-- **State relabelling preserves space at every time.** The relabelled machine uses exactly
the space of the original up to every time `t`. [AB09, §1.4]

**Proof sketch.** Sum `Turing.MultiTapeTM.relabelState_visitedByTapeHead` over the tapes. -/
theorem MultiTapeTM.relabelState_spaceUsed {k : ℕ} {Symbol : Type*} {State State' : Type*}
    (tm : MultiTapeTM k Symbol State) (e : State ≃ State') (input : List Symbol) (t : ℕ) :
    (tm.relabelState e).spaceUsed ((tm.relabelState e).initCfg input) t =
      tm.spaceUsed (tm.initCfg input) t := by
  simp only [MultiTapeTM.spaceUsed, MultiTapeTM.spaceUsedByTape,
    MultiTapeTM.relabelState_visitedByTapeHead]

end Turing

/-- **A coded run visits at least one cell.** Every run of a coded machine, at every time,
has visited at least one work cell: its one work head starts somewhere. So every qualifying
budget `s` of `Complexity.space_universal` is positive, which is what lets its addend-free bound
`C · s` absorb a ruler of the header's length (the RD-3 statement gate's row-1 calculation).

**Proof sketch.** The visited set of tape `0` contains the head's initial position, and it
is one summand of the space. -/
theorem CodeTM.one_le_spaceUsed (M : CodeTM) (x : List Bool) (t : ℕ) :
    1 ≤ M.toFinTM.tm.spaceUsed (M.toFinTM.tm.initCfg x) t := by
  let i₀ : Fin M.toFinTM.k := ⟨0, by simp⟩
  have hne : (M.toFinTM.tm.visitedByTapeHead (M.toFinTM.tm.initCfg x) t i₀).Nonempty :=
    ⟨_, Finset.mem_image.mpr ⟨0, Finset.mem_range.mpr (Nat.succ_pos t), rfl⟩⟩
  exact (Finset.card_pos.mpr hne).trans_le
    (M.toFinTM.tm.spaceUsedByTape_le_spaceUsed _ t i₀)

/-- **The space-faithful coding step.** Every one-work-tape binary machine `M` is equivalent
to a coded machine `M'` that halts with the same outputs at the same times
(`Turing.exists_codeTM`'s clause) **and uses the same space at every time**. This is the space
clause of the coding step named by `Complexity.space_hierarchy`'s sketch. [AB09, §1.4]

**Proof sketch.** `State` carries `Fintype`/`DecidableEq` instances and is inhabited by `q₀`,
so `Fintype.equivFinOfCardEq` gives an equivalence with `Fin (|Q| - 1 + 1)`. Relabel the states
along it (`Turing.MultiTapeTM.relabelState`): by `Turing.MultiTapeTM.relabelState_runFrom_init`
the relabelled run is the original run with renamed states, so halting and outputs correspond
at every time, and the space clause is `Turing.MultiTapeTM.relabelState_spaceUsed`. The
tape-count cast uses `hk : M.k = 1`, eliminated after destructuring the bundle. -/
theorem exists_codeTM_spaceUsed (M : FinTM Bool) (hk : M.k = 1) :
    ∃ M' : CodeTM,
      (∀ (x output : List Bool) (t : ℕ),
        M'.toFinTM.ComputesInTime x output t ↔ M.ComputesInTime x output t) ∧
      ∀ (x : List Bool) (t : ℕ),
        M'.toFinTM.tm.spaceUsed (M'.toFinTM.tm.initCfg x) t =
          M.tm.spaceUsed (M.tm.initCfg x) t := by
  classical
  rcases M with @⟨k, Q, hQ, dQ, tm⟩
  dsimp only at hk
  subst k
  letI : Fintype Q := hQ
  letI : DecidableEq Q := dQ
  have hcard : Fintype.card Q = (Fintype.card Q - 1) + 1 := by
    have : 0 < Fintype.card Q := Fintype.card_pos_iff.mpr ⟨tm.q₀⟩
    omega
  let e := Fintype.equivFinOfCardEq hcard
  refine ⟨⟨Fintype.card Q - 1, tm.relabelState e⟩, ?_, ?_⟩
  · intro x output t
    simp only [CodeTM.toFinTM, FinTM.ComputesInTime, MultiTapeTM.ComputesInTimeAndSpace,
      MultiTapeTM.relabelState_runFrom_init, Cfg.mapState, Option.map_eq_none_iff]
    constructor
    · rintro ⟨s, hhalt, hout, -⟩
      exact ⟨_, hhalt, hout, rfl⟩
    · rintro ⟨s, hhalt, hout, -⟩
      exact ⟨_, hhalt, hout, rfl⟩
  · intro x t
    exact MultiTapeTM.relabelState_spaceUsed tm e x t

end Turing

/-! ### Space at every time, and deciding through the alphabet reduction -/

/-- **The halt-time space bound holds at every time.** If `M` has halted on `x` with output
`w` by time `t`, having visited at most `s` cells by then, it has visited at most `s` cells
by **every** time `t'`: before `t` by monotonicity, after `t` because the halted
configuration is frozen. This is the all-times bridge named by `Complexity.space_hierarchy`'s
sketch (`Turing.FinTM.DecidesInSpace` bounds the space at the halt; the normal form needs every
time). [AB09, §4.1, Definition 4.1]

**Proof sketch.** Every head position visited by time `t'` was visited by time `t`: a time
`u ≤ t` is in range, and at a time `u > t` the configuration is the one at `t`
(`Turing.MultiTapeTM.runFrom_of_halt`). So each visited set at `t'` is contained in the one at
`t`. -/
theorem ComputesInTime.spaceUsed_le_of_halt {Symbol : Type} {M : FinTM Symbol}
    {x w : List Symbol} {t s : ℕ} (h : M.ComputesInTime x w t)
    (hs : M.tm.spaceUsed (M.tm.initCfg x) t ≤ s) :
    ∀ t', M.tm.spaceUsed (M.tm.initCfg x) t' ≤ s := by
  have hhalt := ((computesInTime_iff M x w t).mp h).1
  have key : ∀ t' i, M.tm.visitedByTapeHead (M.tm.initCfg x) t' i ⊆
      M.tm.visitedByTapeHead (M.tm.initCfg x) t i := by
    intro t' i z hz
    simp only [MultiTapeTM.visitedByTapeHead, Finset.mem_image, Finset.mem_range] at hz ⊢
    obtain ⟨u, hu, rfl⟩ := hz
    by_cases hut : u ≤ t
    · exact ⟨u, by omega, rfl⟩
    · refine ⟨t, by omega, ?_⟩
      rw [show u = t + (u - t) by omega, MultiTapeTM.runFrom_add,
        MultiTapeTM.runFrom_of_halt _ hhalt]
  intro t'
  refine le_trans ?_ hs
  exact Finset.sum_le_sum fun i _ => Finset.card_le_card (key t' i)

/-- **A space-bounded computation in the normal form's hypotheses.** If `M` computes `f`
within space `s`, then it computes `f` within the length-dependent time
`n ↦ configBound M n (s n)`, and its space is at most `s |x|` at every time on every `x`.
These are exactly the hypotheses `hM` and `hS` of
`Turing.FinTM.one_work_tape_binary_spaceUsed`. [AB09, §4.1.1]

**Proof sketch.** Time: `Turing.FinTM.ComputesInTime.of_spaceUsed_le`. Space at every time:
`Turing.FinTM.ComputesInTime.spaceUsed_le_of_halt`. -/
theorem ComputesInSpace.computesFunInTime_and_forall_spaceUsed_le {M : FinTM Bool}
    {f : List Bool → List Bool} {s : ℕ → ℕ} (h : M.ComputesInSpace f s) :
    M.ComputesFunInTime f (fun n => M.configBound n (s n)) ∧
      ∀ (x : List Bool) (t : ℕ), M.tm.spaceUsed (M.tm.initCfg x) t ≤ s x.length := by
  refine ⟨fun x => ?_, fun x t => ?_⟩
  · obtain ⟨t, ht, hsp⟩ := h x
    exact ht.of_spaceUsed_le hsp
  · obtain ⟨t₀, ht, hsp⟩ := h x
    exact ht.spaceUsed_le_of_halt hsp t

/-- **Deciding through the alphabet reduction.** Let `D` be a machine over a finite alphabet
`Γ` with an embedding `e` of `Bool`. Suppose that on every `Bool` input `x` it halts with the
one-symbol output `[x ∈ L]` (embedded), and that on **every** input over `Γ` (foreign symbols
included) and at every time it has visited at most `S |x|` cells. Then some binary machine
decides `L` within space `c · (S n + 1)`. No time bound on `D` is assumed: the reduction's
time function is the maximum of the first halting times over the finitely many inputs of each
length, which need not be computable (the RD-3 gate's check 7). [AB09, §1.3.1, Claim 1.5, with
the space clause of `Turing.FinTM.alphabet_reduction_spaceUsed`]

**Proof sketch.** Choose a halting time `g x` for each `Bool` input, and let `T n` be the
maximum of `g` over the inputs of length `n` (a supremum over `Fin n → Bool`). Then `D`
computes the indicator via `e` within `T`, by monotonicity of halted runs. Apply
`Turing.FinTM.alphabet_reduction_spaceUsed`; its machine decides `L` at the halting time
`c · (T n + 1)`, within `c · (S n + 1)` cells. -/
theorem decidesInSpace_of_alphabetReduction {Γ : Type} [Fintype Γ] [DecidableEq Γ]
    (e : Bool ↪ Γ) (D : FinTM Γ) (L : Language Bool) (S : ℕ → ℕ)
    (hD : ∀ x : List Bool, ∃ t, D.ComputesInTime (x.map e)
      ([MultiTapeTM.indicator (L : Set (List Bool)) x].map e) t)
    (hS : ∀ (x : List Γ) (t : ℕ), D.tm.spaceUsed (D.tm.initCfg x) t ≤ S x.length) :
    ∃ (c : ℕ) (M : FinTM Bool), M.DecidesInSpace L fun n => c * (S n + 1) := by
  classical
  choose g hg using hD
  let T : ℕ → ℕ := fun n => (Finset.univ : Finset (Fin n → Bool)).sup fun v => g (List.ofFn v)
  have hM : D.ComputesFunInTimeVia e
      (fun x => [MultiTapeTM.indicator (L : Set (List Bool)) x]) T := by
    intro x
    have hle := Finset.le_sup (f := fun v : Fin x.length → Bool => g (List.ofFn v))
      (Finset.mem_univ x.get)
    dsimp only at hle
    rw [List.ofFn_get] at hle
    exact (hg x).mono hle
  obtain ⟨c, M', -, hM', hS'⟩ := alphabet_reduction_spaceUsed e D _ T S hM hS
  exact ⟨c, M', fun x => ⟨c * (T x.length + 1), hM' x, hS' x _⟩⟩

end FinTM

end Turing

/-! ### The output summary's `Fin 3` code and its tag update -/

/-- **The output summary's `Fin 3` code** (`machine-library-design.md` §12.8a, decision O4):
`empty ↦ 0`, `accept ↦ 1`, `dead ↦ 2`. It is the record tag of the windowed runner's instance
for `Complexity.space_hierarchy` (`Turing.summaryTag`), and the summary code of the
configuration-graph vertex records below. [AB09, §4.1.1] -/
def outSummaryCode : OutSummary → Fin 3
  | .empty => 0
  | .accept => 1
  | .dead => 2

/-- The `Fin 3` code is injective.

**Proof sketch.** Compare the three cases. -/
theorem outSummaryCode_injective : Function.Injective outSummaryCode := by
  intro a b h
  cases a <;> cases b <;> simp_all [outSummaryCode]

/-- **A representative output word for each tag**: `[]` for `0`, `[true]` for `1` and
`[false]` for `2`. -/
def summaryWord (τ : Fin 3) : List Bool :=
  if τ = 0 then [] else if τ = 1 then [true] else [false]

/-- Each representative word has the tag it represents.

**Proof sketch.** Evaluate the three cases. -/
theorem outSummaryCode_summaryWord (τ : Fin 3) :
    outSummaryCode (outSummary (summaryWord τ)) = τ := by
  fin_cases τ <;> rfl

/-- **The summary tag update**: the tag after emitting `b` from an output with tag `τ`,
computed on the representative word. It is the windowed runner's tag update `upd` for the
output summary. -/
def summaryTag (τ : Fin 3) (b : Option Bool) : Fin 3 :=
  outSummaryCode (outSummary (summaryWord τ ++ b.toList))

/-- A silent step leaves the tag unchanged (the record step's `hupd` hypothesis).

**Proof sketch.** Appending nothing keeps the representative word. -/
theorem summaryTag_none (τ : Fin 3) : summaryTag τ none = τ := by
  simpa [summaryTag] using outSummaryCode_summaryWord τ

/-- **The tag of an appended output is the tag update** of the tag of the output: the
compatibility hypothesis `hσ` of the windowed run for `σ = outSummaryCode ∘ outSummary`.
[AB09, §4.1.1]

**Proof sketch.** The representative and the actual word have equal summaries, and summaries
are append-compatible (`Turing.outSummary_append_congr`). -/
theorem summaryTag_append (u : List Bool) (b : Option Bool) :
    outSummaryCode (outSummary (u ++ b.toList)) =
      summaryTag (outSummaryCode (outSummary u)) b :=
  (congrArg outSummaryCode (outSummary_append_congr
    (outSummaryCode_injective (outSummaryCode_summaryWord _)) b.toList)).symm

/-- The tag `1` (`accept`) recognizes exactly the output `[true]`, not merely an output that
begins with `true` (the RD-3 gate's check 5).

**Proof sketch.** Injectivity of the code and `Turing.outSummary_eq_accept_iff`. -/
theorem outSummaryCode_eq_one_iff (u : List Bool) :
    outSummaryCode (outSummary u) = 1 ↔ u = [true] := by
  rw [← outSummary_eq_accept_iff]
  constructor
  · intro h
    exact outSummaryCode_injective (h.trans rfl)
  · intro h
    rw [h]
    rfl

/-- The empty output has tag `0`. -/
theorem outSummaryCode_nil : outSummaryCode (outSummary []) = 0 := rfl

end Turing

/-!
# Machine-construction library: the step-clocked runner (host H3's clock)

A **step clock** runs a body machine under a binary countdown that ticks once per physical body
step. It exits at `finish` when the body stops (halts, or reaches a designated stop state), and
at `timeout` when the countdown is exhausted first. It is the clock of the windowed runner H3
(`machine-library-design.md` §14) and of the nondeterministic time hierarchy's diagonalizer
(C1, which cites the `Bool` instance `Turing.exists_stepClockTM`). Unlike the round counter
`Turing.counterLoopTMVia`, which restarts its body at a fixed anchor every round, it counts
physical steps, so the body's state survives from step to step.

**Status: statement gate pending** (`audits/b6-hosts-statements-pack.md`). The layout
definitions are real; the contract `Turing.exists_stepClockTMVia` is sorried with its proof
sketch, and its `Bool` instance is proved from it.

## Design

* **Layout.** The body is on the first `k` tapes and the counter on the last
  (`Turing.clockCfg`). The counter digits are embedded along `e : Bool ↪ Γ`, as in
  `Turing.counterLoopTMVia`, so the clock runs over any alphabet with a digit embedding; the
  windowed runner runs over the record alphabet.
* **Exact endpoints.** At both exits the body part is the body's configuration at the stopping
  or clock time, and the counter tape differs from its start only on the counter word's cells,
  which hold some word of the same width (`Turing.wordPatch`).
* **Frames.** At every host time up to the exit, the body part (tapes, heads, input head,
  output) is the body's configuration at some body time, and the counter head stays within
  `[cp - 1, cp + |w|]`. This bounds the host's space by the body's plus `|w| + 2`, and carries
  silence and envelopes through the clock.
* The contract is an existential module; the named witness comes at fill time.

## Main definitions

* `Turing.clockCfg` — the host layout: body tapes first, the counter tape last.
* `Turing.wordPatch` — a tape with a word written over an interval.
* `Turing.Cfg.Stopped` — a body configuration that is halted or in a designated stop state.

## Main results

* `Turing.exists_stepClockTMVia` — the step clock over any alphabet (sorried).
* `Turing.exists_stepClockTM` — its `Bool` instance, in C1's draft form (proved from it).

## References

* [AB09] S. Arora, B. Barak, *Computational Complexity: A Modern Approach*,
  Cambridge University Press, 2009. (§3.2, proof of Theorem 3.2: the diagonalizer runs the
  simulation for a bounded number of steps; §4.1.3, proof of Theorem 4.8.)
-/

namespace Turing

/-- **The step clock's layout**: the body configuration `c` on the first `k` tapes, the
counter tape `ct` with its head at `cp` as the last tape, the host control `q`, and the body's
input head and output. -/
def clockCfg {k : ℕ} {Γ S Q : Type} {x : List Γ} (q : Option Q) (c : Cfg k Γ S x)
    (ct : ℤ → Option Γ) (cp : ℤ) : Cfg (k + 1) Γ Q x :=
  ⟨q, c.inputPos, Fin.lastCases ct c.workTapes, Fin.lastCases cp c.workTapePos, c.output⟩

/-- **A tape with a word patched in**: the cells `cp, …, cp + |u| - 1` hold `u`, every other
cell is `ct`'s. -/
def wordPatch {Γ : Type*} (ct : ℤ → Option Γ) (cp : ℤ) (u : List Γ) : ℤ → Option Γ :=
  fun q => if cp ≤ q ∧ q < cp + (u.length : ℤ) then FinTM.bufferTape u (q - cp) else ct q

/-- **A stopped body configuration**: halted, or live in a designated stop state. -/
def Cfg.Stopped {k : ℕ} {Γ S : Type*} {x : List Γ} (stopAt : S → Bool) (c : Cfg k Γ S x) :
    Prop :=
  c.state = none ∨ ∃ s, c.state = some s ∧ stopAt s = true

/-- **H3's clock, the step-clocked runner** (joint statement with C1, whose draft
`exists_stepClockTM` is the instance `Γ = Bool`, `e = refl`; generalized to any alphabet with
a digit embedding, as the windowed runner runs over the record alphabet). For a body `M` with
designated stop states, there is a host on one more tape, with an injection `inj` of the body
states and two exit families `finish` and `timeout` carrying the body state, all distinct, as
follows. Start it at `inj q` with the body configuration `c` (live, at `q`) and a delimited
counter word `w` of value `d` (digits embedded by `e`) on the last tape.
* If the body first stops (halts, or reaches a stop state) at time `τ ≤ d`, the host reaches
  `finish` with the body's configuration at `τ`, within `5τ + 2|w| + 2` steps.
* If the body has not stopped by time `d`, the host reaches `timeout` with the body's
  configuration at time `d`, within `5d + 2|w| + 2` steps.

In both cases no exit occurs earlier; the counter tape differs from its start only on the
counter word's own cells, which hold some word of the same width, and its head is back at
`cp`; and at every host time up to the exit the host's body tapes, body heads, input head and
output are the body's at some body time no later than `τ` (or `d`), while the counter head
stays in `[cp - 1, cp + |w|]`. So the host's work space is the body's plus `|w| + 2`, and it
emits exactly what the body emits. This clock counts **physical body steps**, unlike the round
counter `Turing.counterLoopTMVia`, so a body's state survives from step to step. [AB09, §3.2,
proof of Theorem 3.2; §4.1.3, Theorem 4.8]

**Proof sketch.** Fuse one decrement with every body transition: from `inj s`, if `s` is a stop
state go to `finish`; otherwise run the lifted decrement on the counter tape
(`Turing.decrementTM_run_succ_ofCfg` under `Turing.MultiTapeTM.liftSymbols`), whose success
anchor performs one body transition (the body tapes embedded by R1 along `Fin.castSucc`, as in
`Turing.counterLoopTMVia`) and returns to `inj` of the successor, or to `finish none` when the
transition halts the body; the decrement's underflow anchor is `timeout`. The decrement costs
sum to at most `4τ + 2|w|` (`Turing.counterOverhead_le_of_le`), plus the final underflow sweep
`2|w| + 2` in the timeout case (`Turing.counterOverhead_le`). The round induction is that of
`Turing.counterLoopTMVia_run_done` with one body step per round and an unrestricted body
state. A decrement moves only the counter head and writes only the counter tape, and a body
transition is the body's own step on the body tapes, which gives the frame clause. -/
theorem exists_stepClockTMVia {k : ℕ} {Γ S : Type} [Fintype S] [DecidableEq S]
    [DecidableEq Γ] (e : Bool ↪ Γ) (M : MultiTapeTM k Γ S) (stopAt : S → Bool) :
    ∃ (Q : Type) (_ : Fintype Q) (_ : DecidableEq Q) (H : MultiTapeTM (k + 1) Γ Q)
      (inj : S → Q) (finish timeout : Option S → Q),
      Function.Injective finish ∧ Function.Injective timeout ∧
      (∀ a b, finish a ≠ timeout b) ∧ (∀ s r, inj s ≠ finish r ∧ inj s ≠ timeout r) ∧

/-- **C1's step clock** (the `Bool` instance of `Turing.exists_stepClockTMVia`). This is the
statement of C1's draft `exists_stepClockTM` (`audits/evidence/c1/C1HostsDraft.lean.txt`, §4)
word for word: over `Bool`, with the counter tape's final contents left existential and without
the frame clause. It is proved here from the joint statement, so C1 may cite either.
[AB09, §3.2, proof of Theorem 3.2]

**Proof sketch.** Instantiate the joint statement at `e := Function.Embedding.refl Bool`
(`w.map e = w`) and forget the extra clauses. -/
theorem exists_stepClockTM {k : ℕ} {S : Type} [Fintype S] [DecidableEq S]
    (M : MultiTapeTM k Bool S) (stopAt : S → Bool) :
    ∃ (Q : Type) (_ : Fintype Q) (_ : DecidableEq Q) (H : MultiTapeTM (k + 1) Bool Q)
      (inj : S → Q) (finish timeout : Option S → Q),
      ∀ {x : List Bool} (c : Cfg k Bool S x) (q : S), c.state = some q →
      ∀ (w : List Bool) (ct : ℤ → Option Bool) (cp : ℤ),
        (∀ p : ℤ, -1 ≤ p → p ≤ (w.length : ℤ) → ct (cp + p) = FinTM.bufferTape w p) →
        let d := Nat.ofDigits 2 (w.map Bool.toNat)
        let stopped : Cfg k Bool S x → Prop := fun e =>
          e.state = none ∨ ∃ s, e.state = some s ∧ stopAt s = true
        (∀ τ ≤ d, stopped (M.runFrom c τ) → (∀ u < τ, ¬stopped (M.runFrom c u)) →
          ∃ T ≤ 5 * τ + 2 * w.length + 2, ∃ ct' : ℤ → Option Bool,
            H.runFrom (clockCfg (some (inj q)) c ct cp) T =
              clockCfg (some (finish (M.runFrom c τ).state)) (M.runFrom c τ) ct' cp ∧
            ∀ u < T, ∀ r, (H.runFrom (clockCfg (some (inj q)) c ct cp) u).state ≠
              some (finish r) ∧
              (H.runFrom (clockCfg (some (inj q)) c ct cp) u).state ≠ some (timeout r)) ∧
        ((∀ u ≤ d, ¬stopped (M.runFrom c u)) →
          ∃ T ≤ 5 * d + 2 * w.length + 2, ∃ ct' : ℤ → Option Bool,
            H.runFrom (clockCfg (some (inj q)) c ct cp) T =
              clockCfg (some (timeout (M.runFrom c d).state)) (M.runFrom c d) ct' cp ∧
            ∀ u < T, ∀ r, (H.runFrom (clockCfg (some (inj q)) c ct cp) u).state ≠
              some (finish r) ∧
              (H.runFrom (clockCfg (some (inj q)) c ct cp) u).state ≠ some (timeout r)) := by
  obtain ⟨Q, hQ, dQ, H, inj, finish, timeout, -, -, -, -, h⟩ :=
    exists_stepClockTMVia (Function.Embedding.refl Bool) M stopAt
  refine ⟨Q, hQ, dQ, H, inj, finish, timeout, ?_⟩
  intro x c q hq w ct cp hw
  have hw' : ∀ p : ℤ, -1 ≤ p → p ≤ (w.length : ℤ) →
      ct (cp + p) = FinTM.bufferTape (w.map (Function.Embedding.refl Bool)) p := by
    have hid : w.map (Function.Embedding.refl Bool) = w := by
      rw [Function.Embedding.coe_refl, List.map_id]
    rw [hid]
    exact hw
  obtain ⟨hfin, hto⟩ := h c q hq w ct cp hw'
  refine ⟨fun τ hτ hs hmin => ?_, fun hns => ?_⟩
  · obtain ⟨T, hT, w', -, hrun, hcut, -⟩ := hfin τ hτ hs hmin
    exact ⟨T, hT, _, hrun, hcut⟩
  · obtain ⟨T, hT, w', -, hrun, hcut, -⟩ := hto hns
    exact ⟨T, hT, _, hrun, hcut⟩

end Turing

/-! ### The specification -/

/-- **The three exits of a windowed run**: the simulated machine halted inside the window;
its next step leaves the window; or the clock ran out. -/
inductive WindowExit where
  /-- the simulated machine has halted -/
  | halted
  /-- the next simulated step leaves the window -/
  | left
  /-- the clock is exhausted -/
  | exhausted
deriving DecidableEq

open Classical in
/-- **The semantic windowed run** (host H3's specification). `windowRun M s upd N c τ` runs
at most `N` rounds of the fixed machine `M` from `c` with tag `τ`. Each round first tests
the configuration: if it is halted, the run stops with exit `halted`; otherwise, if the next
configuration lies in the radius-`s` window, it steps and updates the tag by `upd` with the
step's emission; otherwise it stops with exit `left`, unchanged. After `N` rounds without a
stop it reports `exhausted` with the configuration reached. A halt on the `N`-th transition is
therefore recognized only with an `N + 1`-st round: the strict surplus of the RD-3 gate's
check 4. [AB09, §4.1.3, proof of Theorem 4.8: the diagonalizer simulates within the space
bound and stops by a configuration count] -/
noncomputable def windowRun {k : ℕ} {Q T : Type} {x : List Bool} (M : MultiTapeTM k Bool Q)
    (s : ℕ) (upd : T → Option Bool → T) :
    ℕ → Cfg k Bool Q x → T → WindowExit × Cfg k Bool Q x × T
  | 0, c, τ => (.exhausted, c, τ)
  | N + 1, c, τ =>
    if c.state = none then (.halted, c, τ)
    else if (M.step c).InWindow s then
      windowRun M s upd N (M.step c) (upd τ (M.outputSymbol c))
    else (.left, c, τ)

/-- **A run inside the window halts in the windowed run.** Let the tag `σ` of output words be
compatible with `upd` (`σ (u ++ b) = upd (σ u) b`). If `M` from `c` has halted by time `t`,
every configuration up to `t` lies in the window, and `t < N`, then `N` rounds from `c` with
tag `σ c.output` stop with exit `halted`, at the configuration of time `t`, with its output's
tag. This is the direction `Complexity.space_hierarchy`'s contradiction uses. [AB09,
Theorem 4.8, proof]

**Proof sketch.** Induct on `N`. A halted `c` stops at once, and the run from it is frozen. A
live `c` has `t ≥ 1`, its successor is in the window (time `1`), and the induction hypothesis
applies to the successor at `t - 1`; the tag update is `σ` of the appended output
(`Turing.MultiTapeTM.step_output`). -/
theorem windowRun_halted_of_run {k : ℕ} {Q T : Type} {x : List Bool}
    (M : MultiTapeTM k Bool Q) (s : ℕ) (upd : T → Option Bool → T) (σ : List Bool → T)
    (hσ : ∀ u b, σ (u ++ b.toList) = upd (σ u) b) :
    ∀ (N t : ℕ) (c : Cfg k Bool Q x), t < N → (M.runFrom c t).state = none →
      (∀ u ≤ t, (M.runFrom c u).InWindow s) →
      windowRun M s upd N c (σ c.output) =
        (.halted, M.runFrom c t, σ (M.runFrom c t).output) := by
  intro N
  induction N with
  | zero => intro t c ht; omega
  | succ N ih =>
    intro t c ht hhalt hwin
    by_cases hc : c.state = none
    · rw [MultiTapeTM.runFrom_of_halt c hc]
      simp only [windowRun, if_pos hc]
    · cases t with
      | zero => exact absurd (by simpa using hhalt) hc
      | succ t =>
        have hrun : M.runFrom c (t + 1) = M.runFrom (M.step c) t :=
          MultiTapeTM.runFrom_succ_eq_step
        have hstep : (M.step c).InWindow s := by
          simpa [MultiTapeTM.runFrom_succ_eq_step] using hwin 1 (by omega)
        have key := ih t (M.step c) (by omega) (by rw [← hrun]; exact hhalt)
          (fun u hu => by
            have h := hwin (u + 1) (by omega)
            rwa [MultiTapeTM.runFrom_succ_eq_step] at h)
        rw [hrun]
        simp only [windowRun, if_neg hc, if_pos hstep]
        rw [← hσ, ← MultiTapeTM.step_output]
        exact key

/-- **What a windowed run reports** (the full characterization of the three exits). From a
windowed `c`, `N` rounds stop at the configuration of some time `r ≤ N` of `M`'s run, with
every configuration up to `r` in the window and every one before `r` live, and:
* exit `halted` means `r < N` and the configuration at `r` is halted;
* exit `left` means `r < N`, the configuration at `r` is live, and the one at `r + 1` is
  outside the window;
* exit `exhausted` means `r = N`.

**Proof sketch.** Induct on `N`, following the three branches of a round; a step shifts every
time index by one (`Turing.MultiTapeTM.runFrom_succ_eq_step`). -/
theorem windowRun_spec {k : ℕ} {Q T : Type} {x : List Bool}
    (M : MultiTapeTM k Bool Q) (s : ℕ) (upd : T → Option Bool → T) :
    ∀ (N : ℕ) (c : Cfg k Bool Q x) (τ : T), c.InWindow s →
      ∃ r ≤ N, (windowRun M s upd N c τ).2.1 = M.runFrom c r ∧
        (∀ u ≤ r, (M.runFrom c u).InWindow s) ∧
        (∀ u < r, (M.runFrom c u).state ≠ none) ∧
        ((windowRun M s upd N c τ).1 = .halted → r < N ∧ (M.runFrom c r).state = none) ∧
        ((windowRun M s upd N c τ).1 = .left → r < N ∧ (M.runFrom c r).state ≠ none ∧
          ¬(M.runFrom c (r + 1)).InWindow s) ∧
        ((windowRun M s upd N c τ).1 = .exhausted → r = N) := by
  intro N
  induction N with
  | zero =>
    intro c τ hc
    refine ⟨0, le_rfl, by simp [windowRun], ?_, ?_, ?_, ?_, ?_⟩
    · intro u hu
      rw [show u = 0 by omega, MultiTapeTM.runFrom_zero]
      exact hc
    · intro u hu
      omega
    · simp [windowRun]
    · simp [windowRun]
    · intro _
      rfl
  | succ N ih =>
    intro c τ hc
    by_cases hst : c.state = none
    · refine ⟨0, by omega, by simp [windowRun, hst], ?_, ?_, ?_, ?_, ?_⟩
      · intro u hu
        rw [show u = 0 by omega, MultiTapeTM.runFrom_zero]
        exact hc
      · intro u hu
        omega
      · intro _
        exact ⟨by omega, by simpa using hst⟩
      · simp [windowRun, hst]
      · simp [windowRun, hst]
    · by_cases hw : (M.step c).InWindow s
      · have heq : windowRun M s upd (N + 1) c τ =
            windowRun M s upd N (M.step c) (upd τ (M.outputSymbol c)) := by
          simp only [windowRun, if_neg hst, if_pos hw]
        obtain ⟨r, hr, h1, h2, h3, h4, h5, h6⟩ := ih (M.step c) (upd τ (M.outputSymbol c)) hw
        rw [heq]
        refine ⟨r + 1, by omega, ?_, ?_, ?_, ?_, ?_, ?_⟩
        · rw [h1, MultiTapeTM.runFrom_succ_eq_step]
        · intro u hu
          cases u with
          | zero => simpa using hc
          | succ u =>
            rw [MultiTapeTM.runFrom_succ_eq_step]
            exact h2 u (by omega)
        · intro u hu
          cases u with
          | zero => simpa using hst
          | succ u =>
            rw [MultiTapeTM.runFrom_succ_eq_step]
            exact h3 u (by omega)
        · intro h
          obtain ⟨a, b⟩ := h4 h
          exact ⟨by omega, by rw [MultiTapeTM.runFrom_succ_eq_step]; exact b⟩
        · intro h
          obtain ⟨a, b, e⟩ := h5 h
          refine ⟨by omega, by rw [MultiTapeTM.runFrom_succ_eq_step]; exact b, ?_⟩
          rw [MultiTapeTM.runFrom_succ_eq_step]
          exact e

          have := h6 h
          omega

          rw [show u = 0 by omega, MultiTapeTM.runFrom_zero]
          exact hc
        · intro u hu
          omega
        · simp [windowRun, hst, hw]
        · intro _
          refine ⟨by omega, by simpa using hst, ?_⟩
          simpa [MultiTapeTM.runFrom_succ_eq_step] using hw

/-- **The tag tracks the output.** If the tag `σ` of output words is compatible with `upd`
and the run starts with the tag of `c`'s output, the reported tag is the tag of the reported
configuration's output, at every exit. No output word is buffered (design §12.8a, W1).

**Proof sketch.** Induct on `N`; at a step the new tag is `σ` of the appended output. -/
theorem windowRun_tag {k : ℕ} {Q T : Type} {x : List Bool}
    (M : MultiTapeTM k Bool Q) (s : ℕ) (upd : T → Option Bool → T) (σ : List Bool → T)
    (hσ : ∀ u b, σ (u ++ b.toList) = upd (σ u) b) :
    ∀ (N : ℕ) (c : Cfg k Bool Q x),
      (windowRun M s upd N c (σ c.output)).2.2 =
        σ (windowRun M s upd N c (σ c.output)).2.1.output := by
  intro N
  induction N with
  | zero => intro c; simp [windowRun]
  | succ N ih =>
    intro c
    by_cases hst : c.state = none
    · simp [windowRun, hst]
    · by_cases hw : (M.step c).InWindow s
      · have heq : windowRun M s upd (N + 1) c (σ c.output) =
            windowRun M s upd N (M.step c) (σ (M.step c).output) := by
          simp only [windowRun, if_neg hst, if_pos hw]
          rw [← hσ, ← MultiTapeTM.step_output]
        rw [heq]
        exact ih (M.step c)
      · simp [windowRun, hst, hw]

/-- **A stop does not depend on the clock.** If two windowed runs from the same start stop
(exit `halted` or `left`), they report the same result, whatever their round budgets.

**Proof sketch.** Induct on the first budget; both runs take the same branch of every round
until one stops. -/
theorem windowRun_stop_unique {k : ℕ} {Q T : Type} {x : List Bool}
    (M : MultiTapeTM k Bool Q) (s : ℕ) (upd : T → Option Bool → T) :
    ∀ (N N' : ℕ) (c : Cfg k Bool Q x) (τ : T),
      (windowRun M s upd N c τ).1 ≠ .exhausted → (windowRun M s upd N' c τ).1 ≠ .exhausted →
      windowRun M s upd N c τ = windowRun M s upd N' c τ := by
  intro N
  induction N with
  | zero => intro N' c τ h; simp [windowRun] at h
  | succ N ih =>
    intro N' c τ h h'
    cases N' with
    | zero => simp [windowRun] at h'
    | succ N' =>
      by_cases hst : c.state = none
      · simp only [windowRun, if_pos hst]
      · by_cases hw : (M.step c).InWindow s
        · simp only [windowRun, if_neg hst, if_pos hw] at h h' ⊢
          exact ih N' _ _ h h'
        · simp only [windowRun, if_neg hst, if_neg hw]

/-- **Sanity: without the surplus round the clock runs out.** If the first `N`
configurations are live and the first `N + 1` lie in the window, then `N` rounds report
`exhausted` with the configuration of time `N`, **even when that configuration is halted**.
So a halt on the last permitted transition needs one more round: the reason the clock value
must strictly exceed the configuration count (the RD-3 gate's check 4, "the extra halt-test
round").

**Proof sketch.** Induct on `N`; every round steps. -/
theorem windowRun_exhausted_of_live {k : ℕ} {Q T : Type} {x : List Bool}
    (M : MultiTapeTM k Bool Q) (s : ℕ) (upd : T → Option Bool → T) :
    ∀ (N : ℕ) (c : Cfg k Bool Q x) (τ : T), (∀ u < N, (M.runFrom c u).state ≠ none) →
      (∀ u ≤ N, (M.runFrom c u).InWindow s) →
      (windowRun M s upd N c τ).1 = .exhausted ∧
        (windowRun M s upd N c τ).2.1 = M.runFrom c N := by
  intro N
  induction N with
  | zero => intro c τ _ _; simp [windowRun]
  | succ N ih =>
    intro c τ hlive hwin
    have hst : c.state ≠ none := by simpa using hlive 0 (by omega)
    have hw : (M.step c).InWindow s := by
      simpa [MultiTapeTM.runFrom_succ_eq_step] using hwin 1 (by omega)
    have heq : windowRun M s upd (N + 1) c τ =
        windowRun M s upd N (M.step c) (upd τ (M.outputSymbol c)) := by
      simp only [windowRun, if_neg hst, if_pos hw]
    rw [heq, MultiTapeTM.runFrom_succ_eq_step]
    refine ih (M.step c) _ (fun u hu => ?_) (fun u hu => ?_)
    · rw [← MultiTapeTM.runFrom_succ_eq_step]
      exact hlive (u + 1) (by omega)
    · rw [← MultiTapeTM.runFrom_succ_eq_step]
      exact hwin (u + 1) (by omega)

/-- **Sanity: a halt on the final transition that emits the deciding bit** (the RD-3 gate's
suggested obligation for H3). If `M` from `c` halts at time `t + 1` by a transition that
emits `b`, and the run stays in the window, then `t + 2` rounds (the minimal surplus) report
exit `halted` at the halted configuration with the tag of the output **including `b`**.

**Proof sketch.** `Turing.windowRun_halted_of_run` at time `t + 1`, and the last step appends
`b` to the output (`Turing.MultiTapeTM.step_output`). -/
theorem windowRun_halts_on_last_transition {k : ℕ} {Q T : Type} {x : List Bool}
    (M : MultiTapeTM k Bool Q) (s : ℕ) (upd : T → Option Bool → T) (σ : List Bool → T)
    (hσ : ∀ u b, σ (u ++ b.toList) = upd (σ u) b) (t : ℕ) (c : Cfg k Bool Q x) (b : Bool)
    (hhalt : (M.runFrom c (t + 1)).state = none)
    (hemit : M.outputSymbol (M.runFrom c t) = some b)
    (hwin : ∀ u ≤ t + 1, (M.runFrom c u).InWindow s) :
    windowRun M s upd (t + 2) c (σ c.output) =
      (.halted, M.runFrom c (t + 1), σ ((M.runFrom c t).output ++ [b])) := by
  rw [windowRun_halted_of_run M s upd σ hσ (t + 2) (t + 1) c (by omega) hhalt hwin,
    MultiTapeTM.runFrom_succ_eq_step', MultiTapeTM.step_output, hemit]
  rfl

/-! ### The machines -/

/-- **H3's loop: the unclocked windowed round loop.** For a fixed binary machine `M` and a tag
update `upd` that ignores silent steps, there is a module over the record alphabet with an
entry (the round anchor) and three distinct live stop states `stop e` with the following
contract. Start it at its entry with the record of a windowed configuration `c` with tag `τ`
at the head of tape `0`, its other tapes blank, and the native input `x` as digits.
* At every time, every work head stays within `C` times the record length plus one of its
  entry position, and the output is unchanged.
* For every `N`, at some time `t ≤ C · N · (record length + |x| + 1)`, with no stop state
  before `t`, the module is exactly as `N` rounds of `Turing.windowRun` say: if those rounds
  stop (exit `halted` or `left`) it is in `stop e` with the stopping record, and if they do
  not it is back at its entry with the record of the configuration after `N` steps, at a time
  `t ≥ N`. Every other tape, every head, the input position and the output are restored.

So the loop stops exactly when the semantic run does, and a run that never stops keeps the
loop live forever, inside its envelope. [AB09, Theorem 4.8, proof]

**Proof sketch.** One phase host (`Turing.phaseHostTM`) with three phases. The test phase is
`Turing.exists_recordTestTM` at the predicate "halted", embedded by R1 on tape `0`: `yes` goes
to `stop halted`, `no` to the step phase. The step phase is `Turing.exists_recordStepTM` at
`(M, upd)` on the bank `0, …, K`: `yes` returns to the entry, `no` goes to `stop left`. The stop
states are stationary. Each round costs at most `C · (L + |x| + 1)` and at least one step
(both rows have positive first-exit times), and both rows restore every head and scratch tape,
so the envelope holds at all times and does not grow with the number of rounds. The record
length is `Turing.recordLength` (`Turing.joinFields_cfgRecord_length`). The `N`-round
statement is an induction on `N` along `Turing.windowRun`, concatenating rounds by
`Turing.MultiTapeTM.runFrom_add`. -/
theorem exists_windowLoopTM (M : FinTM Bool) {T : Type} [Fintype T] [DecidableEq T]

      (C : ℕ),
      (∀ e, stop e ≠ entry) ∧ Function.Injective stop ∧
      ∀ {x : List Bool} (s : ℕ) (c : Cfg M.k Bool M.State x) (τ : T), c.InWindow s →
      ∀ d : Cfg (K + 1) (RecSym M.State T) P (x.map (RecSym.digitEmb M.State T)),
        d.state = some entry → RecordAt d 0 (cfgRecord s c τ) →
        (∀ j : Fin (K + 1), j ≠ 0 → ∀ p, d.workTapes j p = none) →
        (∀ u (j : Fin (K + 1)), |(L.runFrom d u).workTapePos j - d.workTapePos j| ≤

        (∀ u, (L.runFrom d u).output = d.output) ∧

                    (windowRun M.tm s upd N c τ).2.2) (q - d.workTapePos 0)
                else d.workTapes j q } := by

/-- **H3, the windowed runner** (the loop under the step clock, with the clock word supplied
by the consumer). For a fixed binary machine `M` and a tag update `upd` that ignores silent
steps, there is a module over the record alphabet with an entry and three distinct exits
`exit e`, as follows. Start it at its entry with the record of a windowed configuration `c`
with tag `τ` at the head of tape `0`, a delimited digit word `w` of value `d` at the head of
the last tape, the other tapes blank, and the native input `x` as digits. Then it reaches an
exit `exit out` at a time `t ≤ 5d + 2|w| + 3`, and no exit earlier; up to `t` every head stays
within `C` times the record length plus `|w| + 1` of its entry position, the output is
unchanged, and the space used is at most the number of tapes times twice that radius plus
one. Moreover:
* **halt and window exit are certified**: if `N` rounds of `Turing.windowRun` stop, and
  `C · N · (record length + |x| + 1) ≤ d`, then `out` is their exit;
* **and determined**: if `out` is `halted` or `left`, it is the exit of a stopping
  `Turing.windowRun`, whose record is on tape `0`; the clock interval holds some digit word of
  width `|w|`; every other cell, every head and the input position are restored;
* `out = exhausted` is the clock's timeout, with no further claim on the tapes.

[AB09, Theorem 4.8, proof]

**Proof sketch.** `Turing.exists_stepClockTMVia` at `e := RecSym.digitEmb`, body the loop of
`Turing.exists_windowLoopTM`, and stop states the loop's two stop states `stop halted` and
`stop left`; the clock's `inj` of the loop's entry is the runner's entry, and its `finish` at
the two stop states are the exits `halted` and `left` (all other `finish` values are
unreachable). Every `timeout r` dispatches in one step to the exit `exhausted`, hence the `+ 3`.
The loop's stop time after `N` stopping rounds is at most
`C · N · (L + |x| + 1)`; if it is at most `d` the clock finishes there, and otherwise it times
out. By the clock's frame clause the body heads, the input head and the output follow the
loop's, which the loop's all-times envelope and silence bound, and the counter head stays in
`[cp - 1, cp + |w|]`. -/
theorem exists_windowRunnerTM (M : FinTM Bool) {T : Type} [Fintype T] [DecidableEq T]
    (upd : T → Option Bool → T) (hupd : ∀ τ, upd τ none = τ) :
    ∃ (K : ℕ) (P : Type) (_ : Fintype P) (_ : DecidableEq P)
      (R : MultiTapeTM (K + 2) (RecSym M.State T) P) (entry : P) (exit : WindowExit → P)
      (C : ℕ),
      (∀ e, exit e ≠ entry) ∧ Function.Injective exit ∧
      ∀ {x : List Bool} (s : ℕ) (c : Cfg M.k Bool M.State x) (τ : T), c.InWindow s →
      ∀ (w : List Bool)
        (d : Cfg (K + 2) (RecSym M.State T) P (x.map (RecSym.digitEmb M.State T))),
        d.state = some entry → RecordAt d 0 (cfgRecord s c τ) →
        (∀ p : ℤ, -1 ≤ p → p ≤ (w.length : ℤ) →
          d.workTapes (Fin.last (K + 1)) (d.workTapePos (Fin.last (K + 1)) + p) =
            FinTM.bufferTape (w.map (RecSym.digitEmb M.State T)) p) →
        (∀ j : Fin (K + 2), j ≠ 0 → j ≠ Fin.last (K + 1) → ∀ p, d.workTapes j p = none) →
        ∃ (t : ℕ) (out : WindowExit),
          t ≤ 5 * Nat.ofDigits 2 (w.map Bool.toNat) + 2 * w.length + 3 ∧
          (R.runFrom d t).state = some (exit out) ∧
          (∀ u < t, ∀ e, (R.runFrom d u).state ≠ some (exit e)) ∧
          (∀ u ≤ t, ∀ j : Fin (K + 2), |(R.runFrom d u).workTapePos j - d.workTapePos j| ≤
            ((C * (recordLength M.k x.length s + w.length + 1) : ℕ) : ℤ)) ∧
          (∀ u ≤ t, (R.runFrom d u).output = d.output) ∧
          R.spaceUsed d t ≤ (K + 2) * (2 * C * (recordLength M.k x.length s + w.length + 1) + 1) ∧
          (∀ N, (windowRun M.tm s upd N c τ).1 ≠ .exhausted →

              Nat.ofDigits 2 (w.map Bool.toNat) →
            out = (windowRun M.tm s upd N c τ).1) ∧
          (out ≠ .exhausted → ∃ N, (windowRun M.tm s upd N c τ).1 = out ∧
            ∃ w' : List Bool, w'.length = w.length ∧
            R.runFrom d t =
              { d with
                state := some (exit out)
                workTapes := fun j q =>
                  if j = 0 ∧ d.workTapePos 0 ≤ q ∧
                      q < d.workTapePos 0 + (recordLength M.k x.length s : ℤ)

                      (windowRun M.tm s upd N c τ).2.2) (q - d.workTapePos 0)

                    wordPatch (d.workTapes j) (d.workTapePos j)
                      (w'.map (RecSym.digitEmb M.State T)) q

/-! ### From space bounds to windows -/

/-- **Window containment.** If `M` has visited at most `s` work cells by time `t` on `x`,
then every configuration of its run up to time `t` lies in the radius-`s` window: every head
is within `[-s, s]` and every cell outside it is blank. This is the containment step of
`Complexity.space_hierarchy`'s contradiction, and the hypothesis under which the windowed
runner follows the run. [AB09, §4.1.1, Claim 4.4]

**Proof sketch.** Each tape's visited set has at most `s` cells and is an interval around `0`
(`Turing.MultiTapeTM.abs_pos_lt_card_visited`), so each visited cell has absolute value below
`s`. The head at time `u` is visited, and a nonblank cell at time `u` was visited by then
(`Turing.MultiTapeTM.mem_visited_of_ne_none`), hence by time `t`. -/
theorem FinTM.inWindow_of_spaceUsed_le (M : FinTM Bool) (x : List Bool) {t s : ℕ}
    (hs : M.tm.spaceUsed (M.tm.initCfg x) t ≤ s) :
    ∀ u ≤ t, (M.tm.runFrom (M.tm.initCfg x) u).InWindow s := by
  intro u hu
  have hmem : ∀ i, ∀ z ∈ M.tm.visitedByTapeHead (M.tm.initCfg x) t i, |z| < (s : ℤ) := by
    intro i z hz
    have hcard : (M.tm.visitedByTapeHead (M.tm.initCfg x) t i).card ≤ s :=
      (M.tm.spaceUsedByTape_le_spaceUsed _ t i).trans hs
    exact (M.tm.abs_pos_lt_card_visited x t i hz).trans_le (by exact_mod_cast hcard)
  refine ⟨fun i => (hmem i _ ?_).le, fun i z hz => ?_⟩
  · simp only [MultiTapeTM.visitedByTapeHead, Finset.mem_image, Finset.mem_range]
    exact ⟨u, by omega, rfl⟩
  · by_contra hne
    have hv := M.tm.visitedByTapeHead_mono _ hu i (M.tm.mem_visited_of_ne_none x u i z hne)
    have := hmem i z hv
    omega

/-- **The windowed run of a space-bounded halting computation** (the B6 instance). If `M`
halts on `x` with output `w` by time `t`, having visited at most `s` cells, and `t < N`, then
`N` rounds from `M`'s initial configuration with the empty-output tag `0` report exit
`halted`, the halted configuration of time `t`, and the tag of `w`. With the tag `1` exactly
when `w = [true]` (`Turing.outSummaryCode_eq_one_iff`), this is the verdict the diagonalizer
flips. [AB09, Theorem 4.8, proof]

**Proof sketch.** Window containment (`Turing.FinTM.inWindow_of_spaceUsed_le`), then
`Turing.windowRun_halted_of_run` with `σ = outSummaryCode ∘ outSummary`, whose compatibility
is `Turing.summaryTag_append`. -/
theorem windowRun_summary_of_halts (M : FinTM Bool) (x : List Bool) {w : List Bool}
    {t s N : ℕ} (h : M.ComputesInTime x w t) (hs : M.tm.spaceUsed (M.tm.initCfg x) t ≤ s)
    (hN : t < N) :
    windowRun M.tm s summaryTag N (M.tm.initCfg x) 0 =
      (.halted, M.tm.runFrom (M.tm.initCfg x) t, outSummaryCode (outSummary w)) := by
  obtain ⟨hhalt, hout⟩ := (FinTM.computesInTime_iff M x w t).mp h
  have key := windowRun_halted_of_run M.tm s summaryTag (fun u => outSummaryCode (outSummary u))
    summaryTag_append N t (M.tm.initCfg x) hN hhalt (FinTM.inWindow_of_spaceUsed_le M x hs)
  rw [hout] at key
  exact key

/-- **The configuration count is at most a power of two** (the RD-3 gate's check 4):
`configBound M n s ≤ 2 ^ (|Q| + posWidth n + 3 k (2s + 1))`. Its four factors satisfy
`|Q| + 1 ≤ 2^|Q|`, `n + 2 ≤ 2^(posWidth n)`, `3^(k(2s+1)) ≤ 2^(2k(2s+1))` and
`(2s + 1)^k ≤ 2^(k(2s+1))`. A clock word of all `true` digits one longer than the exponent has
value `2^W - 1 > configBound M n s`. [AB09, §4.1.1, Claim 4.4]

**Proof sketch.** Multiply the four factor bounds and collect the powers of two. -/
theorem FinTM.configBound_le_two_pow (M : FinTM Bool) (n s : ℕ) :
    M.configBound n s ≤
      2 ^ (Fintype.card M.State + posWidth n + 3 * M.k * (2 * s + 1)) := by
  have hQ : Fintype.card M.State + 1 ≤ 2 ^ Fintype.card M.State :=
    Nat.lt_two_pow_self
  have hn : n + 2 ≤ 2 ^ posWidth n := by
    have h := Nat.lt_size_self (n + 1)
    rw [← Nat.size_eq_bits_len] at h
    exact h
  have h3 : 3 ^ (M.k * (2 * s + 1)) ≤ 2 ^ (2 * (M.k * (2 * s + 1))) :=
    calc 3 ^ (M.k * (2 * s + 1)) ≤ 4 ^ (M.k * (2 * s + 1)) :=
          Nat.pow_le_pow_left (by norm_num) _
      _ = 2 ^ (2 * (M.k * (2 * s + 1))) := by
          rw [pow_mul 2 2 (M.k * (2 * s + 1))]
          norm_num
  have hw : (2 * s + 1) ^ M.k ≤ 2 ^ (M.k * (2 * s + 1)) := by
    rw [mul_comm M.k, pow_mul]
    exact Nat.pow_le_pow_left (Nat.lt_two_pow_self).le _
  have hsplit : 2 ^ (Fintype.card M.State + posWidth n + 3 * M.k * (2 * s + 1)) =
      2 ^ Fintype.card M.State * 2 ^ posWidth n * 2 ^ (2 * (M.k * (2 * s + 1))) *
        2 ^ (M.k * (2 * s + 1)) := by
    rw [← pow_add, ← pow_add, ← pow_add]
    congr 1
    ring
  rw [hsplit]
  unfold FinTM.configBound
  exact Nat.mul_le_mul (Nat.mul_le_mul (Nat.mul_le_mul hQ hn) h3) hw

/-! ### The runner -/

/-- **H3 with the configuration-count clock** (what `Complexity.space_hierarchy`'s
diagonalizer cites). The windowed runner that builds its own clock. For a fixed binary machine
`M` and a tag update `upd` that ignores silent steps, there is a module over the record alphabet
with an entry and three distinct exits `exit e`, as follows. Start it at its entry with the
record of a windowed configuration `c` with tag `τ` at the head of tape `0`, every other tape
blank, and the native input `x` as digits. Then it reaches an exit `exit out` within
`C · 2^(C·(L + 1))` steps, where `L` is the record length, and no exit earlier. Up to then
every head stays within `C · (L + 1)` cells of its entry position, so the space used is `O(L)`
with constants depending only on `M` and `upd`, and the output is unchanged. Moreover:
* **the configuration count suffices**: if `N ≤ configBound M |x| s + 1` rounds of
  `Turing.windowRun` stop, then `out` is their exit, and the stopping record is on tape `0`;
* if `out` is `halted` or `left`, it is the exit of a stopping `Turing.windowRun`, whose record
  is on tape `0`, with every other tape blank again and every head and the input position
  restored.

With `Turing.windowRun_summary_of_halts`, a halting run of `M` within `s` cells and
`configBound M |x| s` steps is reported as `halted` with its output's tag. The bound
`N ≤ configBound + 1` contains the extra halt-test round (the RD-3 gate's check 4). [AB09,
§4.1.3, proof of Theorem 4.8; §4.1.1, Claim 4.4]

**Proof sketch.** The statement does not fix the clock, and two routes meet it.

*Route A (one shared clock).* Build the clock word, then run `Turing.exists_windowRunnerTM` on
it, then clear it. The clock word is all `true` of width `W := c_M · L`: by
`Turing.FinTM.configBound_le_two_pow`, the configuration count is at most
`2 ^ (|Q| + posWidth |x| + 3k(2s + 1))`, the per-round cost is
`C · (L + |x| + 1) ≤ C · 2^(L + 1)` (since `|x| + 2 ≤ 2^(posWidth |x|)` and
`posWidth |x| ≤ L`), and `L ≥ k(2s + 1) + posWidth |x|`; so `2^W - 1` exceeds
`C · (configBound + 1) · (L + |x| + 1)` for a constant `c_M` depending only on `|Q|` and `C`
(`L ≥ 4`). The word is written by copying the record's layout `c_M` times onto a scratch tape
and mapping every cell to `digit true` (`Turing.copyTM`, `Turing.skipTM`, `Turing.scanTM`, as
S1b's plan does, design §12.8a §4 step 5); it costs `O(L)` cells and time. After a `halted` or
`left` exit, clear the clock (`Turing.clearTM_run_ofCfg`) and rewind its head.

*Route B (the round clock, proved today; the RD-3 gate's minor 3).* Run the window round (the
test row, then the step row) as the body of `Turing.counterLoopTMVia`, with the anchor at the
round's start and the halt and window exits merged into its one optional early exit
(`Turing.counterLoopTMVia_run_escape`), clock exhaustion being `done`
(`Turing.counterLoopTMVia_run_done`); after an escape, one more test row tells `halted` from
`left` on the unchanged record. The clock word has width `|Q| + posWidth |x| + 3k(2s + 1) + 1`
or more, so its value exceeds `configBound M |x| s`: rounds, not steps, are counted, and the
time is at most the clock value times `C · (L + |x| + 1)` (`Turing.counterLoop_time_le`). -/
theorem exists_configWindowRunnerTM (M : FinTM Bool) {T : Type} [Fintype T] [DecidableEq T]
    (upd : T → Option Bool → T) (hupd : ∀ τ, upd τ none = τ) :
    ∃ (K : ℕ) (P : Type) (_ : Fintype P) (_ : DecidableEq P)
      (R : MultiTapeTM (K + 1) (RecSym M.State T) P) (entry : P) (exit : WindowExit → P)
      (C : ℕ),
      (∀ e, exit e ≠ entry) ∧ Function.Injective exit ∧
      ∀ {x : List Bool} (s : ℕ) (c : Cfg M.k Bool M.State x) (τ : T), c.InWindow s →

# Machine-construction library: input devices (host H5)

An **input device** presents a *virtual* input `y` at a virtual head position `i` inside a host
configuration over a *physical* input `z`, and supplies the two operations a simulated machine
needs: read the virtual cell (`Turing.inputCell y i`: blank at `0` and past the end, the
input-tape convention of `Turing.Cfg.inputSymbol`), and move the virtual head by the clamped
move `Turing.moveInputPos`. It is host H5 of the registry (`machine-library-design.md` §14).
Two devices are stated here.
* **Native** (`Turing.NativeAt`): `z = y`, and the physical head is the virtual one. Nothing is
  stored, and a host step is a source step (literal lockstep). It is the device of H2's step
  block and of `U₀` (`TuringMachine/SelfUniversal.lean`).
* **Bounded-prefix ruler** (`Turing.RulerAt`): `z` is a header of length `ℓ > 0` followed by
  `y`, the physical head is at `ℓ + i`, and a work tape holds the unary ruler `true^ℓ`. Since
  `ℓ > 0`, the physical cell `p - ℓ` is blank exactly at the virtual left boundary, so a
  restoring sweep of `ℓ` cells tests it without clamping. Its storage is the ruler's `ℓ + 2`
  cells. It is the device of the addend-free `Complexity.space_universal`, whose header length
  is linear in the budget (the RD-3 statement gate, minor 1).

The buffered device is Z1 (`Build/VirtualInput.lean`). The binary-position device of the
registry row is not stated here; no current consumer needs it.

**The ruler host is a block simulation** (the H2-S gate, finding 2). `Turing.exists_rulerHostTM`
turns any native-input machine into one on the suffix input: each source step is one host step,
followed by a boundary test after a left move, so `t` source steps take between `t` and
`C · (ℓ + 1) · t` host steps. At every host time the bank, the output and the ruler are those of
the source at some source time (the intermediate frames), the host does not halt before the
source does (the exit cut), and the time and space ledgers are separate clauses. Literal
lockstep is the native special case.

the devices' correctness facts are proved; the three machine contracts are sorried with their

/-- **The cell of a virtual input at position `i`** (the input-tape convention of
`Turing.Cfg.inputSymbol`): blank at `0` and beyond the word, the `i`-th symbol otherwise.
[AB09, §1.2: the input tape, with blanks at both ends] -/
def inputCell {Γ : Type*} (y : List Γ) (i : ℕ) : Option Γ :=
  if i = 0 then none else y[i - 1]?

/-- The native input symbol is the input cell at the head.

**Proof sketch.** Compare the three cases of `Turing.Cfg.inputSymbol`: position `0`, the right
blank `|y| + 1` (where the lookup is out of range), and the interior
(`Turing.inputSymbolInner`). -/
theorem Cfg.inputSymbol_eq_inputCell {k : ℕ} {Γ S : Type*} {y : List Γ}
    (c : Cfg k Γ S y) : c.inputSymbol = inputCell y c.inputPos.val := by
  have hlt := c.inputPos.isLt
  by_cases h0 : c.inputPos.val = 0
  · have hz : c.inputPos = 0 := Fin.ext h0
    simp [Cfg.inputSymbol, inputCell, hz]
  · by_cases hr : c.inputPos.val = y.length + 1
    · have hz : c.inputPos ≠ 0 := fun h => h0 (by rw [h]; rfl)
      simp only [Cfg.inputSymbol, inputCell, dif_neg hz, dif_pos hr, if_neg h0]
      rw [List.getElem?_eq_none (by omega)]
    · have hin := inputSymbolInner (cfg := c) (c.inputPos.val - 1) (by omega) (by omega)
      rw [hin]
      simp only [inputCell, if_neg h0]
      rw [List.getElem?_eq_getElem (by omega)]

/-- **H5, the native device**: a host configuration presents its own input `y` at virtual
position `i` when its physical input head is at `i`. Reading is the native read, and moving is
the native clamped move; there is nothing to store. This is the device of H2's step block
(its seam relation's input clause) and of `U₀`, whose virtual input is all of its input.
[AB09, §1.2] -/
def NativeAt {K : ℕ} {Γ S : Type*} {y : List Γ} (d : Cfg K Γ S y) (i : Fin (y.length + 2)) :
    Prop :=
  d.inputPos = i

/-- The native device reads the virtual input cell.

**Proof sketch.** `Turing.Cfg.inputSymbol_eq_inputCell` at the head. -/
theorem NativeAt.inputSymbol_eq {K : ℕ} {Γ S : Type*} {y : List Γ} {d : Cfg K Γ S y}
    {i : Fin (y.length + 2)} (h : NativeAt d i) : d.inputSymbol = inputCell y i.val := by
  rw [Cfg.inputSymbol_eq_inputCell, h]

/-- The native device moves the virtual head by the clamped move. -/
theorem NativeAt.move {K : ℕ} {Γ S : Type*} {y : List Γ} {d : Cfg K Γ S y}
    {i : Fin (y.length + 2)} (h : NativeAt d i) (m : SignType) :
    NativeAt { d with inputPos := moveInputPos d.inputPos m } (moveInputPos i m) := by
  unfold NativeAt at h ⊢
  rw [h]

/-- The initial configuration presents its input natively at position `1`, the position at
which `U₀`'s startup must leave its input head (the RD-3 gate's check 2). -/
theorem nativeAt_init {K : ℕ} {Γ S : Type*} (q₀ : S) (y : List Γ) :
    NativeAt (Cfg.init q₀ y : Cfg K Γ S y) 1 := rfl

/-! ### The bounded-prefix ruler device -/

/-- **The boundary test reads a blank exactly at the virtual left boundary.** If the header
length `ℓ` is positive and the physical head is at `p` with `ℓ ≤ p ≤ |z| + 1`, then the
physical input cell `p - ℓ` is blank exactly when `p = ℓ`. This holds for every `z`, so for an
empty payload as well (the RD-3 gate's suggested sanity obligation for the bounded-prefix
device).

**Proof sketch.** At `p = ℓ` the cell is position `0`. Otherwise `1 ≤ p - ℓ ≤ |z|`, since
`ℓ ≥ 1`, and the cell holds an input symbol. -/
theorem inputCell_sub_eq_none_iff {z : List Bool} {ℓ p : ℕ} (hℓ : 0 < ℓ) (hp : ℓ ≤ p)
    (hpz : p ≤ z.length + 1) : inputCell z (p - ℓ) = none ↔ p = ℓ := by
  unfold inputCell
  by_cases h : p - ℓ = 0
  · simp only [if_pos h, true_iff]
    omega
  · rw [if_neg h, List.getElem?_eq_getElem (by omega)]
    simp only [reduceCtorEq, false_iff]
    omega

/-- **Away from the boundary the virtual cell is the physical one.** If `y` is `z` without
its first `ℓ` symbols, the virtual cell `i ≠ 0` of `y` is the physical cell `ℓ + i` of `z`,
the right blank included.

**Proof sketch.** Both are the lookup of `z` at `ℓ + i - 1` (`List.getElem?_drop`). -/
theorem inputCell_of_drop {z y : List Bool} {ℓ : ℕ} (h : z.drop ℓ = y) {i : ℕ}
    (hi : i ≠ 0) : inputCell y i = inputCell z (ℓ + i) := by
  subst h
  unfold inputCell
  rw [if_neg hi, if_neg (by omega), List.getElem?_drop]
  congr 1
  omega

/-- **H5, the bounded-prefix ruler device** (the RD-3 gate's row 1): a host configuration `d`
over the physical input `z` presents the virtual input `y` at virtual position `i` with header
length `ℓ` and ruler tape `r` when `z` is a header of length `ℓ > 0` followed by `y`, the
physical head is at `ℓ + i`, and tape `r` holds, from its head, the delimited unary ruler
`true^ℓ`. Since `ℓ > 0`, the physical cell `i` is blank exactly when `i = 0`, so a sweep of
`ℓ` cells left, a read and a sweep back test the virtual left boundary without clamping. The
ruler's cells are the device's whole storage: `ℓ + 2` visited cells, however far the virtual
head travels. [AB09, §1.2; Exercise 4.1] -/
def RulerAt {K : ℕ} {S : Type*} {y z : List Bool} (ℓ : ℕ) (r : Fin K) (d : Cfg K Bool S z)
    (i : Fin (y.length + 2)) : Prop :=
  0 < ℓ ∧ ℓ ≤ z.length ∧ z.drop ℓ = y ∧ d.inputPos.val = ℓ + i.val ∧
    ∀ p : ℤ, -1 ≤ p → p ≤ (ℓ : ℤ) →
      d.workTapes r (d.workTapePos r + p) = FinTM.bufferTape (List.replicate ℓ true) p

/-- **The header length of `Complexity.space_universal`'s input.** The input
`⟨bits s, ⟨α, x⟩⟩ = pairEncode (bits s) (pairEncode α x)` is a header of length
`2|bits s| + 2|α| + 4` followed by `x`.

**Proof sketch.** Each pairing doubles its first word and adds two separator cells
(`Turing.universal_pair_length`). -/
theorem pairEncode_pairEncode_length (u α x : List Bool) :
    (pairEncode u (pairEncode α x)).length = (2 * u.length + 2 * α.length + 4) + x.length := by
  rw [universal_pair_length, universal_pair_length]
  omega

/-- **The payload after the header.** Dropping the header of length `2|u| + 2|α| + 4` from
`pairEncode u (pairEncode α x)` leaves `x`: the ruler device's `z.drop ℓ = y`.

**Proof sketch.** Drop the two pairings' prefixes one after the other. -/
theorem pairEncode_pairEncode_drop (u α x : List Bool) :
    (pairEncode u (pairEncode α x)).drop (2 * u.length + 2 * α.length + 4) = x := by
  have hd (v z : List Bool) : (pairEncode v z).drop (2 * v.length + 2) = z := by
    have hl : ((v.flatMap fun b => [b, b]) ++ [false, true]).length = 2 * v.length + 2 := by
      have h := universal_pair_length v []
      simpa [pairEncode] using h
    rw [show pairEncode v z = ((v.flatMap fun b => [b, b]) ++ [false, true]) ++ z from rfl]
    exact List.drop_left' hl
  rw [show 2 * u.length + 2 * α.length + 4 = (2 * u.length + 2) + (2 * α.length + 2) by ring,
    ← List.drop_drop, hd, hd]

/-- **The restoring suffix-boundary test** (the ruler device's core; the RD-3 gate's suggested
sanity obligation). There is a one-tape binary module with an entry and two distinct verdicts
as follows. Start it at its entry with the delimited ruler `true^ℓ`, `ℓ > 0`, at its head and
the physical input head at a position `p ≥ ℓ`. It reaches `yes` if `p = ℓ` and `no`
otherwise, within `C · (ℓ + 1)` steps and no verdict earlier, with nothing else changed: the
input head is back at `p` and the ruler head at its start, having stayed within `ℓ + 1` cells.
The input itself is arbitrary, so an empty payload is included. [AB09, §1.2]

**Proof sketch.** Move the input head left and the ruler head right in lockstep until the ruler
head reads the blank after the ruler: `ℓ` moves, none clamped since `p ≥ ℓ`. Read the input cell
at `p - ℓ`: it is blank exactly when `p - ℓ = 0`, since `p - ℓ ≤ |z| + 1 - ℓ ≤ |z|`
(`Turing.inputCell_sub_eq_none_iff`). Move both heads back `ℓ` cells (the ruler head stops at
the blank before the ruler, then steps right). A finite control carries the verdict. -/
theorem exists_rulerTestTM :
    ∃ (P : Type) (_ : Fintype P) (_ : DecidableEq P) (R : MultiTapeTM 1 Bool P)
      (entry yes no : P) (C : ℕ), yes ≠ no ∧
      ∀ {z : List Bool} (ℓ : ℕ) (d : Cfg 1 Bool P z), d.state = some entry → 0 < ℓ →
        ℓ ≤ d.inputPos.val →
        (∀ p : ℤ, -1 ≤ p → p ≤ (ℓ : ℤ) →
          d.workTapes 0 (d.workTapePos 0 + p) = FinTM.bufferTape (List.replicate ℓ true) p) →
        ∃ t ≤ C * (ℓ + 1),
          (∀ u < t, (R.runFrom d u).state ≠ some yes ∧ (R.runFrom d u).state ≠ some no) ∧
          (∀ u ≤ t, |(R.runFrom d u).workTapePos 0 - d.workTapePos 0| ≤ ((ℓ + 1 : ℕ) : ℤ)) ∧
          R.runFrom d t = { d with state := some (if d.inputPos.val = ℓ then yes else no) } := by
  sorry

/-- **H5, the ruler device's call rows** ("read the virtual input cell", "move the virtual input
head"). There is a one-tape binary module with a read entry, three read verdicts
`readExit v`, a move entry per direction and a move exit, as follows, for every presentation
`Turing.RulerAt ℓ 0 d i` of a virtual input `y` at `i`.
* **Read**: from the read entry it reaches `readExit (inputCell y i)` within `C · (ℓ + 1)`
  steps, no read verdict earlier, with nothing else changed.
* **Move** by `m`: from `moveEntry m` it reaches the move exit within `C · (ℓ + 1)` steps, not
  earlier, with the physical head at `ℓ + (moveInputPos i m)` and every tape, every head and
  the output unchanged; so the result presents `y` at the clamped position `moveInputPos i m`.

In both, the ruler head stays within `ℓ + 1` cells of its start, so the device's work space is
`ℓ + 2` cells. These rows are the interface for a device-generic step block; the ruler host
below uses the boundary test directly. [AB09, §1.2]

**Proof sketch.** Both rows begin with the boundary test of `Turing.exists_rulerTestTM`. Read:
on `yes` answer blank; on `no` answer the native symbol under the head, which is
`y[i - 1]` or the right blank (`Turing.inputCell_of_drop`). Move: a right move is the native
clamped move (at `i = |y| + 1` the physical head is at `|z| + 1` and clamps exactly as
`moveInputPos` does); a stationary move does nothing; a left move is suppressed on `yes` and is
the native left move on `no`. Rows are joined by R2 seams; the dispatch steps add a constant. -/
theorem exists_rulerDeviceTM :
    ∃ (P : Type) (_ : Fintype P) (_ : DecidableEq P) (R : MultiTapeTM 1 Bool P)
      (readEntry : P) (readExit : Option Bool → P) (moveEntry : SignType → P) (moveExit : P)
      (C : ℕ),
      Function.Injective readExit ∧ (∀ v, readExit v ≠ moveExit) ∧
      ∀ {y z : List Bool} (ℓ : ℕ) (d : Cfg 1 Bool P z) (i : Fin (y.length + 2)),
        RulerAt ℓ 0 d i →
        (d.state = some readEntry →
          ∃ t ≤ C * (ℓ + 1),
            (∀ u < t, ∀ v, (R.runFrom d u).state ≠ some (readExit v)) ∧
            (∀ u ≤ t, |(R.runFrom d u).workTapePos 0 - d.workTapePos 0| ≤ ((ℓ + 1 : ℕ) : ℤ)) ∧
            R.runFrom d t = { d with state := some (readExit (inputCell y i.val)) }) ∧
        (∀ m : SignType, d.state = some (moveEntry m) →
          ∃ t ≤ C * (ℓ + 1),
            (∀ u < t, (R.runFrom d u).state ≠ some moveExit) ∧
            (∀ u ≤ t, |(R.runFrom d u).workTapePos 0 - d.workTapePos 0| ≤ ((ℓ + 1 : ℕ) : ℤ)) ∧
            (R.runFrom d t).state = some moveExit ∧
            (R.runFrom d t).inputPos.val = ℓ + (moveInputPos i m).val ∧
            (R.runFrom d t).workTapes = d.workTapes ∧
            (R.runFrom d t).workTapePos = d.workTapePos ∧
            (R.runFrom d t).output = d.output) := by
  sorry

/-- **The ruler host layout**: a configuration `c` of an `m`-tape machine on the virtual input
`y`, viewed over the physical input `z` with a header of length `ℓ`: the control `q`, the
physical input head at `ℓ + c`'s position, `c`'s work tapes and heads first, the ruler tape
`rt` with its head at `rp` last, and `c`'s output. -/
def rulerHostCfg {m : ℕ} {S Q : Type} {y z : List Bool} (ℓ : ℕ)
    (hz : z.length = ℓ + y.length) (q : Option Q) (c : Cfg m Bool S y) (rt : ℤ → Option Bool)
    (rp : ℤ) : Cfg (m + 1) Bool Q z :=
  ⟨q, ⟨ℓ + c.inputPos.val, by have := c.inputPos.isLt; omega⟩, Fin.lastCases rt c.workTapes,
    Fin.lastCases rp c.workTapePos, c.output⟩

/-- **H5, the ruler host**: a positive, finite block simulation of any native-input machine on
a suffix input (the H2-S gate's finding 2). For any binary machine `M` on `m` tapes there is a
host on one more tape (the ruler, last), with an injection `inj` of the source states paired
with a boundary tag, as follows. Present a source configuration `c` on the virtual input `y`
inside `z = header ++ y` (header length `ℓ > 0`) through `Turing.rulerHostCfg`, with the ruler
`true^ℓ` at the ruler head and the tag `b` true exactly at the virtual left boundary. Then for
every `t`:
* **block endpoint**: after some `t'` host steps with `t ≤ t' ≤ C · (ℓ + 1) · t` the host
  presents the source's configuration after `t` steps, with a correct tag;
* **exit cut**: if the source is live before `t`, the host is live before `t'`;
* **intermediate frames**: at every host time up to `t'`, the bank tapes, the bank heads and
  the output are the source's at some source time no later than `t`, the ruler tape is
  unchanged, and the ruler head is on the ruler or one of its two delimiters;
* **space ledger**: the bank heads visit exactly the source's cells, and the ruler head
  `ℓ + 2` cells.

So the host halts exactly when the source does (the cut and `t ≤ t'` give the converse), with
the source's output, using the source's space plus `ℓ + 2` cells, within `C · (ℓ + 1)` times
the source's time. Literal lockstep (`t' = t`) is the native special case, and Z1's
`Turing.vhostEmitTM`. This is how H2's step block, whose input is native, runs on a suffix
input unchanged. [AB09, §1.2; Exercise 4.1]

**Proof sketch.** Each host step performs the source transition, reading the native symbol, or
blank when the tag is set, and suppressing a left move when the tag is set. A right move
clears the tag; after a left move from a cleared tag the host pauses for the boundary test of
`Turing.exists_rulerTestTM` (on the ruler tape, by R1) and sets the tag from its verdict. A
halting source transition halts the host in the same step, with no pause. The pause costs
`C · (ℓ + 1)` steps, moves no bank head, writes nothing and emits nothing, which gives the
frames and the cut. Induct on `t` as `Turing.vhostEmitTM_runFrom` does; the visited-set clauses
follow `Turing.vhostEmitTM_visitedByTapeHead_bank` and
`Turing.vhostEmitTM_visitedByTapeHead_buffer`. -/
theorem exists_rulerHostTM {m : ℕ} {S : Type} [Fintype S] [DecidableEq S]
    (M : MultiTapeTM m Bool S) :
    ∃ (Q : Type) (_ : Fintype Q) (_ : DecidableEq Q) (H : MultiTapeTM (m + 1) Bool Q)
      (inj : S → Bool → Q) (C : ℕ), 0 < C ∧
      ∀ {y z : List Bool} (ℓ : ℕ) (hz : z.length = ℓ + y.length), 0 < ℓ → z.drop ℓ = y →
      ∀ (rt : ℤ → Option Bool) (rp : ℤ),
        (∀ p : ℤ, -1 ≤ p → p ≤ (ℓ : ℤ) →
          rt (rp + p) = FinTM.bufferTape (List.replicate ℓ true) p) →
      ∀ (c : Cfg m Bool S y) (b : Bool), (b = true ↔ c.inputPos.val = 0) → ∀ t : ℕ,
        let d := rulerHostCfg ℓ hz (c.state.map fun q => inj q b) c rt rp
        ∃ t', t ≤ t' ∧ t' ≤ C * (ℓ + 1) * t ∧
          (∃ b' : Bool, (b' = true ↔ (M.runFrom c t).inputPos.val = 0) ∧
            H.runFrom d t' =
              rulerHostCfg ℓ hz ((M.runFrom c t).state.map fun q => inj q b')
                (M.runFrom c t) rt rp) ∧
          ((∀ u < t, (M.runFrom c u).state ≠ none) → ∀ u < t', (H.runFrom d u).state ≠ none) ∧
          (∀ u ≤ t', ∃ v ≤ t,
            (∀ i : Fin m, (H.runFrom d u).workTapes i.castSucc = (M.runFrom c v).workTapes i ∧
              (H.runFrom d u).workTapePos i.castSucc = (M.runFrom c v).workTapePos i) ∧
            (H.runFrom d u).output = (M.runFrom c v).output ∧
            (H.runFrom d u).workTapes (Fin.last m) = rt ∧
            (H.runFrom d u).workTapePos (Fin.last m) ∈ Finset.Icc (rp - 1) (rp + ℓ)) ∧
          (∀ i : Fin m, H.visitedByTapeHead d t' i.castSucc = M.visitedByTapeHead c t i) ∧
          H.visitedByTapeHead d t' (Fin.last m) ⊆ Finset.Icc (rp - 1) (rp + ℓ) := by
  sorry

end Turing

# The self-application universal machine `U₀`

[AB09, Exercise 4.1] at self-application: one fixed machine `U₀` that, on an input
`pairEncode α w`, simulates the machine coded by `α` on that same input and reproduces its
output, with a space overhead that is a constant factor depending on `α` only. It is the
universal machine of `Complexity.space_hierarchy`'s window route (`machine-library-design.md`
§16b item 3): a public row built from H2's step block and H5's native device, not a private host
of that proof (`policy.md` §1, *Hosts come first*).

**Status: statement gate pending** (`audits/b6-hosts-statements-pack.md`). Both contracts are
sorried with their proof sketches.

## Design

* **Self-application.** The simulated input is all of `U₀`'s input, so the native device serves
  (`Turing.NativeAt`: its left boundary is a real blank) and no input position is stored or
  copied.
* **Forward only.** Halting runs within `s` cells are reproduced within `C_α · (s + 1)` cells;
  nothing is claimed of other runs, which is all the window route uses.
* **Library notions only.** The startup's endpoint is the step block's seam relation written
  out: the table on tape `1`, the unary initial state on tape `2` from cell `2`, the input head
  at `1`, the output empty. Neither statement names a declaration of the H2 promotion (H2-S), so
  its renaming changes only the sketches. The fill depends on H2-S round 2: the public step
  block contract, and the repaired iteration with its cofinality bound.
* **Generic in the effective scheme**; `Complexity.space_hierarchy` instantiates
  `Complexity.TimeHierarchy.code`.

## Main results

* `Turing.exists_selfStartupTM` — the startup, ending at the step block's seam (sorried).
* `Turing.exists_selfUniversal` — `U₀`, with its forward space ledger (sorried).

/-- **`U₀`, the self-application universal machine** (`Complexity.space_hierarchy`'s sketch;
the sibling of `Complexity.space_universal`, with the native device in place of the
bounded-prefix one). For an effective scheme `c` there is a binary machine `U₀` such that
for every code `α` there is a constant `C > 0` with: whenever the machine coded by `α` halts
on `pairEncode α w` with some output, having visited at most `s` cells, `U₀` halts on the same
input with the same output, having visited at most `C · (s + 1)` cells. Only this forward
direction is claimed; `Complexity.space_hierarchy` instantiates
`c := Complexity.TimeHierarchy.code`. [AB09, Exercise 4.1, forward clause, at self-application;
§4.1.3, proof of Theorem 4.8]

Deviation: `C` depends on the code `α` (as in `Turing.universal`), and the input is the coded
machine's own input (self-application), so no copy and no position counter is needed.

**Proof sketch.** Startup, then wrapped rounds.
(i) *Startup.* `Turing.exists_selfStartupTM` reaches, within `B_α` cells, the step block's seam
for the coded machine's initial configuration on the same input: input head at `1`, table and
unary state in place, output empty.
(ii) *The wrapped round, with H2-S finding 4's reset invariant.* At every seam the step block's
bank represents the source configuration **with its output erased**, `{c with output := []}`
(so its summary cell is blank), while `U₀`'s own physical output is the real cumulative output
`c.output`. From such a seam at a live `c`, run H2's step block at one coded work tape, embedded
by R1 on tapes `0`–`2` (the public contract of the H2 promotion, `Turing.StepBlock.roundTM_effect`;
private `h1Round_effect` in `TuringMachine/CodeSimulator.lean` today), on `{c with output := []}`.
The transition read off the table depends only on the state, the input symbol and the work
symbol, which the erasure does not change, so the round ends at the seam of
`a.apply {c with output := []}`, with summary cell `summaryEmit none (a.output) = a.output`: the
round's exact emission. A host leaf on tape `2` then emits that bit, if any, so that `U₀`'s
output becomes `(a.apply c).output`, and blanks the cell, which re-establishes the invariant
for `a.apply c`. On the halting round the leaf runs before `U₀` halts physically (forwarding
precedes the halt).
(iii) *Iteration.* Induct on the source steps, as H2-S round 2's repaired `roundTM_iterate`
does (the additive iteration with the cofinality bound `t ≤ T`, H2-S finding 1), with each round
replaced by the wrapped round of (ii). Finding 4 notes that the silent iterate is not itself a
theorem about the wrapper, so the fill proves the wrapped iterate; it cites the repaired
`roundTM_iterate` directly if H2-S round 2 states it for a general round.
(iv) *Space.* In each round the mirrored head is at the source head's start or end cell and the
two auxiliary heads stay in `[-B, B]` with `B := 50·(|tableBitsK| + 1)` (`roundTM_visited`); the
leaf moves no head. So the mirrored tape visits only cells the coded machine visits, at most `s`;
the auxiliary tapes at most `2B + 1` cells each; the startup `B_α`. The space is at most
`B_α + s + 2(2B + 1) ≤ C_α · (s + 1)`. -/

/-- **The space-bounded universal machine** ([AB09, Exercise 4.1], p. 93,
forward clause; spec, fill pending — phase P4.3, restated forward-only

machine overruns `s` or does not halt. The time is existential, as
`Turing.FinTM.ComputesInTime`'s halting demands, with no stated bound. Every
qualifying run has `s ≥ 1` (`Turing.CodeTM.one_le_spaceUsed`), so the bound
is never `0`.

Deviations from the book's `SU(α, t, x) = M_α(x)` within `C · t` cells:
* **`C` depends on the representation `α`**, not only on `M_α`, as in
  `Turing.universal`, whose module docstring records why an arbitrary
  effective scheme forces this.
* "Halts before using `t` cells" is read as "at most `s` visited cells"; the
  budget is an argument of `SU`, as in the book, but is never read.
* The output is the simulated output itself: with no failure clause there is
  no verdict to tag. The former `[false]` clause, and with it the
  visited-interval counters, the core-count clock and the probe/replay of the
  previous statement, went with design §16b item 3.

There is no input-device addend: the gated `+ logSpace |x| + 1` (a binary
position for the simulated input head) is replaced by a unary ruler of the
header's length, whose cells the bound absorbs (the RD-3 gate's minor 1).

**Proof sketch.** A code-first interpreter in three parts. (i) **Startup.**

with `ℓ = 2|bits s| + 2|α| + 4` (`Turing.pairEncode_pairEncode_length`,
`Turing.pairEncode_pairEncode_drop`) and the physical input head ends at
`ℓ + 1`, the virtual position `1`; the budget is never read. Canonize `α`

the effective scheme supplies no bound linear in `|α|`, and none is claimed.
