# MIG-1 statement draft: named witnesses for the existential rows

**Status: a statement draft for the MIG-1 statement gate; not for landing as a file.** Each
declaration below is the draft of a public declaration that MIG-1 adds to one of the home files
named in its docstring (`machine-library-design.md` §2, the named-machine rule; §16, MIG-1).
The draft lives in the namespace `Turing.FinTM.MIG1Draft` so that it can import the snapshot,
where today's rows are public and today's witnesses are private; on landing, every
`Turing.FinTM.MIG1Draft.X` becomes the name given in its docstring.

Three kinds of declaration appear.

* **Named witnesses.** Today's private witness machines, made public under the names below.
  Where the body is short it is reproduced verbatim from its home file, so that facts such as
  the tape count hold by `rfl`; the long ones (`loopHostTM`, `callTM`, `pairMapSndTM`,
  `polyUnaryEngineTM`) are `sorry` here and keep their existing bodies on landing.
* **Spec theorems** (`sorry` here). Each states, about the named witness, exactly what today's
  proofs establish: a time bound with an explicit constant and, where the witness has its own
  space argument, a space bound (five witnesses here, seven in the full design). On landing
  their proofs are the existing private lemmas, or the new proofs that the `f2_` region of
  `Build/Catalog.lean` holds today, moved next to the witness.

  `type_of% @<landed row>`, the landed row's own type, and proves it from the spec theorems.
  The draft therefore elaborates only if every listed row keeps its statement unchanged while
  becoming a corollary; this is the mechanical form of "consumers untouched".

The spec theorems are stated in the library's existing style (`ComputesFunInTime`,
`spaceUsed`, `Cfg.ofWords` seams), not as `Turing.Contract` instances; `MIG1-design.md`
records why.

/-! ### Catalog: space from time -/

/-- **Space from time** (landing: `Turing.FinTM.ComputesInTime.spaceUsed_le`, public in
`Build/Catalog.lean`, replacing the private `f2_space_of_time`). If `M` halts on `x` with
output `y` within `T` steps, then at every time `t` its work tapes have visited at most
`M.k · (T + 1)` cells in all. [AB09, Definition 4.1 and the remark opening the proof of
Theorem 4.2: a machine running in time `T` visits at most `T + 1` cells per tape.]

**Proof sketch.** After the halt the configuration no longer changes, so every head position
at any time `t` already occurs at some time `u ≤ T`. Each tape's visited set is therefore
contained in the image of `{0, …, T}`, which has at most `T + 1` elements; sum over the `k`
tapes. -/
theorem spaceUsed_le_of_computesInTime {M : FinTM Bool} {x y : List Bool} {T : ℕ}
    (h : M.ComputesInTime x y T) (t : ℕ) :
    M.tm.spaceUsed (M.tm.initCfg x) t ≤ M.k * (T + 1) := by
  have hh := ((computesInTime_iff _ _ _ _).mp h).1
  have hsub (i : Fin M.k) :
      M.tm.visitedByTapeHead (M.tm.initCfg x) t i ⊆
        M.tm.visitedByTapeHead (M.tm.initCfg x) T i := by
    intro z hz
    obtain ⟨u, _, rfl⟩ := Finset.mem_image.mp hz
    by_cases hu : u ≤ T
    · exact Finset.mem_image.mpr ⟨u, Finset.mem_range.mpr (by omega), rfl⟩
    · have hr : M.tm.runFrom (M.tm.initCfg x) u =
          M.tm.runFrom (M.tm.initCfg x) T := by
        rw [show u = T + (u - T) by omega, MultiTapeTM.runFrom_add,
          MultiTapeTM.runFrom_of_halt _ hh]
      exact Finset.mem_image.mpr ⟨T, Finset.mem_range.mpr (by omega),
        congrArg (fun c => c.workTapePos i) hr.symm⟩
  calc
    _ ≤ ∑ _i : Fin M.k, (T + 1) := by
      apply Finset.sum_le_sum
      intro i _
      exact (Finset.card_le_card (hsub i)).trans (by
        unfold MultiTapeTM.visitedByTapeHead
        exact (Finset.card_image_le).trans (by rw [Finset.card_range]))
    _ = _ := by simp

/-! ### Composition: the copy and constant machines -/

/-- **The copy machine** (landing: `Turing.FinTM.idTM`, public in
`TuringMachine/Composition.lean`; today the private witness of
`Turing.FinTM.computesFunInTime_id`, copied into `Build/Catalog.lean` as `f2_idTM`). A machine
with no work tapes that writes each input symbol to its output while moving right, and halts
on the first blank. [AB09, §1.2] -/
def idTM : FinTM Bool where
  k := 0
  State := Unit
  tm :=
    { q₀ := ()
      tr := fun _ inp _ =>
        match inp with
        | some b => ⟨SignType.pos, fun i => i.elim0, some b, some ()⟩
        | none => ⟨SignType.zero, fun i => i.elim0, none, none⟩ }

/-- The copy machine has no work tapes. -/
theorem idTM_k : idTM.k = 0 := rfl

/-- **The copy machine's time** (landing: `Turing.FinTM.idTM_computes`, in `Composition`). On
input `x` the copy machine halts after exactly `|x| + 1` steps with output `x`.

**Proof sketch.** By induction on `t ≤ |x|`, after `t` steps the machine is live, its input
head is at cell `t + 1` and it has written the first `t` input symbols (today's private
`idTM_run`). At `t = |x|` the head reads the blank after the input, and the next step halts
without writing. This is the body of today's `computesFunInTime_id`, before its weakening. -/
theorem idTM_computes (x : List Bool) : idTM.ComputesInTime x x (x.length + 1) := by
  sorry

/-- **The constant machine** (landing: `Turing.FinTM.constTM`, public in `Composition`; today
private there and copied as `f2_constTM`). A machine with no work tapes whose states form a
chain that writes the fixed word `w`, one symbol per step, ignoring its input, then halts.
[AB09, §1.2] -/
def constTM (w : List Bool) : FinTM Bool where
  k := 0
  State := Fin (w.length + 1)
  tm := { q₀ := 0, tr := fun i _ _ => emitAction w id i }

/-- The constant machine has no work tapes. -/
theorem constTM_k (w : List Bool) : (constTM w).k = 0 := rfl

/-- **The constant machine's time** (landing: `Turing.FinTM.constTM_computes`, in
`Composition`). On every input the constant machine halts after exactly `|w| + 1` steps with
output `w`.

**Proof sketch.** The emission chain writes `w` in `|w|` steps (`Turing.FinTM.emit_halts`) and
halts on the next, with the output appended to the initially empty tape. -/
theorem constTM_computes (w x : List Bool) :
    (constTM w).ComputesInTime x w (w.length + 1) := by
  sorry

/-! ### TimeConstructible: the binary length counter -/

/-- One carry transition of the length counter, the first one also advancing the input
(verbatim from `ClassP/TimeConstructible.lean`'s private `counterBump`, which stays private). -/
private def lengthBitsBump (d : SignType) (w : Option Bool) : Action 1 Bool (Fin 4) :=
  if w = some true then
    ⟨d, fun _ => (some (some false), .pos), none, some 1⟩
  else ⟨d, fun _ => (some (some true), .neg), none, some 2⟩

/-- **The binary length counter** (landing: `Turing.FinTM.lengthBitsTM`, public in
`ClassP/TimeConstructible.lean`; today the private `Complexity.counterTM`, copied into Catalog
as `f2_counterTM`). A one-work-tape machine that keeps a little-endian binary counter on its
work tape, increments it once per input symbol, and on the blank after the input emits the
counter's bits and halts, so that it computes `x ↦ Nat.bits |x|`. States: count `0`, carry
`1`, rewind `2`, emit `3`. [AB09, §1.3, the examples of time-constructible functions] -/
def lengthBitsTM : FinTM Bool where
  k := 1
  State := Fin 4
  tm :=
    { q₀ := 0
      tr := fun q inp work =>
        if q = 0 then
          match inp with
          | none => ⟨.zero, fun _ => (none, .zero), none, some 3⟩
          | some _ => lengthBitsBump .pos (work 0)
        else if q = 1 then lengthBitsBump .zero (work 0)
        else if q = 2 then
          match work 0 with
          | none => ⟨.zero, fun _ => (none, .pos), none, some 0⟩
          | some _ => ⟨.zero, fun _ => (none, .neg), none, some 2⟩
        else
          match work 0 with
          | none => ⟨.zero, fun _ => (none, .zero), none, none⟩
          | some b => ⟨.zero, fun _ => (none, .pos), some b, some 3⟩ }

/-- **The length counter's time** (landing: `Turing.FinTM.lengthBitsTM_computes`, in
`TimeConstructible`). The counter computes `x ↦ Nat.bits |x|` within `5·(|x| + 1)` steps.
[AB09, §1.3]

**Proof sketch.** Today's proof of `Complexity.timeConstructible_id`: with twice the number of
`true` counter bits as potential, elapsed time plus potential is at most `4n` after `n`
increments; entering emission and the final halt add two steps, and the emitted word, of
length at most `n`, costs one step per bit. -/
theorem lengthBitsTM_computes :
    lengthBitsTM.ComputesFunInTime (fun x => Nat.bits x.length) (fun n => 5 * (n + 1)) := by
  sorry

/-- **The length counter's space** (landing: `Turing.FinTM.lengthBitsTM_spaceUsed`, in
`TimeConstructible`; today Catalog's `f2_counter_space`). At every time, the counter's work
tape has visited at most `5·(Nat.size |x| + 1)` cells: logarithmic space.

**Proof sketch.** Every counting round returns the head to the origin, and a carry walks at
most the counter's binary width, which never exceeds `Nat.size |x|`; emission walks the stored
word once. So at every time the head is within `2·(Nat.size |x| + 1)` of the origin (today's
`f2_counter_heads`, from the increment ledger `f2_counter_count_space`, both moved), and the
tape visits at most `4·(Nat.size |x| + 1) + 1 ≤ 5·(Nat.size |x| + 1)` cells. -/
theorem lengthBitsTM_spaceUsed (x : List Bool) (t : ℕ) :
    lengthBitsTM.tm.spaceUsed (lengthBitsTM.tm.initCfg x) t ≤ 5 * (Nat.size x.length + 1) := by
  sorry

/-- **Row** `Complexity.timeConstructible_id`, statement unchanged. -/
theorem row_timeConstructible_id : type_of% @Complexity.timeConstructible_id :=
  ⟨fun n => le_refl n, 5, by decide, lengthBitsTM, lengthBitsTM_computes⟩

/-- **Row** `Turing.FinTM.computesFunInTime_lengthBits` (Primitives), statement unchanged. -/
theorem row_computesFunInTime_lengthBits :
    type_of% @Turing.FinTM.computesFunInTime_lengthBits :=
  ⟨lengthBitsTM, 5, lengthBitsTM_computes⟩

/-- **Space row** `Turing.FinTM.computesFunInTime_lengthBits_spaceUsed` (Catalog), statement
unchanged. Replaces the 23 copied or new `f2_counter*` declarations. -/
theorem row_computesFunInTime_lengthBits_spaceUsed :
    type_of% @Turing.FinTM.computesFunInTime_lengthBits_spaceUsed :=
  ⟨lengthBitsTM, 5, lengthBitsTM_computes, lengthBitsTM_spaceUsed⟩

/-! ### Primitives: the pair extractor -/

/-- **The pair extractor** (landing: `Turing.FinTM.pairExtractTM`, public in
`Build/Primitives.lean`; today private there and copied as `f2_pairExtractTM`). On an input
`pairEncode a b` it validates the doubled prefix while buffering `a` on its one work tape,
then emits `a` if `first` and the suffix `b` if `second`; on a malformed input it halts with
empty output. One machine serves the first-component, second-component and concatenation
rows (P6, P13). -/
def pairExtractTM (first second : Bool) : FinTM Bool where
  k := 1
  State := Option Bool ⊕ Fin 3
  tm :=
    { q₀ := .inl none
      tr := fun q inp work => match q with
        | .inl none => match inp with
          | some b => ⟨.pos, fun _ => (none, 0), none, some (.inl (some b))⟩
          | none => ⟨0, fun _ => (none, 0), none, none⟩
        | .inl (some b) => match inp with
          | none => ⟨0, fun _ => (none, 0), none, none⟩
          | some c =>
            if b = c then
              ⟨.pos, fun _ => (some (some b), .pos), none, some (.inl none)⟩
            else if b then ⟨.pos, fun _ => (none, 0), none, none⟩
            else ⟨.pos, fun _ => (none, .neg), none, some (.inr 0)⟩
        | .inr q => match q.val with
          | 0 => match work 0 with
            | some _ => ⟨0, fun _ => (none, .neg), none, some (.inr 0)⟩
            | none => ⟨0, fun _ => (none, .pos), none, some (.inr 1)⟩
          | 1 => match work 0 with
            | some b => ⟨0, fun _ => (none, .pos), if first then some b else none, some (.inr 1)⟩
            | none => ⟨0, fun _ => (none, 0), none, some (.inr 2)⟩
          | _ => if second then match inp with
              | some b => ⟨.pos, fun _ => (none, 0), some b, some (.inr 2)⟩
              | none => ⟨0, fun _ => (none, 0), none, none⟩
            else ⟨0, fun _ => (none, 0), none, none⟩ }

/-- The pair extractor has one work tape. -/
theorem pairExtractTM_k (first second : Bool) : (pairExtractTM first second).k = 1 := rfl

/-- **The pair extractor's time** (landing: `Turing.FinTM.pairExtractTM_computes`, in
`Primitives`; today the private `pairExtract_computes`). On every input the extractor halts
within `5·(|x| + 1)` steps; its output is the selected components of the decoded pair, and
empty when the input is not a pair encoding.

**Proof sketch.** Today's `pairExtract_computes`, made public: the aligned scan reads the
doubled prefix two cells at a time while buffering, the separator turns it into a rewind of the
buffer, the replay emits `a`, and the suffix copy emits `b`; each phase is linear in `|x|`. -/
theorem pairExtractTM_computes (first second : Bool) (x : List Bool) :
    (pairExtractTM first second).ComputesInTime x
      (match pairDecode x with
        | some (a, b) => (if first then a else []) ++ (if second then b else [])
        | none => []) (5 * (x.length + 1)) := by
  sorry

/-- **First component** (landing: `Turing.FinTM.pairExtractTM_fst`, in `Primitives`). The
extractor at `(true, false)` computes the first component of a decoded pair, and `[]` on a
malformed input, within `5·(n + 1)`.

**Proof sketch.** Specialize `pairExtractTM_computes` and split on the decoding. -/
theorem pairExtractTM_fst :
    (pairExtractTM true false).ComputesFunInTime
      (fun x => ((pairDecode x).map Prod.fst).getD []) (fun n => 5 * (n + 1)) := by
  intro x
  have h := pairExtractTM_computes true false x
  cases hd : pairDecode x with
  | none => simpa [hd] using h
  | some p => cases p; simpa [hd] using h

/-- **Second component** (landing: `Turing.FinTM.pairExtractTM_snd`, in `Primitives`). The
extractor at `(false, true)` computes the second component of a decoded pair, and `[]` on a
malformed input, within `5·(n + 1)`.

**Proof sketch.** Specialize `pairExtractTM_computes` and split on the decoding. -/
theorem pairExtractTM_snd :
    (pairExtractTM false true).ComputesFunInTime
      (fun x => ((pairDecode x).map Prod.snd).getD []) (fun n => 5 * (n + 1)) := by
  intro x
  have h := pairExtractTM_computes false true x
  cases hd : pairDecode x with

  | some p => cases p; simpa [hd] using h

/-! ### Primitives: the unary polynomial generator -/

/-- **The unary polynomial engine** (landing: today's private `catalogPolyUnaryTM d C` of
`Build/Primitives.lean`, which may stay private; copied into Catalog as
`f2_catalogPolyUnaryTM`). Its `d + 1` nested unary loop tapes, each installed by one input
scan, run an odometer of side `|x| + 1` and emit `C` ones per tick, writing
`C·(|x| + 1)^(d + 1)` ones. `sorry` here: the landed body is unchanged. -/
def polyUnaryEngineTM (d C : ℕ) : FinTM Bool := sorry

/-- **The unary polynomial generator** (landing: `Turing.FinTM.polyUnaryTM`, public in
`Primitives`). The machine that writes `C·(|x| + 1)^e` ones: the constant machine for
`e = 0`, and the unary engine for `e = d + 1`. Today the same case split is made inside the
proofs of `computesFunInTime_polyUnary` and of Catalog's `f2_unary_sharp`. -/
def polyUnaryTM (C : ℕ) : ℕ → FinTM Bool
  | 0 => constTM (List.replicate C true)
  | d + 1 => polyUnaryEngineTM d C

/-- **The unary generator's time** (landing: `Turing.FinTM.polyUnaryTM_computes`, in
`Primitives`). The generator writes `C·(|x| + 1)^e` ones within
`(C + 5e + 4)·((|x| + 1)^e + |x| + 1)` steps; the sharp degree `e`, with a linear allowance,
is what the threaded length check consumes.

**Proof sketch.** For `e = 0`, `constTM_computes` gives `C + 1` steps. For `e = d + 1`,
today's `catalogPoly_unary_computes` gives `(C + 5(d + 1) + 4)·(|x| + 1)^(d + 1)`; both are
below the stated bound (today's `f2_unary_sharp`). -/
theorem polyUnaryTM_computes (C e : ℕ) :
    (polyUnaryTM C e).ComputesFunInTime
      (fun x => List.replicate (C * (x.length + 1) ^ e) true)
      (fun n => (C + 5 * e + 4) * ((n + 1) ^ e + n + 1)) := by
  sorry

/-- **The unary generator's space** (landing: `Turing.FinTM.polyUnaryTM_spaceUsed`, in
`Primitives`; today Catalog's `f2_poly_space`). At every time the generator has visited at
most `5e·(|x| + 1)` work cells: each of its loop tapes holds a unary counter of side
`|x| + 1`.

**Proof sketch.** For `e = 0` there are no work tapes. For `e = d + 1`, every head starts at
the origin and moves by unit steps inside `[-1, |x| + 1]` on its loop tape (the install scan
and the in-place odometer revisits; today's `f2_polyHeads_bounds` and `f2_poly_step`), so each
of the `d + 1` loop tapes and the administrative tapes contributes a bounded multiple of
`|x| + 1`. -/
theorem polyUnaryTM_spaceUsed (C e : ℕ) (x : List Bool) (t : ℕ) :
    (polyUnaryTM C e).tm.spaceUsed ((polyUnaryTM C e).tm.initCfg x) t ≤
      5 * e * (x.length + 1) := by
  sorry

/-- The sharp unary bound is below the row's polynomial bound: for every `n`,
`a·((n + 1)^e + n + 1) ≤ 2a·(n + 1)^(e + 1)`.

**Proof sketch.** Both `(n + 1)^e` and `n + 1` are at most `(n + 1)^(e + 1)`. -/
theorem polyUnary_bound_le (a e n : ℕ) :
    a * ((n + 1) ^ e + n + 1) ≤ 2 * a * (n + 1) ^ (e + 1) := by
  have h1 : (n + 1) ^ e ≤ (n + 1) ^ (e + 1) :=
    Nat.pow_le_pow_right (Nat.succ_pos n) (Nat.le_succ e)
  have h2 : n + 1 ≤ (n + 1) ^ (e + 1) := by
    calc n + 1 = (n + 1) ^ 1 := (pow_one _).symm
      _ ≤ (n + 1) ^ (e + 1) := Nat.pow_le_pow_right (Nat.succ_pos n) (by omega)
  calc a * ((n + 1) ^ e + n + 1) ≤ a * (2 * (n + 1) ^ (e + 1)) :=
        Nat.mul_le_mul_left _ (by omega)
    _ = 2 * a * (n + 1) ^ (e + 1) := by ring

/-- **Row** `Turing.FinTM.computesFunInTime_polyUnary`, statement unchanged. -/

/-- The decider padded with the idle branch tapes (verbatim from `Build/Wrappers.lean`'s
private `timedPadTM`, which stays private). -/
private def timedPadTM (D : FinTM Bool) (r : ℕ) : MultiTapeTM (D.k + r) Bool D.State where
  q₀ := D.tm.q₀
  tr q inp work := leftAction r id (D.tm.tr q inp (fun i => work (Fin.castAdd r i)))

/-- **The timed conditional** (landing: `Turing.FinTM.timedCondTM`, public in
`Build/Wrappers.lean`; today private there and copied into Catalog as `f2_timedCondTM`). Run
the decider `D` with its output captured on the last tape, step back to read the verdict,
rewind the input, then run `M₁` or `M₂`, as the verdict says, on its own untouched tape bank.
(W3; [AB09, §1.2] for the model.) -/
def timedCondTM (D M₁ M₂ : FinTM Bool) : FinTM Bool where
  k := (D.k + (M₁.k + M₂.k)) + 1
  State := D.State ⊕ (Bool ⊕ ((Bool × Bool) ⊕ (M₁.State ⊕ M₂.State)))
  tm :=
    { q₀ := .inl D.tm.q₀
      tr := fun q inp work => match q with
        | .inl q => captureAction Sum.inl (.inr (.inl false))
            ((timedPadTM D (M₁.k + M₂.k)).tr q inp (fun i => work i.castSucc))
        | .inr (.inl false) =>
          ⟨0, (fun i => if (i : ℕ) < D.k + (M₁.k + M₂.k) then (none, 0)
            else (none, .neg)), none, some (.inr (.inl true))⟩
        | .inr (.inl true) => controlAction 0
            (some (.inr (.inr (.inl ((work (Fin.last _)).getD false, false)))))
        | .inr (.inr (.inl (b, false))) =>
            controlAction .neg (some (.inr (.inr (.inl (b, true)))))
        | .inr (.inr (.inl (b, true))) => match inp with
          | some _ => controlAction .neg (some (.inr (.inr (.inl (b, true)))))
          | none => controlAction .pos
              (some (.inr (.inr (.inr (branchTM M₁ M₂ b).tm.q₀))))
        | .inr (.inr (.inr q)) => leftAction 1 id
            (rightAction D.k (fun s => .inr (.inr (.inr s)))
              ((branchTM M₁ M₂ false).tm.tr q inp
                (fun i => work (Fin.natAdd D.k i).castSucc))) }
