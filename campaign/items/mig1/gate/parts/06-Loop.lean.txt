/-- **The loop host** (landing: `Turing.FinTM.loopHostTM`, made public in place at
`Build/Loop.lean:649`, today the private abbreviation `loopHost`, body unchanged; Catalog holds
an older copy, `f2_loopHost`, from before the forwarding flag). The decision and find host of
the bounded loop: it runs the fuel machine `F` with its output captured, copies the fuel word
`Nat.bits R` into a fixed-width counter, rewinds, starts `body`, and then alternates captured
body rounds from the `anchor` seam with fixed-width debits of the counter (the first anchor
entry is free). An accepting round halts with `[true]`, or in find mode replays the round's own
output; underflow of the counter halts with `[false]`, or with nothing in find mode. It is the
non-forwarding instance `loopHostM body F anchor false findMode` of the shared controller. -/
-- @@verbatim Loop Loop --public --nodoc loopHost

/-- **The loop host's configuration contract** (landing: `Turing.FinTM.loopHostTM_contracts`,
new in `Loop` after `loopHost_contracts`). Given a fuel machine for `Nat.bits (R |x|)` within
`T`, an invariant `Inv` that holds at `s0 x` and is preserved by `stepF`, a body startup that
reaches the `anchor` seam of `s0 x` within `T |x|` without visiting the anchor earlier, and body
rounds that, from the seam of an invariant word `s`, take positive time at most `T |x|`, do not
revisit the anchor in between, and either halt with output `out x s` (when `acceptF x s`) or
reach the seam of `stepF x s`: then for every input `x` the host has a family `cfg` of round
configurations with a startup of at most `10·(T |x| + 1)` steps reaching `cfg 0`, empty output
at rounds `0, …, R |x|`, a halted terminal `cfg (R |x| + 1)` with output `[false]` (`[]` in
find mode), and, for each round `i ≤ R |x|`, a segment of at most `10·(T |x| + 1)` steps that
halts with output `[true]` (the round's output in find mode) if orbit point `i` is accepted,
and otherwise reaches `cfg (i + 1)`. The coefficient `10` is today's `loopHost_bound`.

**Proof sketch.** Today's private `loopHost_contracts` (`Build/Loop.lean:2066`), whose proof
opens with `refine ⟨loopHost_bound, ?_⟩`, `loopHost_bound = max 1 (max 9 (3 + 2 + 5)) = 10`:
the fuel phase and the body startup give the startup (`loopHost_prepare`, `loopHost_start`);
each segment is one captured body round followed by a debit and rewind of the counter, whose
width never exceeds `T |x|` (`loop_fuel_width`), so every phase costs a constant multiple of
`T |x| + 1` (`loopHost_round`); the last debit underflows into the terminal. -/
theorem loopHostTM_contracts (body F : FinTM Bool) (anchor : body.State)
    (Inv : List Bool → List Bool → Prop)
    (stepF : List Bool → List Bool → List Bool)
    (acceptF : List Bool → List Bool → Bool)
    (out : List Bool → List Bool → List Bool) (findMode : Bool)
    (s0 : List Bool → List Bool) (R T : ℕ → ℕ)
    (hF : F.ComputesFunInTime (fun x => Nat.bits (R x.length)) T)
    (hInv0 : ∀ x : List Bool, Inv x (s0 x))
    (hInvStep : ∀ (x s : List Bool), Inv x s → Inv x (stepF x s))
    (hstart : ∀ x : List Bool, ∃ t ≤ T x.length,
      (∀ t' < t,
        (body.tm.runFrom (body.tm.initCfg x) t').state ≠ some anchor) ∧
      body.tm.runFrom (body.tm.initCfg x) t =
        Cfg.ofWords anchor (stateWord body.k (s0 x)))
    (hround : ∀ (x s : List Bool), Inv x s →
      ∃ t, 0 < t ∧ t ≤ T x.length ∧
        (∀ t', 0 < t' → t' < t →
          (body.tm.runFrom
            (Cfg.ofWords (input := x) anchor (stateWord body.k s)) t').state
              ≠ some anchor) ∧
        if acceptF x s then
          (body.tm.runFrom
            (Cfg.ofWords (input := x) anchor (stateWord body.k s)) t).state
              = none ∧
          (body.tm.runFrom
            (Cfg.ofWords (input := x) anchor (stateWord body.k s)) t).output
              = out x s
        else
          body.tm.runFrom
            (Cfg.ofWords (input := x) anchor (stateWord body.k s)) t =
              Cfg.ofWords anchor (stateWord body.k (stepF x s))) :
    ∀ x : List Bool,
      ∃ (cfg : ℕ → Cfg (loopHostTM body F anchor findMode).k Bool
          (loopHostTM body F anchor findMode).State x) (startup : ℕ),
        startup ≤ 10 * (T x.length + 1) ∧
        (loopHostTM body F anchor findMode).tm.runFrom
          ((loopHostTM body F anchor findMode).tm.initCfg x) startup = cfg 0 ∧
        (∀ i ≤ R x.length, (cfg i).output = []) ∧
        (cfg (R x.length + 1)).state = none ∧
        (cfg (R x.length + 1)).output = (if findMode then [] else [false]) ∧
        (∀ i ≤ R x.length, ∃ t ≤ 10 * (T x.length + 1),
          if acceptF x ((stepF x)^[i] (s0 x)) then
            ((loopHostTM body F anchor findMode).tm.runFrom (cfg i) t).state = none ∧
            ((loopHostTM body F anchor findMode).tm.runFrom (cfg i) t).output =
              (if findMode then out x ((stepF x)^[i] (s0 x)) else [true])
          else (loopHostTM body F anchor findMode).tm.runFrom (cfg i) t = cfg (i + 1)) := by
  sorry

/-- **The clean call** (landing: `Turing.FinTM.callTM`, made public in place at
`Build/Loop.lean:3897`, today the private `emCallTM`, body unchanged). From the entry seam holding
an argument word on tape `0`, it runs `M` on that argument through tracked banks with `M`'s
output captured, clears every bank to its observed extent, and then either installs the result
in place of the argument (`emit = false`) or forwards it to the physical output and keeps the
argument (`emit = true`), erases its administrative storage, and enters its exit state. -/
-- @@verbatim Loop Loop --public --nodoc emCallTM

/-- **The clean call's entry state** (landing: `Turing.FinTM.callEntry`, new in `Loop` after

/-- **The clean call's exit state** (landing: `Turing.FinTM.callExit`, new in `Loop` after

exit anchor of the finishing phase; it is a different summand of the state type from
`callEntry`. -/
def callExit (M : FinTM Bool) (emit : Bool) : (callTM M emit).State := .inr (.inr 5)

/-- **The clean call has a tape** (landing: `Turing.FinTM.callTM_k_pos`, new in `Loop`). The

**Proof sketch.** The layout's tape count is a successor; `Nat.zero_lt_succ`. -/
theorem callTM_k_pos (M : FinTM Bool) (emit : Bool) : 0 < (callTM M emit).k :=
  Nat.zero_lt_succ _
