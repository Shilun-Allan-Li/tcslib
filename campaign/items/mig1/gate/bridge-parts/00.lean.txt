/-!
# MIG-1 bridge and duplicate probe (not landed)

1. **The loop-host bridge** (design §11, risk 1). Catalog's 21 modified loop-host copies are
   stated for `f2_loopHost`, copied from an older `Build/Loop.lean` before the forwarding flag.
   With verbatim copies of both definition families, `rfl` shows that the old host is the
   current shared controller at `forward = false`, so the moved budget proofs can be re-targeted
   at `loopHostM _ _ _ false` (today's `loopHost`, the gate's `loopHostTM`) by rewriting alone.
2. **Duplicates of existing public declarations.** Four private Catalog lemmas of the region
   have the statements of `Fin.sum_univ_add` (Mathlib), `Turing.MultiTapeTM.timed_input_bound`
   and `Turing.eq_pairEncode_of_pairDecode`; each `example` proves the copied statement
   (verbatim) by the public declaration in one term.

## References

* [AB09] S. Arora, B. Barak, *Computational Complexity: A Modern Approach*,
  Cambridge University Press, 2009. (§1.2: the machine model.)
-/

/-- The old host is the shared controller with the forwarding flag off, definitionally. -/
example (body F : FinTM Bool) (anchor : body.State) (findMode : Bool) :
    f2_loopHost body F anchor findMode = loopHostM body F anchor false findMode := rfl

/-- `f2_sum_add` (`Build/Catalog.lean:10468`) is `Fin.sum_univ_add`. -/
example {a b : ℕ} (f : Fin (a + b) → ℕ) :
    (∑ i : Fin (a + b), f i) =
      (∑ i : Fin a, f (Fin.castAdd b i)) + ∑ i : Fin b, f (Fin.natAdd a i) :=
  Fin.sum_univ_add f

/-- `f2_loop_input_run_le` (`Build/Catalog.lean:6126`) is `MultiTapeTM.timed_input_bound`. -/
example {k : ℕ} {S : Type*} {x : List Bool}
    (tm : MultiTapeTM k Bool S) (c : Cfg k Bool S x) (t : ℕ) :
    (tm.runFrom c t).inputPos.val ≤ c.inputPos.val + t :=
  tm.timed_input_bound c t

/-- `f2_catalogPair_inverse` (`Build/Catalog.lean:4166`) is `Turing.eq_pairEncode_of_pairDecode`
with its binders reordered. -/
example (x : List Bool) :
    ∀ a v, pairDecode x = some (a, v) → x = pairEncode a v :=
  fun a v h => Turing.eq_pairEncode_of_pairDecode x a v h
