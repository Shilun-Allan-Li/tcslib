# RD-2 statement draft: the closed-form configuration codec and the H6 kit

A sorried statement draft for backlog item RD-2 (`machine-library-design.md` §16b item 2 and
§14 row H6). It proposes three things, each in its own section, all inside the scratch
namespace `Complexity.Draft.RD2` so that nothing clashes with the tree:

1. **The H6 kit** (`FormulaKit`): fixed-arity gate templates given by an explicit truth table,
   their closed-form wiring, the exactly-one gadget, the clause-and-literal cost ledger, and
   the uniform-emission theorems (a polynomial-time family of clause groups serializes in
   polynomial time). Intended home: a new topic `TCSlib/Complexity/FormulaKit/`.
2. **Tseitin after the prefix**: the generalized prefix semantics `QBF.PrefixTruth`, and the
   theorem that appending existentially quantified Tseitin gate variables after an arbitrary
   quantifier prefix preserves truth, over `BoolCircuit.DAGCircuit.toCNF`.
3. **The restated Claim 4.4(2)** (`ConfigCodec`): public definitions of the configuration codec
   and its three CNFs (validity, adjacency, acceptance) with closed-form variable indexing and
   explicitly ordered clause lists, and theorems about them in place of

   uniformity (polynomial-time emission) theorems that the packaged existential could not
   supply. A corollary recovers an existential of the old shape.

Definitions carry real bodies; nontrivial theorems are `sorry` with a proof sketch.

/-! ## 1. The H6 kit: gates, layouts and ledgers (intended `FormulaKit/Gate.lean`) -/

namespace FormulaKit

/-- **Block variable**: the `i`-th variable of the `t`-th block of `width` consecutive
variables placed after `base` variables, `base + t · width + i`. The packing of [AB09,
Lemma 2.11]'s snapshot variables (Cook-Levin's private `clPack`), and the level-blocked
layout of the `ψᵢ` variables of [AB09, Theorem 4.13]. -/
def blockVar (base width t i : ℕ) : ℕ := base + t * width + i

/-- The low `ℓ` bits of `r`, as an assignment to `Fin ℓ` (bit `i` is `r.testBit i`). -/
def bitsOf (ℓ r : ℕ) : Fin ℓ → Bool := fun i => r.testBit i.val

/-- The clause over variables `0, …, ℓ - 1` that is false exactly at the assignment `v`
([AB09, Claim 2.13]: the literal on `i` has polarity `!v i`). -/
def excludeClause (ℓ : ℕ) (v : Fin ℓ → Bool) : CNF.Clause ℕ :=
  List.ofFn fun i => (i.val, !v i)

/-- **The truth-table template** of a fixed-arity Boolean predicate `p` ([AB09, Claim 2.13]):
one excluding clause for every falsifying row, the rows taken in the order `r = 0, …,
2^ℓ - 1` of their binary values. Deviation from the private `clTemplate` and
`codecLocalCheck`: the clause list is an explicit function of `ℓ` and `p`, not a choice from
`Complexity.exists_cnf_boolFun`, so an emitter's output can be compared with it literally. -/
def template (ℓ : ℕ) (p : (Fin ℓ → Bool) → Bool) : CNF ℕ :=
  (List.range (2 ^ ℓ)).filterMap fun r =>
    if p (bitsOf ℓ r) then none else some (excludeClause ℓ (bitsOf ℓ r))

/-- **The template computes its predicate** ([AB09, Claim 2.13]): under any assignment `a`,
the truth-table template of `p` evaluates to `p` of `a`'s first `ℓ` values.

**Proof sketch.** The restriction of `a` to `Fin ℓ` is `bitsOf ℓ r` for the unique `r < 2^ℓ`
whose bits it lists (`Nat.testBit` of the sum of its powers of two). An excluding clause is
false at `a` exactly when its row is that restriction. So the template is false at `a` iff
that row was kept, i.e. iff `p` is false there. -/
theorem template_eval (ℓ : ℕ) (p : (Fin ℓ → Bool) → Bool) (a : ℕ → Bool) :
    (template ℓ p).eval a = p (fun i => a i.val) := by
  sorry

/-- The template mentions only variables below its arity. -/
theorem template_numVars_le (ℓ : ℕ) (p : (Fin ℓ → Bool) → Bool) :
    (template ℓ p).numVars ≤ ℓ := by
  sorry

/-- The template has at most one clause per row of the truth table, so at most `2^ℓ`. -/
theorem template_length_le (ℓ : ℕ) (p : (Fin ℓ → Bool) → Bool) :
    (template ℓ p).length ≤ 2 ^ ℓ := by
  sorry

/-- Every template clause has exactly `ℓ` literals, so the template is an `ℓ`-CNF. -/
theorem template_widthAtMost (ℓ : ℕ) (p : (Fin ℓ → Bool) → Bool) :
    (template ℓ p).WidthAtMost ℓ := by
  sorry

/-- **A variable bound gives a `numVars` bound**: if every literal of `φ` is on a variable
below `N`, then `φ.numVars ≤ N` (the private `foldr_max_le_of_forall` of `Formulas/CNF.lean`
and `codecCnf_numVars` of `TQBF.lean`, made public). -/
theorem numVars_le_of_forall_lt (φ : CNF ℕ) (N : ℕ) (h : ∀ C ∈ φ, ∀ l ∈ C, l.1 < N) :
    φ.numVars ≤ N := by
  sorry

/-- **A gate**: the template of `p` with its variable `j` wired to the global variable
`wire j`. Repeated wire values are allowed. The snapshot-keyed local gate of design §14 row
H6: Cook-Levin's `clGroup` and the configuration codec's `transitionGate` are instances. -/
def gate (ℓ : ℕ) (p : (Fin ℓ → Bool) → Bool) (wire : ℕ → ℕ) : CNF ℕ :=
  (template ℓ p).relabel wire

/-- **A gate computes its predicate on its wires**: the gate evaluates under `a` to `p` of
the values `a (wire j)`. -/
theorem gate_eval (ℓ : ℕ) (p : (Fin ℓ → Bool) → Bool) (wire : ℕ → ℕ) (a : ℕ → Bool) :
    (gate ℓ p wire).eval a = p (fun i => a (wire i.val)) := by
  rw [gate, CNF.eval_relabel, template_eval]
  rfl

/-- Total read of an `ℓ`-bit assignment at a natural-number position (`false` outside). -/
def readBit {ℓ : ℕ} (v : Fin ℓ → Bool) (j : ℕ) : Bool :=
  if h : j < ℓ then v ⟨j, h⟩ else false

/-- **Exactly one of the listed variables is true**, without auxiliary variables: one
positive clause over the list and, for each ordered pair of distinct entries, one exclusion
clause. The clause order is the list order (the private `codecOneHot` took
`Finset.univ.toList`, whose order is unspecified). -/
def exactlyOne (vs : List ℕ) : CNF ℕ :=
  [vs.map fun v => (v, true)] ++
    vs.flatMap fun v => (vs.filter fun w => w != v).map fun w => [(v, false), (w, false)]

/-- **Exactly-one semantics**: the gadget holds iff some listed variable `j` is true and
every listed variable equals the test "is `j`".

**Proof sketch.** The positive clause supplies a true entry `j`; the exclusion clause of
`(j, v)` forces every other entry false. Conversely a single true entry satisfies the
positive clause and every exclusion (the private `codecOneHot_eval`, over a list). -/
theorem exactlyOne_eval (vs : List ℕ) (a : ℕ → Bool) :
    (exactlyOne vs).eval a = true ↔ ∃ j ∈ vs, ∀ v ∈ vs, a v = decide (v = j) := by
  sorry

/-- **Clause-and-literal cost**: literal occurrences plus one per clause, so that empty
clauses are counted (the private `codecCnfCost`). -/
def cost (φ : CNF ℕ) : ℕ := (φ.map fun C => C.length + 1).sum

/-- **Serialization ledger**: if every variable of `φ` is below `N`, the chapter-2
serialization of `φ` has at most `cost φ · (N + 3) + 1` bits (the private
`codecCnf_serialize`).

**Proof sketch.** A literal below `N` serializes to at most `N + 2` bits; a clause adds its
marker and terminator, both charged to its extra cost unit; the formula adds one
terminator. -/
theorem serialize_length_le (φ : CNF ℕ) (N : ℕ) (h : ∀ C ∈ φ, ∀ l ∈ C, l.1 < N) :
    (CNF.serialize φ).length ≤ cost φ * (N + 3) + 1 := by
  sorry

/-- A gate costs at most `2^ℓ · (ℓ + 1)`, whatever its wiring. -/
theorem gate_cost_le (ℓ : ℕ) (p : (Fin ℓ → Bool) → Bool) (wire : ℕ → ℕ) :
    cost (gate ℓ p wire) ≤ 2 ^ ℓ * (ℓ + 1) := by
  sorry

/-- The exactly-one gadget over `m` variables costs at most `m + 1 + 3m²`. -/
theorem exactlyOne_cost_le (vs : List ℕ) :
    cost (exactlyOne vs) ≤ vs.length + 1 + 3 * vs.length ^ 2 := by
  sorry

/-! ## 2. Uniform emission (intended `FormulaKit/Emit.lean`) -/

/-- **A fragment**: the serialization of `φ` without its formula terminator, i.e. every
clause with its marker and terminator. Cook-Levin's private `clFragment`. -/
def fragment (φ : CNF ℕ) : List Bool :=
  φ.flatMap fun C => true :: CNF.serializeClause C

/-- A serialization is its fragment followed by the single terminator. -/
theorem serialize_eq_fragment (φ : CNF ℕ) : CNF.serialize φ = fragment φ ++ [false] := rfl

/-- Fragments turn concatenation of formulas into concatenation of words. -/
theorem fragment_append (φ ψ : CNF ℕ) : fragment (φ ++ ψ) = fragment φ ++ fragment ψ := by
  simp [fragment]

/-- Fragments of an indexed concatenation are the concatenated fragments. -/
theorem fragment_flatMap {β : Type} (xs : List β) (G : β → CNF ℕ) :
    fragment (xs.flatMap G) = xs.flatMap fun b => fragment (G b) := by
  induction xs with
  | nil => rfl
  | cons b xs ih => simp only [List.flatMap_cons, fragment_append, ih]

/-- **Ordered uniform emission** (design §14 row H6, "ordered emission"): if the number of
rounds is polynomial-time in unary and round `i`'s chunk is polynomial-time from the pair of
the instance and `i` in unary, then the concatenation of the chunks of rounds `0, …,
count x - 1` is polynomial-time.

**Proof sketch.** Run `Complexity.polyTimeComputable_emitIter` on the state word
`pairEncode x 1ⁱ`: the step appends one `1` while `i < count x` and then saturates, the chunk
is the given one below `count x` and empty after; both are polynomial-time by
`Complexity.polyTimeComputable_ite` and the pair projections. Saturation bounds every
iterate by `|x| + count x + O(1)`, polynomial by `PolyTimeComputable.output_length_le`, and
the iteration count `a'(n + 1)^k' + 1` is chosen at least `count x`. -/
theorem polyTimeComputable_flatMap_range (count : List Bool → ℕ)
    (chunk : List Bool → ℕ → List Bool)
    (hcount : PolyTimeComputable fun x => List.replicate (count x) true)
    (hchunk : PolyTimeComputable fun z => chunk (pairFstD z) (pairSndD z).length) :
    PolyTimeComputable fun x => (List.range (count x)).flatMap (chunk x) := by
  sorry

/-- **Uniform serialization**: a formula given as `count x` ordered groups, each group's
fragment polynomial-time from the instance and its index, serializes in polynomial time.

**Proof sketch.** `fragment_flatMap` and `serialize_eq_fragment` reduce it to
`polyTimeComputable_flatMap_range` followed by appending the constant terminator
(`PolyTimeComputable.append`). -/
theorem polyTimeComputable_serialize_flatMap (count : List Bool → ℕ)
    (G : List Bool → ℕ → CNF ℕ)
    (hcount : PolyTimeComputable fun x => List.replicate (count x) true)
    (hG : PolyTimeComputable fun z => fragment (G (pairFstD z) (pairSndD z).length)) :
    PolyTimeComputable fun x => CNF.serialize ((List.range (count x)).flatMap (G x)) := by
  sorry

/-- **A gate with polynomial-time wires has a polynomial-time fragment**: the template is
fixed, so only the unary wire indices vary (the public form of Cook-Levin's private
`clA5Template_native`).

**Proof sketch.** Induct over the fixed clause list of the template. Each literal serializes
as the unary wire index, one more `1`, the run terminator and the fixed polarity; finite
concatenation (`PolyTimeComputable.append`) assembles clauses and the fragment. -/
theorem polyTimeComputable_fragment_gate (ℓ : ℕ) (p : (Fin ℓ → Bool) → Bool)
    (wire : List Bool → ℕ → ℕ)
    (hw : ∀ j < ℓ, PolyTimeComputable fun z => List.replicate (wire z j) true) :
    PolyTimeComputable fun z => fragment (gate ℓ p (wire z)) := by
  sorry

/-- **Shifting by a polynomial-time offset preserves polynomial-time serialization**: from
the serialization of `F x`, inserting `o x` extra `1`s at the start of every literal's unary
index gives the serialization of `F x` with every variable `v` renamed `o x + v`.

**Proof sketch.** A two-input transducer: copy the serialized word, and at every literal
start (a `1` after a clause marker or after a literal's polarity bit) first copy the unary
word `1^(o x)`. The parse states are the six states of the public CNF grammar automaton
(`Std.Sat.CNF.syntaxStep`). -/
theorem polyTimeComputable_serialize_relabel_add (F : List Bool → CNF ℕ)
    (o : List Bool → ℕ)
    (hF : PolyTimeComputable fun x => CNF.serialize (F x))
    (ho : PolyTimeComputable fun x => List.replicate (o x) true) :
    PolyTimeComputable fun x => CNF.serialize ((F x).relabel (o x + ·)) := by
  sorry

end FormulaKit

/-! ## 3. Tseitin after the prefix (intended `FormulaKit/Tseitin.lean`) -/

namespace QBF

/-- **Prefix truth over an arbitrary leaf predicate**: the recursion of
`Complexity.QBF.truthAux` ([AB09, Definition 4.10]) with the matrix test replaced by any
predicate `P` of the final assignment. Quantifier number `i` of the prefix binds variable `i`,
as in `Complexity.QBF`. -/
def PrefixTruth (P : (ℕ → Bool) → Prop) :
    List Complexity.QBF.Quant → (ℕ → Bool) → ℕ → Prop
  | [], σ, _ => P σ
  | .ex :: qs, σ, i => ∃ b : Bool, PrefixTruth P qs (Function.update σ i b) (i + 1)
  | .all :: qs, σ, i => ∀ b : Bool, PrefixTruth P qs (Function.update σ i b) (i + 1)

/-- The CNF-matrix semantics is the prefix semantics with the matrix test as leaf. -/
theorem truthAux_iff_prefixTruth (m : CNF ℕ) (qs : List Complexity.QBF.Quant)
    (σ : ℕ → Bool) (i : ℕ) :
    Complexity.QBF.truthAux m qs σ i ↔ PrefixTruth (fun τ => m.eval τ = true) qs σ i := by
  induction qs generalizing σ i with
  | nil => exact Iff.rfl
  | cons q qs ih =>
    cases q with
    | ex => exact exists_congr fun b => ih _ _
    | all => exact forall_congr' fun b => ih _ _

/-- Prefix truth depends on its leaf predicate only through its truth values. -/
theorem prefixTruth_congr {P P' : (ℕ → Bool) → Prop} (h : ∀ τ, P τ ↔ P' τ)
    (qs : List Complexity.QBF.Quant) (σ : ℕ → Bool) (i : ℕ) :
    PrefixTruth P qs σ i ↔ PrefixTruth P' qs σ i := by
  induction qs generalizing σ i with
  | nil => exact h σ
  | cons q qs ih =>
    cases q with
    | ex => exact exists_congr fun b => ih _ _
    | all => exact forall_congr' fun b => ih _ _

/-- **Splitting a prefix**: the truth of `qs ++ rs` is the truth of `qs` with, as leaf, the
truth of `rs` started at the variable after `qs`. -/
theorem prefixTruth_append (P : (ℕ → Bool) → Prop) (qs rs : List Complexity.QBF.Quant)
    (σ : ℕ → Bool) (i : ℕ) :
    PrefixTruth P (qs ++ rs) σ i ↔
      PrefixTruth (fun τ => PrefixTruth P rs τ (i + qs.length)) qs σ i := by
  induction qs generalizing σ i with
  | nil => exact Iff.rfl
  | cons q qs ih =>
    have he : i + 1 + qs.length = i + (q :: qs).length := by
      simp only [List.length_cons]
      omega
    cases q with
    | ex =>
      simp only [List.cons_append, PrefixTruth]
      exact exists_congr fun b => by rw [ih, he]
    | all =>
      simp only [List.cons_append, PrefixTruth]
      exact forall_congr' fun b => by rw [ih, he]

/-- **An existential suffix is satisfiability above the bound part**: if the matrix mentions
only variables below `i + j`, then `j` existential quantifiers started at variable `i` hold
iff some assignment agreeing with `σ` below `i` satisfies the matrix. The case `i = 0` is
`Complexity.QBF.truth_exPrefix_iff_satisfiable` ([AB09, Example 4.12]).

**Proof sketch.** Forward, the witnesses build a final assignment that agrees with `σ` below
`i` and satisfies the matrix. Backward, choose the witness `τ v` at each step `v`; after `j`
updates the built assignment agrees with `τ` below `i + j`, hence below `numVars`, and
`Complexity.eval_congr_of_lt_numVars` closes (the private Q2/Q3 lemmas of
`Formulas/QBF.lean`, generalized to a start index). -/
theorem truthAux_exSuffix_iff (m : CNF ℕ) (j : ℕ) (σ : ℕ → Bool) (i : ℕ)
    (hm : m.numVars ≤ i + j) :
    Complexity.QBF.truthAux m (List.replicate j .ex) σ i ↔
      ∃ τ : ℕ → Bool, (∀ v < i, τ v = σ v) ∧ m.eval τ = true := by
  sorry

end QBF

/-- **Tseitin, pointwise** ([AB09, Lemma 6.11], read per input assignment): for a circuit
whose gates read at most two vertices, an assignment `σ` of the input variables `0, …,
n - 1` extends to an assignment satisfying the Tseitin formula `C.toCNF` iff the circuit
outputs `1` on `σ`. (The public `satisfiable_iff_toCNF_satisfiable` is the existential
closure of this statement over `σ`.)

**Proof sketch.** Forward: by strong induction on the vertex number, a satisfying extension
agrees with the vertex values of `C` on `σ` (the private
`values_getD_eq_of_eval_tseitinGates` of `DAGCircuitSat.lean`); the output unit clause then
gives output `1`. Backward: extend `σ` by the vertex values (the private
`eval_tseitinGates_values`), which agree with `σ` on the inputs (`values_getD_input`). -/
theorem exists_toCNF_extension_iff {n : ℕ} (C : BoolCircuit.DAGCircuit n)
    (hC : ∀ g ∈ C.gates, g.args.length ≤ 2) (σ : ℕ → Bool) :
    (∃ τ : ℕ → Bool, (∀ v < n, τ v = σ v) ∧ C.toCNF.eval τ = true) ↔
      C.eval (fun i => σ i) = true := by
  sorry

/-- **Tseitin after the prefix, for any encoding** (the fill obligation "Tseitin-after-prefix
equivalence" of `Complexity.TQBF_PSPACEHard`): let `qs` be any quantifier prefix, `T` a CNF on
the prefix variables and `G` further variables, and `P` a predicate of the prefix assignment.
If, for every assignment `σ`, some assignment agreeing with `σ` on the prefix variables
satisfies `T` exactly when `P σ` holds, then the closed formula with prefix `qs` followed by
`G` existential quantifiers and matrix `T` is true iff the prefix `qs` holds of `P`. The
auxiliary values are thus never fixed before the universal variables they depend on (TQBF
round-1 answer 5). [AB09, §4.2, p. 83: auxiliary variables, as in the Cook-Levin proof,
give an equivalent formula with a CNF matrix; Lemma 6.11's Tseitin variables are an
instance]

**Proof sketch.** `QBF.truthAux_iff_prefixTruth` and `QBF.prefixTruth_append` split the
prefix after `qs`; `QBF.truthAux_exSuffix_iff` (with the `numVars` bound) turns the
existential suffix at each leaf into "some extension satisfies `T`", which is `P` by the
pointwise hypothesis; `QBF.prefixTruth_congr` transports the leaf. -/
theorem truth_exSuffix_of_pointwise (qs : List Complexity.QBF.Quant) (T : CNF ℕ) (G : ℕ)
    (P : (ℕ → Bool) → Prop) (hT : T.numVars ≤ qs.length + G)
    (hpt : ∀ σ : ℕ → Bool,
      (∃ τ : ℕ → Bool, (∀ v < qs.length, τ v = σ v) ∧ T.eval τ = true) ↔ P σ) :
    Complexity.QBF.truth ⟨qs ++ List.replicate G .ex, T⟩ ↔
      QBF.PrefixTruth P qs (fun _ => false) 0 := by
  change Complexity.QBF.truthAux T (qs ++ List.replicate G .ex) (fun _ => false) 0 ↔ _
  rw [QBF.truthAux_iff_prefixTruth, QBF.prefixTruth_append]
  apply QBF.prefixTruth_congr
  intro τ
  rw [← QBF.truthAux_iff_prefixTruth, Nat.zero_add,
    QBF.truthAux_exSuffix_iff T G τ qs.length hT]
  exact hpt τ

/-- **Tseitin after the prefix, for circuits**: the instance of `truth_exSuffix_of_pointwise`
for the Tseitin CNF `C.toCNF` of a circuit of fan-in at most two on the `qs.length` prefix
variables, with one existential quantifier per gate: the formula is true iff the prefix `qs`
holds of the circuit's output. [AB09, Lemma 6.11 and §4.2]

**Proof sketch.** Every Tseitin variable is a vertex
(`BoolCircuit.DAGCircuit.toCNF_var_lt_size`), so `numVars ≤ qs.length + #gates`; the
pointwise hypothesis is `exists_toCNF_extension_iff`. -/
theorem truth_tseitin_after_prefix (qs : List Complexity.QBF.Quant)
    (C : BoolCircuit.DAGCircuit qs.length) (hC : ∀ g ∈ C.gates, g.args.length ≤ 2) :
    Complexity.QBF.truth ⟨qs ++ List.replicate C.gates.length .ex, C.toCNF⟩ ↔
      QBF.PrefixTruth (fun σ => C.eval (fun i => σ i) = true) qs (fun _ => false) 0 :=
  truth_exSuffix_of_pointwise qs C.toCNF C.gates.length _
    (FormulaKit.numVars_le_of_forall_lt _ _ C.toCNF_var_lt_size)
    (exists_toCNF_extension_iff C hC)

/-! ## 4. The restated Claim 4.4(2): the closed-form codec (intended in place in `TQBF.lean`)

Layout of a code word of `width M n s` bits, for input length `n` and window radius `s`
(`k = M.k`, `Q = card M.State + 1`, cells `j < 2s + 1` stand for positions `j - s`):

| field | variables | meaning |
|---|---|---|
| input content | `i` for `i < n` | input bit `i` |
| input head | `n + j` for `j < n + 2` | the input head is at `j` |
| state | `2n + 2 + r` for `r < Q` | the state has index `r` (`0` is halt) |
| work cells | `2n + 2 + Q + 3((2s+1)i + j) + b` | tape `i`, cell `j`, flag `b` (see below) |
| summary | `2n + 2 + Q + 3k(2s+1) + d` | `d = 0`: output is `[true]`; `d = 1`: output is dead |

The work flags of a cell are `b = 0` "holds `false`", `b = 1` "holds `true`" and `b = 2` "the
head is here". Adjacency reads two blocks: the source code at `[0, width)` and the target code at
`[width, 2·width)`. -/

namespace ConfigCodec

variable (M : FinTM Bool)

/-- The number of state markers: one per state and one for the halting state. -/
def stateCount : ℕ := Fintype.card M.State + 1

/-- **The machine-constant state numbering**: halt is `0`, and state `q` is one more than its
position in a fixed enumeration of the finite state type. This choice depends on the
machine only (not on `n` or `s`), so an emitter for the fixed machine hardwires it. -/
noncomputable def stateIndex : Option M.State → ℕ
  | none => 0
  | some q => (Fintype.equivFin M.State q).val + 1

/-- The first state-marker variable, after the input content and the input-head track. -/
def stateOffset (n : ℕ) : ℕ := 2 * n + 2

/-- The first work-track variable, after the state markers. -/
def workOffset (n : ℕ) : ℕ := stateOffset n + stateCount M

/-- The first summary variable, after `3 · k · (2s + 1)` work-track bits. -/
def summaryOffset (n s : ℕ) : ℕ := workOffset M n + 3 * (M.k * (2 * s + 1))

/-- **The code width**, `2n + 4 + Q + 3k(2s + 1)`: linear in `s + n` for the fixed machine
([AB09, Claim 4.4(2)]; deviation (i) of the module docstring of `TQBF.lean`: the code carries
the input, so the width is `O(s + n)` rather than `O(s)`). Unlike the old packaged statement
there is no padding to `C · (s + n + 1)`. -/
def width (n s : ℕ) : ℕ := summaryOffset M n s + 2

/-- The variable of input bit `i`. -/
def inputVar (i : ℕ) : ℕ := i

/-- The variable of the input-head marker at position `j` (`0` and `n + 1` are the end
markers). -/
def headVar (n j : ℕ) : ℕ := n + j

/-- The variable of the state marker of `q`. -/
noncomputable def stateVar (n : ℕ) (q : Option M.State) : ℕ := stateOffset n + stateIndex M q

/-- The variable of flag `b` of cell `j` of work tape `i`. -/
def workVar (n s i j b : ℕ) : ℕ := workOffset M n + 3 * ((2 * s + 1) * i + j) + b

/-- The variable of the output-summary flag (`false`: accepting, `true`: dead). -/
def summaryVar (n s : ℕ) (dead : Bool) : ℕ := summaryOffset M n s + if dead then 1 else 0

/-- The three flags of window cell `j` (position `j - s`) of work tape `i`: holds `false`,
holds `true`, carries the head (exact integer position, so an exterior head marks no cell). -/
def workFlags (s : ℕ) {x : List Bool} (c : Cfg M.k Bool M.State x) (i : Fin M.k) (j : ℕ) :
    List Bool :=
  [decide (c.workTapes i ((j : ℤ) - s) = some false),
    decide (c.workTapes i ((j : ℤ) - s) = some true),
    decide (c.workTapePos i = (j : ℤ) - s)]

/-- **The configuration codec** ([AB09, Claim 4.4(2)], the marker discipline of the
Cook-Levin tableau row): the input content, the one-hot input head, the one-hot state, the
window tracks of every work tape, and the two-bit output summary, concatenated in the order
of the layout table. The output tape enters only through `Turing.outSummary` (a full-output
code of fixed length cannot be injective; TQBF round-1 finding 1). Total on all inputs and
configurations; its theorems concern inputs of length `n` and windowed configurations. -/
noncomputable def code (n s : ℕ) (x : List Bool) (c : Cfg M.k Bool M.State x) : List Bool :=
  List.ofFn (fun i : Fin n => x.getD i false) ++
    List.ofFn (fun j : Fin (n + 2) => decide (c.inputPos.val = j.val)) ++
    List.ofFn (fun r : Fin (stateCount M) => decide (stateIndex M c.state = r.val)) ++
    (List.finRange M.k).flatMap (fun i => (List.range (2 * s + 1)).flatMap (workFlags M s c i)) ++
    [decide (outSummary c.output = .accept), decide (outSummary c.output = .dead)]

/-- **The validity CNF** ([AB09, Claim 4.4(2)]; TQBF round-1 finding 3: the `ψ` recursion
guards its midpoints with it): exactly one input-head marker, exactly one state marker,
exactly one head marker per work tape, never both symbol flags of a cell, and never both
summary flags. Input content is unconstrained. Every clause list is ordered by `List.range`,
so the formula is a closed-form function of `(M, n, s)`. -/
def validity (n s : ℕ) : CNF ℕ :=
  FormulaKit.exactlyOne ((List.range (n + 2)).map (headVar n)) ++
    FormulaKit.exactlyOne ((List.range (stateCount M)).map (stateOffset n + ·)) ++
    (List.range M.k).flatMap (fun i =>
      FormulaKit.exactlyOne ((List.range (2 * s + 1)).map fun j => workVar M n s i j 2)) ++
    (List.range M.k).flatMap (fun i => (List.range (2 * s + 1)).map fun j =>
      [(workVar M n s i j 0, false), (workVar M n s i j 1, false)]) ++
    [[(summaryVar M n s false, false), (summaryVar M n s true, false)]]

/-- **The acceptance CNF** ([AB09, Claim 4.4(2)]): the halt marker and the accepting-summary
flag, as two unit clauses. -/
def acceptance (n s : ℕ) : CNF ℕ :=
  [[(stateOffset n, true)], [(summaryVar M n s false, true)]]

/-- **Carried-input equality** between the source block and the target block: two clauses
per input bit. -/
def inputEquality (n s : ℕ) : CNF ℕ :=
  (List.range n).flatMap fun i =>
    [[(i, false), (width M n s + i, true)], [(i, true), (width M n s + i, false)]]

/-- The finite transition cases: the state (halt included), the scanned input symbol, and
the scanned work symbols. A machine-only type. -/
abbrev Case := Option M.State × Option Bool × (Fin M.k → Option Bool)

/-- The action of a case: the machine's transition, or the silent identity at halt. -/
def caseAction (q : Case M) : Action M.k Bool M.State :=
  match q.1 with
  | none => ⟨0, fun _ => (none, 0), none, none⟩
  | some st => M.tm.tr st q.2.1 q.2.2

/-- **The machine-constant case list**: a fixed enumeration of the finite case type. Its order
depends on the machine only, so an emitter for the fixed machine hardwires it. -/
noncomputable def caseList : List (Case M) := (Finset.univ : Finset (Case M)).toList

/-- The `3k + 7` Boolean ports of one transition gate: the guard markers, the scanned input
and work symbols, the old summary, and the old and new value of the updated bit. -/
inductive Port (k : ℕ)
  | state
  | inputHead
  | inputSymbol
  | workHead : Fin k → Port k
  | workSymbol : Fin k → Bool → Port k
  | summary : Bool → Port k
  | oldBit
  | newBit

/-- The number of ports of a gate on a machine with `k` work tapes. -/
def portCount (k : ℕ) : ℕ := 3 * k + 7

/-- **Closed-form port numbering**: `state, inputHead, inputSymbol`, then the `k` work heads,
then two symbol flags per tape, then the two summary flags, then the old and new bit. -/
def portIndex {k : ℕ} : Port k → ℕ
  | .state => 0
  | .inputHead => 1
  | .inputSymbol => 2
  | .workHead i => 3 + i.val
  | .workSymbol i t => 3 + k + 2 * i.val + if t then 1 else 0
  | .summary t => 3 + 3 * k + if t then 1 else 0
  | .oldBit => 5 + 3 * k
  | .newBit => 6 + 3 * k

/-- The port with a given number (inverse to `portIndex` below `portCount k`). -/
def portOf (k j : ℕ) : Port k :=
  if h₀ : j < 3 then (if j = 0 then .state else if j = 1 then .inputHead else .inputSymbol)
  else if h : j < 3 + k then .workHead ⟨j - 3, by omega⟩
  else if h' : j < 3 + 3 * k then .workSymbol ⟨(j - 3 - k) / 2, by omega⟩ ((j - 3 - k) % 2 = 1)
  else if j = 3 + 3 * k then .summary false
  else if j = 4 + 3 * k then .summary true
  else if j = 5 + 3 * k then .oldBit
  else .newBit

/-- What a gate asserts about its new bit: a copy of the old bit, a constant, or one of the
two summary flags recomputed from the old flags and the case's output. -/
inductive Expect
  | copy
  | const (b : Bool)
  | summary (dead : Bool)
  deriving DecidableEq

/-- A gate kind: the case, whether the guarded input position is interior, and the
expectation. A machine-only type, so the gate templates are fixed for the machine. -/
abbrev GateKind := Case M × Bool × Expect

/-- Two symbol flags decode to blank, `false` or `true` (the illegal `11` reads `true`). -/
def readSymbol (f t : Bool) : Option Bool := if t then some true else if f then some false else none

/-- Two summary flags decode to an output summary (the illegal `11` reads dead). -/
def readSummary (acc dead : Bool) : OutSummary :=
  if dead then .dead else if acc then .accept else .empty

/-- A canonical output word with each summary. -/
def summaryWord : OutSummary → List Bool
  | .empty => []
  | .accept => [true]
  | .dead => [false]

/-- **The guard of a gate**: the selected state, input-head and work-head markers are all set,
and the scanned input and work symbols are those of the case (an end-marker position scans
blank). -/
def guard (q : Case M) (interior : Bool) (a : Port M.k → Bool) : Bool :=
  a .state && a .inputHead && (List.finRange M.k).all (fun i => a (.workHead i)) &&
    decide ((if interior then some (a .inputSymbol) else none) = q.2.1) &&
    (List.finRange M.k).all fun i =>
      decide (readSymbol (a (.workSymbol i false)) (a (.workSymbol i true)) = q.2.2 i)

/-- The bit a gate expects as the new bit. -/
def expectBit (act : Action M.k Bool M.State) : Expect → (Port M.k → Bool) → Bool
  | .copy, a => a .oldBit
  | .const b, _ => b
  | .summary dead, a =>
    decide (outSummary (summaryWord (readSummary (a (.summary false)) (a (.summary true))) ++
      act.output.toList) = if dead then .dead else .accept)

/-- **The predicate of a gate kind**: if the guard holds, the new bit is the expected bit. -/
def kindPred (κ : GateKind M) (a : Port M.k → Bool) : Bool :=
  !guard M κ.1 κ.2.1 a || (a .newBit == expectBit M (caseAction M κ.1) κ.2.2 a)

/-- Head of work tape `i` in the head tuple coded by `h` (mixed radix `2s + 1`). -/
def headOf (s h i : ℕ) : ℕ := h / (2 * s + 1) ^ i % (2 * s + 1)

/-- The input-head move of `Turing.moveInputPos`, on natural-number positions. -/
def moveInput (n p : ℕ) (m : SignType) : ℕ :=
  let p' := ((p : ℤ) + (m.cast : ℤ)).toNat
  if p' < n + 2 then p' else n + 1

/-- **The expectation of target bit `v`** under input-head position `p`, head tuple `h` and
case `q`: input bits are copied; head, state and work-head markers are recomputed constants;
a symbol flag at a written head cell is the written value and is copied elsewhere; the
summary flags are recomputed. Closed form in `(n, s, p, h, v)` and the fixed case. -/
noncomputable def expectOf (n s p h : ℕ) (q : Case M) (v : ℕ) : Expect :=
  let act := caseAction M q
  if v < n then .copy
  else if v < stateOffset n then .const (decide (moveInput n p act.inputTape = v - n))
  else if v < workOffset M n then .const (decide (stateIndex M act.state = v - stateOffset n))
  else if v < summaryOffset M n s then
    let u := v - workOffset M n
    let i := u / 3 / (2 * s + 1)
    let j := u / 3 % (2 * s + 1)
    if hi : i < M.k then
      if u % 3 < 2 then
        if headOf s h i = j then
          match (act.workTapes ⟨i, hi⟩).1 with
          | none => .copy
          | some w => .const (decide (w = some (decide (u % 3 = 1))))
        else .copy
      else .const (decide ((headOf s h i : ℤ) + ((act.workTapes ⟨i, hi⟩).2.cast : ℤ) = j))
    else .copy
  else .summary (decide (v = summaryOffset M n s + 1))

/-- **The wiring of a gate** (closed form): guard ports read the source block at the
markers selected by `(p, h, q)`; the old bit is source variable `v`; the new bit is target
variable `width + v`. The input-symbol port of an end-marker position reads an arbitrary
variable that the guard ignores. -/
noncomputable def portWire (n s p h : ℕ) (q : Case M) (v : ℕ) : Port M.k → ℕ
  | .state => stateVar M n q.1
  | .inputHead => headVar n p
  | .inputSymbol => if 0 < p ∧ p ≤ n then inputVar (p - 1) else summaryVar M n s false
  | .workHead i => workVar M n s i (headOf s h i) 2
  | .workSymbol i t => workVar M n s i (headOf s h i) (if t then 1 else 0)
  | .summary t => summaryVar M n s t
  | .oldBit => v
  | .newBit => width M n s + v

/-- **One transition gate**: the fixed template of its kind, wired in closed form. -/
noncomputable def transitionGate (n s p h : ℕ) (q : Case M) (v : ℕ) : CNF ℕ :=
  FormulaKit.gate (portCount M.k)
    (fun a => kindPred M (q, decide (0 < p ∧ p ≤ n), expectOf M n s p h q v)
      (fun port => FormulaKit.readBit a (portIndex port)))
    (fun j => portWire M n s p h q v (portOf M.k j))

/-- **The transition conjunction**, enumerated in closed form: input-head positions
`p < n + 2`, head tuples `h < (2s + 1)^k`, the fixed case list, and target bits
`v < width` (TQBF round-2 finding 4: polynomial, `(n + 2)(2s + 1)^k` guarded positions for
the fixed machine; universality is applied per gate, never per row). -/
noncomputable def transition (n s : ℕ) : CNF ℕ :=
  (List.range (n + 2)).flatMap fun p =>
    (List.range ((2 * s + 1) ^ M.k)).flatMap fun h =>
      (caseList M).flatMap fun q =>
        (List.range (width M n s)).flatMap fun v => transitionGate M n s p h q v

/-- **The adjacency CNF** ([AB09, Claim 4.4(2)]): carried-input equality and the transition
conjunction, over the source block `[0, width)` and the target block `[width, 2·width)`. -/
noncomputable def adjacency (n s : ℕ) : CNF ℕ := inputEquality M n s ++ transition M n s

/-- **The initial vertex's code is computed in polynomial time** (the fill obligation "the
initial-code computation" of `Complexity.TQBF_PSPACEHard`): the input itself, a head marker
at the first input position, the start-state marker, blank windows with every head marker at

/-! ## 5. The old packaged shape, as a corollary -/

/-- **Claim 4.4(2), packaged form, recovered** (only if the old existential is kept): for
every machine there is a constant `C` such that for all `(n, s)` there are a code width
`ℓ ≤ C · (s + n + 1)`, a codec of exact width `ℓ`, and three CNFs with the old clauses. The
one change from `Complexity.exists_adjacency_codec_cnf` is the width clause: the old one
fixed the length to exactly `C · (s + n + 1)`, which needs padding; here the width is the
closed-form `ConfigCodec.width` and only bounded by `C · (s + n + 1)`.

**Proof sketch.** Take `C` the maximum of the width coefficient and the size constant `K` of
`ConfigCodec.exists_serialize_length_le`, and the codec and CNFs of `ConfigCodec`; every
clause is one of the theorems above. -/
theorem exists_adjacency_codec_cnf_of_closedForm (M : FinTM Bool) :
    ∃ C : ℕ, 0 < C ∧ ∀ (n s : ℕ),
      ∃ (ℓ : ℕ) (code : (x : List Bool) → Cfg M.k Bool M.State x → List Bool)
        (φv φa φacc : CNF ℕ),
        ℓ ≤ C * (s + n + 1) ∧
        (∀ (x : List Bool) (c : Cfg M.k Bool M.State x), (code x c).length = ℓ) ∧
        (∀ (x x' : List Bool), x.length = n → x'.length = n →
          ∀ (c : Cfg M.k Bool M.State x) (c' : Cfg M.k Bool M.State x'),
            c.InWindow s → c'.InWindow s → code x c = code x' c' → x = x') ∧
        (∀ (x : List Bool), x.length = n →
          ∀ c d : Cfg M.k Bool M.State x, c.InWindow s → d.InWindow s →
            (code x c = code x d ↔ NDTM.coreSum c = NDTM.coreSum d)) ∧
        (∀ w : List Bool, w.length = ℓ →
          (φv.eval (fun v => w.getD v false) = true ↔
            ∃ (x : List Bool), x.length = n ∧
              ∃ c : Cfg M.k Bool M.State x, c.InWindow s ∧ w = code x c)) ∧
        (∀ (x : List Bool), x.length = n →
          ∀ c d : Cfg M.k Bool M.State x, c.InWindow s → d.InWindow s →
            (φa.eval (fun v => (code x c ++ code x d).getD v false) = true ↔
              NDTM.coreSum (M.tm.step c) = NDTM.coreSum d)) ∧
        (∀ (x x' : List Bool), x.length = n → x'.length = n → x ≠ x' →
          ∀ (c : Cfg M.k Bool M.State x) (c' : Cfg M.k Bool M.State x'),
            c.InWindow s → c'.InWindow s →
            φa.eval (fun v => (code x c ++ code x' c').getD v false) = false) ∧
        (∀ (x : List Bool), x.length = n →
          ∀ c : Cfg M.k Bool M.State x, c.InWindow s →
            (φacc.eval (fun v => (code x c).getD v false) = true ↔
              (c.state = none ∧ outSummary c.output = OutSummary.accept))) ∧
        φv.numVars ≤ ℓ ∧ φacc.numVars ≤ ℓ ∧ φa.numVars ≤ 2 * ℓ ∧
        (CNF.serialize φv).length ≤ C * (s + n + 2) ^ C ∧
        (CNF.serialize φa).length ≤ C * (s + n + 2) ^ C ∧
        (CNF.serialize φacc).length ≤ C * (s + n + 2) ^ C := by
  obtain ⟨K, hK⟩ := ConfigCodec.exists_serialize_length_le M
  let C := max (Fintype.card M.State + 6 * M.k + 5) K
  have hC : 0 < C := lt_of_lt_of_le (by omega) (le_max_left _ _)
  have hpow : ∀ n s : ℕ, K * (s + n + 2) ^ K ≤ C * (s + n + 2) ^ C := fun n s =>
    Nat.mul_le_mul (le_max_right _ _) (Nat.pow_le_pow_right (by omega) (le_max_right _ _))
  refine ⟨C, hC, fun n s => ⟨ConfigCodec.width M n s, ConfigCodec.code M n s,
    ConfigCodec.validity M n s, ConfigCodec.adjacency M n s, ConfigCodec.acceptance M n s,
    (ConfigCodec.width_le M n s).trans (Nat.mul_le_mul_right _ (le_max_left _ _)),
    ConfigCodec.code_length M n s,
    fun x x' hx hx' c c' _ _ h => ConfigCodec.code_input_eq M n s x x' hx hx' c c' h,
    fun x hx c d hc hd => ConfigCodec.code_eq_iff M n s x hx c d hc hd,
    ConfigCodec.validity_eval_iff M n s,
    fun x hx c d hc hd => ConfigCodec.adjacency_eval_iff M n s x hx c d hc hd,
    fun x x' hx hx' hne c c' _ _ => ConfigCodec.adjacency_eval_of_ne M n s x x' hx hx' hne c c',
    fun x _ c _ => ConfigCodec.acceptance_eval_iff M n s x c,
    ConfigCodec.validity_numVars_le M n s, ConfigCodec.acceptance_numVars_le M n s,
    ConfigCodec.adjacency_numVars_le M n s,
    (hK n s).1.trans (hpow n s), (hK n s).2.1.trans (hpow n s),
    (hK n s).2.2.trans (hpow n s)⟩⟩

end Complexity.Draft.RD2
