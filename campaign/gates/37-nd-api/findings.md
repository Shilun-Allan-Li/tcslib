## Adversarial boundary checks

These are direct mathematical evaluations of the supplied definitions, not newly elaborated Lean tests.

1. **Zero budget, including empty input.** The sole word of length zero is `[]`. `runWith_nil` leaves the initial control `some q₀`, so `HaltsWithin input 0` and `AcceptsWithin input 0` are both false. The universal quantifier is not vacuous. Consequently the natural coefficient zero in `NTIME` cannot manufacture a decider.
2. **Distinct choices and an early halt.** Take a zero-work-tape, one-state machine whose false transition halts emitting false and whose true transition halts emitting true. All branches halt after one step, and there is an accepting branch, without every branch accepting. The replay's blank choice cell selects the false transition; a true cell selects the true transition. Once halted, additional choices or replay steps preserve the result. In particular the replay's choice head need not advance after halting, consistently with `replayTM_runFrom`.
3. **Empty stream and negative tape positions.** For `guessRunCfg c j [] q`, the interval condition is impossible, so every work cell is preserved, although the control changes. For a two-bit stream at head position `-2`, precisely cells `-2` and `-1` are patched; cell zero and every other tape remain unchanged. There is no hidden nonnegative-head assumption.
4. **Empty virtual input and capture of existing output.** With an empty virtual word and canonical source input position 1, the buffer head is at integer position zero, not minus one. A halted source stays halted after tagging. Forwarding output is `pre ++ c.output`; suppression captures `capPre ++ c.output` and keeps physical output `out₀`. This distinguishes the correct equation from finding 3's abbreviated prose.
5. **Stopped configurations and auxiliary tape boundaries.** A halted configuration satisfies `Stopped` regardless of the test; a live configuration satisfies it exactly when its state passes the test. At `k = 0`, the table and summary tapes are still distinct indices zero and one; `clockCfg` and `withChoiceTape` still have their single appended tape. `Rep_iff` does not accidentally impose liveness or physical-output equality.

Suitable permanent sanity lemmas would record zero-budget nonhalting/nonacceptance, the no-cell-change property of an empty `guessRunCfg` patch, and the capture-word equation for `vhostSilentCfg`. These are suggestions, not extra gate requirements.
