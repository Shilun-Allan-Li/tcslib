## Literal target and model meaning

Restate the full target and work-space conventions mathematically before assessing the proof.
One finite Boolean machine `SU` is chosen before **every code string** `α`. For each representation
`α`, a positive natural `Cα` is chosen before `s,x,output,t`. Whenever the decoded one-work-tape
source halts on `x` with the **actual arbitrary output list** at time `t` and its work space by
then is at most `s`, `SU` on `pairEncode (Nat.bits s) (pairEncode α x)` halts at some time with
that same output and space at most **`Cα*s`**, with no input-length addend.

Time is existential; there is no simulator time promise, budget test/clock, overrun verdict,
well-formed-code restriction or decision-output restriction. The numerical budget is not
interpreted as a bound or clock, but its encoding is physically scanned to locate the suffix.
Input and append-only output storage are excluded from the unchanged work-space measure.
Visited-head cells count time0 and both ruler boundary blanks. The code bundle equation is
the actually published `Turing.CodeTM.toFinTM_eq`, not foreign-definition reduction.
