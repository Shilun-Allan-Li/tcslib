start = t.index("namespace FinNDTM\n\n/-- **The linear-overhead coded normal form**")
end = t.index("end FinNDTM\n\n", start) + len("end FinNDTM\n\n")
block = t[start:end]
assert block.count('theorem ') == 1 and 'theorem exists_codeNDTM_accepts_linear' in block
assert block.rstrip().endswith('end FinNDTM') and '  sorry\n' in block
inner = block[len("namespace FinNDTM\n\n"):-len("end FinNDTM\n\n")]
t = t[:start] + t[end:]
# imports
oi = "import TCSlib.Complexity.ClassP.TimeConstructible\n"
assert t.count(oi) == 1
t = t.replace(oi, oi + "import TCSlib.Complexity.ClassNP.NDNormalForm\n")
# Main results bullet
ob = ("* `Turing.FinNDTM.exists_codeNDTM_accepts_linear` — the linear-overhead coded\n"
      "  normal form ([BGW70]-style).\n")
assert t.count(ob) == 1
t = t.replace(ob, "* `Turing.FinNDTM.exists_codeNDTM_accepts_linear` — the linear-overhead coded\n"
                  "  normal form ([BGW70]-style), stated in\n"
                  "  `TCSlib.Complexity.ClassNP.NDNormalForm` (moved there, user 2026-10-17).\n")
# design paragraph: the host-contract modules
od = ("  `TCSlib.Complexity.TuringMachine.NDCodeSimulator` and\n"
      "  `TCSlib.Complexity.ClassNP.ExhaustiveReplay`.\n")
assert t.count(od) == 1
t = t.replace(od, "  `TCSlib.Complexity.TuringMachine.NDCodeSimulator` and\n"
                  "  `TCSlib.Complexity.ClassNP.ExhaustiveReplay`; the normal form is in\n"
                  "  `TCSlib.Complexity.ClassNP.NDNormalForm`.\n")
assert 'theorem exists_codeNDTM_accepts_linear' not in t
open(H, 'w', encoding='utf-8').write(t)

[AB09, §3.2] ([BGW70]-style guess-then-verify): every bundled binary nondeterministic machine has a
coded two-work-tape equivalent (`Turing.CodeNDTM`) whose acceptance tracks the original's at linear

nondeterministic time hierarchy (`TCSlib.Complexity.Diagonalization.NTimeHierarchy`) diagonalizes
over these codes. The statement was gated with phase P3.3's statements and lived in that module. It
moved here unchanged (user, 2026-10-17; C1's fill plan, `audits/evidence/c1/C1-fill-plan.md`), so
that its fill can run beside the universal machine's in `NTimeHierarchy`.

No new definitions: the normal form is an existential contract.

  phase P3.3).
