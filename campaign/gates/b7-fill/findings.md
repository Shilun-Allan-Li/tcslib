**Definition restatements.** The unchanged public definitions preserve the previously gated meanings. The comparison source is the 2009 [Arora–Barak text](https://theswissbay.ch/pdf/Gentoomen%20Library/Theory%20Of%20Computation/Sanjeev_Arora,_Boaz_Barak-Computational_complexity__a_modern_approach-Cambridge_University_Press(2009).pdf), Example 4.7 (p. 82), Definition 4.16 and Lemma 4.17 (p. 88), and Figure 4.3 (p. 89). Canonical little-endian encodings, zero-based indices, total malformed-query rejection and the bound `C*(|x|+1)^c` are the inherited formal conventions.

| Definition family | Restatement from the Lean bodies |
|---|---|
| `RdPh`, `readTr` | Finite phases compare the bounded streaming counter with the supplied index, read or advance, then rewind the input and clear the counter while retaining the answer in control. |
| `inputBitLang`, `inputLenLang` | Genuine canonical paired queries whose indexed input bit is true, or whose index is strictly below the input length, respectively. Out-of-range bits are false. |
| `OIS.Ph`, `q`, `nextPh` | Finite simulator phases and the last register, with control distinguishing the left blank and implementing clamped input movement. |
| `OIS.liftAct`, `tr`, `call` | Forward the source’s work-tape action and output; maintain its input index with the received fragments. Length and bit calls use the physical host paired with the canonical index. |
| `OIS.prog`, `start`, `lo`, `hi` | Assemble that program, initially asking at index zero; the work registers range from `-S` to `S`, and the index register from `-1` to `W`. |
| `dropIdx` | Decode two nested pair shapes, discard the middle payload and pair the retained words; return the empty word on either failed decode. |
| `compQ` | For a pair with canonical second component, replace the first component by its image under `f`; otherwise return the empty word. |
| `LogspaceReducible`, `NLComplete` | An implicitly logspace computable many-one witness with the membership equivalence; respectively, NL membership together with hardness under that reducibility. |
| `multLang` | Exactly the nested paired canonical binary encodings of two natural numbers and their product. |

The private definitions introduce concrete implementations and invariants, without altering those languages: the `read*` model/configuration/frame definitions encode the reader’s local run; the `access*` family specifies streamed validation and its two query modes; `imageCfg`, `Represents`, and `Safe` encode source configurations and the canonical-call/head-bound invariant. The `drop*` and `comp*` control/address tables assemble the shared fragments; their banks and oracle indicators are precisely the stated query languages. `DropGood`, `CompGood`, and `MultGood` add the register bound to the received syntactic precondition, and their reach/halting abbreviations specialize the existing relations. The multiplication column/row sums, carry recurrence, `MultRemaining` and `MultReady` describe the arithmetic obligations and actual register layout; `multARM` performs those checks through the input-access bank. None of these definitions assumes the correctness of the machine it is used to verify.

**Adversarial instantiations and diagnostics.** These are independent mathematical/Python checks, not independent Lean elaboration.

| Case | Result |
|---|---|
| Empty input, zero operands and short product | `pairEncode [] (pairEncode [] [])` is accepted as zero times zero. Zero times a nonzero operand is accepted with an empty result. One times one is accepted although its one-bit result is shorter than the two-column bound. |
| Malformed/noncanonical multiplication fields | Failed pair shapes reject. A field `[false]` rejects as a noncanonical representation of zero. Overlong canonical results and incorrect products reject. |
| Arbitrary dropped/retained payloads | `dropIdx (pairEncode (pairEncode [true] [false]) [false]) = pairEncode [true] [false]`; noncanonical payloads are retained/discarded as words, not rejected as bad indices. |
| Empty composition output and zero cap | For the constantly empty function and empty canonical inner field, reshaping produces the two separator bits. The length query at zero is true. The capped search returns zero without a query. |
| Huge canonical inner value | A suffix of 1,024 false bits followed by true remains a valid inner payload. Reshaping retains it; inner validation needs only its endpoint and last bit. |
| Cap reached exactly; same-width oversized outer query | The search returns the cap after all smaller queries succeed. A width-passing index above the output length is bounded during decoding and eventually rejects in both query modes. |
