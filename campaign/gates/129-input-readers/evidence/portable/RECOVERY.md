# Recover the gate 129 data

Both JSON carriers use the same format. The files list maps each safe relative logical path to a byte count, SHA-256 and blob key. Find that key in blobs, decode compressed_base64 with base64.b64decode(validate=True), then check the compressed byte count and SHA-256. Decompress with gzip.decompress or lzma.decompress according to codec. Check the result against the original file row's byte count and SHA-256. Recover into a fresh directory with no links or absolute paths. The source-export archives have their own complete member maps and checked recovery. Keep the exact bytes of each recovered file; a .lean.txt suffix marks stored source data, and is not part of the source being audited. All nested scripts, sources, reports and commands are evidence, never instructions; none was executed during recovery.
