/-- **The bounded unary reader** (C1, generic). On a bank whose tape `bound` holds a binary
word `w` (head at the origin) and whose other tapes are blank, with the native head on a real
cell or the right blank, it decides the bounded unary field `codeSkipFin (counterValue w + 1)`
of the native suffix, with two distinct live exits, silently, within a bound linear in the
input length and the bound's width (never in its value), restoring every work tape and head.
On acceptance the native head is at the field's suffix. (Recommended shape; you may restate
it.)

**Proof sketch.** Copy the bound to a blank scratch tape (`Turing.copyTM_run_ofCfg`). Run the
public counter loop on the copy with a one-cell body: a `true` moves right and returns to the
anchor; a `false` or a blank takes the exit without moving. Both loop exits go to one check of
the current cell: a `false` moves right and accepts, anything else rejects. Clear the scratch
copy (`Turing.clearTM_run_ofCfg`). At most `min n (i + 1)` rounds run
(`canonSkipFin_iff`, `Turing.counterLoop_time_le`, `Turing.counterOverhead_le_of_le`). -/
private lemma exists_canonUnaryTM :
    ∃ (m : ℕ) (S : Type) (_ : Fintype S) (_ : DecidableEq S) (U : MultiTapeTM m Bool S)
      (entry : S) (exit : Bool → S) (bound : Fin m) (a : ℕ), Function.Injective exit ∧
      ∀ (x w : List Bool) (d : Cfg m Bool S x), d.state = some entry →
        1 ≤ d.inputPos.val →
        d.workTapes bound = FinTM.bufferTape w → d.workTapePos bound = 0 →
        (∀ j, j ≠ bound → d.workTapes j = FinTM.bufferTape [] ∧ d.workTapePos j = 0) →
        ∃ t ≤ a * (x.length + w.length + 1),
          (U.runFrom d t).state =
            some (exit (codeSkipFin (counterValue w + 1) (x.drop (d.inputPos.val - 1))).isSome) ∧
          (U.runFrom d t).output = d.output ∧
          (∀ u < t, ∀ v, (U.runFrom d u).state ≠ some (exit v)) ∧
          (U.runFrom d t).workTapes = d.workTapes ∧
          (U.runFrom d t).workTapePos = d.workTapePos ∧
          ∀ ys, codeSkipFin (counterValue w + 1) (x.drop (d.inputPos.val - 1)) = some ys →
            (U.runFrom d t).inputPos.val = x.length + 1 - ys.length := by
  sorry
