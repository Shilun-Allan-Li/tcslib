## Known pitfalls at this pin

The library fill lists (`briefs/lib-fill-batch{W,P,L}.md`) carry over
verbatim, plus:
- `exists_loopFindTM`'s seams are full configuration equalities at
  `Cfg.ofWords`/`stateWord` — the candidate invariant permits length
  `≤ n + 1`, and the loop-state word must carry everything that
  crosses a seam.
- `Nat.bits 0 = []`; little-endian; `Nat.bits` needs
  `Mathlib.Data.Nat.Bits` (imported here already).
- The split payload `pairEncode (w.take i) (w.drop i)` has length
  `n + i + 2 ≤ 2n + 2` — inside the envelope, but only if emitted
  from the preserved original input, never reconstructed from the
  candidate's bits (the candidate is a length counter only).
