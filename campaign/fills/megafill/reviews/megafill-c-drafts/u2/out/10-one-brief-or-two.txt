Does U2-E follow from U2-U? No, not from the statement. exists_selfUniversalK gives, per code α,
U's run on pairEncode α w against the coded machine's run on the same pairEncode α w. U2-E needs
U's run on pairEncode α x against the coded machine's run on the suffix x. The only reduction is
to apply U2-U to a derived scheme E' whose machine for α runs E.machine α on the suffix (a ruler
host over it). E' then needs its own canonizer computing serializeK (E'.machine α), a table-level
compiler with no published row. Its time is C_α (t + 1), so the composite is C'(C_α (t + 1) + 1).
That is a new construction, not a corollary. The docstrings agree: U2-E's sketch builds its own
startup and ruler host, and U2-U's docstring mentions only exists_selfUniversal (k = 1) as a
consumer.
Does U2-U follow from U2-E? No: U2-E has no space clause, and its simulated input is the suffix.
=> The draft's claim "neither follows from the other" holds.
