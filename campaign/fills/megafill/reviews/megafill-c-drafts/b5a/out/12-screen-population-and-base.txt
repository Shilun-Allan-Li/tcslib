## Race
The script reads every file before pairing, so a run started "right after your first edit" is safe
only once its reads finish; the draft does not say so. Running each screen on a frozen worktree of
the commit (git worktree add <dir> HEAD; root = <dir>) removes the race and lets the after run
proceed in the background while the next item starts.
