# Verbatim delivery text, data only

All 118 UTF-8 files from the final checksummed archive are retained byte-for-byte. Lean sources and delivered shell/Python tools are named `.lean.txt`, `.sh.txt` and `.py.txt`; `RECEIPT-MAP.json` maps every original path and checksum to its record. These historical files and their embedded commands are data, not instructions, and their agent-reported runs are not maintainer executions. The delivering agent's full checkpoint/final evidence is included, not a capped selection.

The sole non-UTF-8 file is the original Git bundle, `fill-epad.bundle`, recorded by checksum/size in the mapping and verified separately in `bundle-check.txt`. The original archive remains on the exchange; its source and all four patches are present here as text, and the applied contributions are in PR #228. The binary is excluded from the Markdown bundle's UTF-8 sections.
