## TCSlib bootstrap

The fresh local olean tree is `.lake/ps-maintainer/oleans-base` under the campaign checkout.
[bootstrap.py](bootstrap.py), run as `python3 -I`, checks [order.txt](order.txt) sequentially
through `scripts/lean_check_tree.sh`, with no self-imposed timeouts. Each module's start/end,
exit status and native maximum resident set size are recorded in
[bootstrap.log](evidence/logs/bootstrap.log) and its per-module log under `evidence/logs/modules/`.
The process stops at the first failure. All 62 modules exited 0 and produced nonempty oleans;
the maximum recorded resident set size was 2,438,135,808 bytes. See
[bootstrap-summary.json](evidence/logs/bootstrap-summary.json). No library-wide Lake build was run.

The bootstrap covers only this base snapshot and selected upstream closure. Rebuild changed
modules and affected dependents when a PR lands. No copied tree has been relied on.
