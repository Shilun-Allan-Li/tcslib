## Host contract

The statement is mathematically credible as written, with no missing `k ≤ B`, coin-length, positive-width, or positive-trial hypothesis. It computes the total list operation actually defined: overlapping blocks, repeated blocks when `B=0`, and short or empty prefixes are all legitimate. The test hypothesis supplies polynomial time on the parameter/value word pair; it is not an assumption that evaluating an arbitrary predicate is automatically efficient.

Its existential form is sufficient. From the option equation one obtains rejection iff `g z = []`, success iff it is nonempty, and the accepted value from the tail. In the failure branch, `listToNat [].tail = 0`, so the advertised `getD 0` identity follows. Consumers need no definition of the machine or its witness. They also need no fixed-width or canonical payload: the value equation and the tail-length upper bound suffice.

| Consumer | Specialization and remaining interface |
|---|---|
| dl-a · `polyTimeComputable_expSampleRaw` | `E a v := v < a`, with the modulus numeral as `par`, `sizeStr` for `kw`, and the parameter word for `bw` and `tw`. `sampleBelowL_eq_rejectBlocksL` identifies the option. The tail computes its zero-default value, and published width normalization gives the output numeral. |
| dl-c · generators and encryption | The same specialization supplies `dlc_numPoly_sample` directly as a polynomial-time tail word. Its existing numeral calculus then serves all three machines. `length_sizeStr` supplies the `Nat.size` width. |
| rsa · unit sampler and `rsaGenRaw` | `E a v := v < a ∧ Nat.Coprime v a`. The existing unit-test calculation can be restated on `pairEncode w b`; the all-word specification handles leading zeros. Use `sampleUnitL_eq` and `unitSampleStr_eq`, retaining the existing polynomial-time fallback and width-normalization code. No positive-modulus hypothesis needs adding to the host; the zero-modulus branch simply never accepts. |
| rabin · generators | `E _ v := v.Prime ∧ P v`, with the parameter ignored and the leaf test composed with `pairSndD`. Set `kw=bw` to the width word and `tw` to the unary trial polynomial. The bound on the tail is exactly the premise needed by `rabin_pad_eq`. `samplePrimePL` is in the consumer's own file; the unit-sampling part still uses rsa's published polynomial-time theorem. |

The proof sketch is followable: retain the header, decrement the counter, and drop one block. The step-length estimate `2|x|+4` is independent of the header's internal structure; well-formed states subsequently shrink. Apply `polyTimeComputable_iterateFind` with `R=var` and that orbit bound, split its result as the existing sealed dl-a/dl-c proofs do, and identify the search using `find?_range_and_lt` and `rejectBlocksL_eq_find?`. Replacing the four private loops remains S2 work, as authorized.

The citations point to the intended applications: book/PDF pages 52/64 (DL domain), 53–54/65–66 (RSA domain and exponent sampling), 61/73 (Rabin domain), and 63/75 (Blum-prime generation). They are application references, not a textbook theorem asserting this generic host. Truncation to a supplied number of trials and a separate statistical-error lemma correctly distinguish the finite-coin implementation from the ideal repeated sampling. Nothing here proves an unconditional prime-class density estimate or an efficient safe-prime generator.
