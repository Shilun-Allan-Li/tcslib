# Universal Classes of Hash Functions

<a id="pdf-1c24478649f7-p001-b002"></a>
<!-- pdf-source: page=1; block=2; confidence=0.99 -->
This paper gives an *input independent* average linear time algorithm for storage and retrieval on keys. The algorithm makes a random choice of hash function from a suitable class of hash functions. Given any sequence of inputs the expected time (averaging over all functions in the class) to store and retrieve elements is linear in the length of the sequence. The number of references to the data base required by the algorithm for any input is extremely close to the theoretical minimum for any possible hash function with randomly distributed inputs. We present three suitable classes of hash functions which also can be evaluated rapidly. The ability to analyze the cost of storage and retrieval without worrying about the distribution of the input allows as corollaries improvements on the bounds of several algorithms.

<a id="pdf-1c24478649f7-p002-b001"></a>
<!-- pdf-source: page=2; block=1; confidence=0.91 -->
The paper introduces notation, defines universal classes, derives their performance properties, constructs efficiently evaluable examples, and gives applications. The stated motivation is to reduce sensitivity to input distributions by randomizing the algorithm choice.

## Notation

<a id="pdf-1c24478649f7-p002-b003"></a>
<!-- pdf-source: page=2; block=3; confidence=0.90 -->
For a set $S$, $|S|$ is its cardinality; for real $x$, $\lceil x\rceil$ is the least integer at least $x$. For bit strings, $x\oplus y$ denotes XOR, and $\mathbb Z_n$ denotes integers modulo $n$. Hash functions map $A$ to $B$, with $|A|>|B|$; elements of $A$ are keys and elements of $B$ are indices. Define $\delta_f(x,y)=1$ when $x\ne y$ and $f(x)=f(y)$, and $0$ otherwise. Replacing an argument by a set means summing over its elements; in particular, $\delta_H(x,S)$ sums collision indicators over functions in $H$ and keys in $S$.

## Properties of Universal Classes

<a id="pdf-1c24478649f7-p002-b005"></a>
<!-- pdf-source: page=2; block=5; confidence=0.99 -->
Let $H$ be a class of functions from $A$ to $B$. We say that $H$ is universal$_2$ if for all $x,y$ in $A$, $\delta_H(x,y)\le |H|/|B|$. That is, $H$ is universal$_2$ if no pair of distinct keys collide under more than $(1/|B|)$th of the functions.

<a id="pdf-1c24478649f7-p003-b001"></a>
<!-- pdf-source: page=3; block=1; confidence=0.96 -->
The condition controls collisions pairwise; it does not require uniform distribution of larger subsets, which may matter in some applications.

<a id="pdf-1c24478649f7-p003-b002"></a>
<!-- pdf-source: page=3; block=2; confidence=0.84 -->
**Proposition 1.** For any collection $H$ of hash functions, not necessarily universal, there exist distinct $x,y\in A$ such that $\delta_H(x,y)>|H|(1/|B|-1/|A|)$.

<a id="pdf-1c24478649f7-p003-b003"></a>
<!-- pdf-source: page=3; block=3; confidence=0.98 -->
**Proposition 1.** Given any collection $H$ of hash functions (not necessarily universal$_2$), there exist $x,y\in A$ such that
\[
\delta_H(x,y)>|H|\left(\frac1{|B|}-\frac1{|A|}\right).
\]
**Proof.** Let $a=|A|$, $b=|B|$, and $f\in H$. For each $i\in B$, let $A_i$ be the set of elements of $A$ mapped into $i$ by $f$, and let $a_i=|A_i|$. Then
\[
\delta_f(A,A)=\sum_{i\in B}a_i(a_i-1)\ge b\bigl((a/b)^2-a/b\bigr)=a^2(1/b-1/a).
\]
Summing over the $|H|$ functions gives $\delta_H(A,A)\ge a^2|H|(1/b-1/a)$. The sum on the left has $a^2$ terms, of which the diagonal terms are zero. Therefore some distinct $x,y\in A$ satisfy $\delta_H(x,y)>|H|(1/b-1/a)$.

<a id="pdf-1c24478649f7-p003-b004"></a>
<!-- pdf-source: page=3; block=4; confidence=0.98 -->
An associative memory supports storing, retrieving, and deleting key-data pairs. One implementation hashes keys into an array of $|B|$ linked lists and searches the selected list for the key.

<a id="pdf-1c24478649f7-p004-b001"></a>
<!-- pdf-source: page=4; block=1; confidence=0.98 -->
In this associative memory system, the time required to perform an operation involving the key $x$ is less than some linear function of the length of the list indexed by $f(x)$. If $S$ is the set of keys which have been the subject of a Store, this list is of length $1+\delta_f(x,S)$. The next proposition calculates the expected length of this list. Once again, we emphasize that this result holds for any $x$ and $S$, and that the average is over the class of hash functions.

**Proposition 2.** Let $x$ be any element of $A$ and $S$ any subset of $A$. Let $f$ be a function chosen randomly from a universal$_2$ class of functions (with equal probabilities on the functions). Then the mean value of $\delta_f(x,S)$ is $\le |S|/|B|$.

<a id="pdf-1c24478649f7-p004-b002"></a>
<!-- pdf-source: page=4; block=2; confidence=0.89 -->
**Proposition 2.** For any $x\in A$ and $S\subseteq A$, if $f$ is chosen uniformly from a universal class of functions $H:A\to B$, then $\mathbb E_f[\delta_f(x,S)]\le |S|/|B|$.

<a id="pdf-1c24478649f7-p004-b003"></a>
<!-- pdf-source: page=4; block=3; confidence=0.81 -->
**Proof.** Expand the mean over $f\in H$ and write $\delta_f(x,S)=\sum_{y\in S}\mathbf 1[f(x)=f(y)]$. By universality, each collision has probability at most $1/|B|$, so summing over $S$ gives the stated bound.

<a id="pdf-1c24478649f7-p004-b004"></a>
<!-- pdf-source: page=4; block=4; confidence=0.94 -->
**Definition.** For a request concerning $x$, let its cost be $1+\delta_f(x,S)$, with $S$ the keys inserted earlier. For a request sequence $R$, $C(f,R)$ is the sum of these costs in request order. This cost models linked lists; balanced-tree resolution instead gives individual cost $1+\log\delta_f(x,S)$.

<a id="pdf-1c24478649f7-p004-b005"></a>
<!-- pdf-source: page=4; block=5; confidence=0.93 -->
**Proposition 3.** If $R$ has $r$ requests, including $k$ insertions, and $f$ is selected uniformly from a universal class $H$, then $\mathbb E[C(f,R)]\le r(1+k/|B|)$.

<a id="pdf-1c24478649f7-p004-b006"></a>
<!-- pdf-source: page=4; block=6; confidence=0.96 -->
**Proof.** Each request sees at most $k$ previously inserted keys. Proposition 2 bounds its expected cost by $1+k/|B|$; add these bounds over the $r$ requests.

<a id="pdf-1c24478649f7-p005-b001"></a>
<!-- pdf-source: page=5; block=1; confidence=0.98 -->
Proposition 2 gives a bound on the probability of error when $f$ is chosen from a class of universal$_2$ functions, and suggests that to achieve an error probability of less than $p$, we should let $B$ have size $|S|/p$. To be precise, Proposition 2 says that if $x$ and $S$ are specified, then a randomly chosen $f$ will erroneously accept $x$ with probability less than $1/p$.

<a id="pdf-1c24478649f7-p005-b002"></a>
<!-- pdf-source: page=5; block=2; confidence=0.96 -->
**Proposition 4.** For $x\in A$, $S\subseteq A$, and $p=\mathbb E_f[\delta_f(x,S)]$ under uniform choice from a universal class $H$, the probability that $\delta_f(x,S)>tp$ is less than $1/t$.

<a id="pdf-1c24478649f7-p005-b003"></a>
<!-- pdf-source: page=5; block=3; confidence=0.63 -->
**Proof.** The nonnegative values $\{\delta_f(x,S):f\in H\}$ have mean $p$. The excerpt argues that if a value exceeds $tp$, enough other values must lie below $p$ to preserve that mean, yielding probability below $1/t$.

<a id="pdf-1c24478649f7-p006-b001"></a>
<!-- pdf-source: page=6; block=1; confidence=0.99 -->
For the classes $H_2$ and $H_3$ presented in the next section, Markowsky [7] has calculated bounds on the second and fourth moments of the set of costs. These are used to show that when $|S|/|B|$ is about 1, the probability that a cost (of a request or sequence of requests) is greater than $t\mu$ is less than $1/t^2$ and also less than $1/t^4.

When balanced trees are used in place of linked lists, and $|S|/|B|=1$, the expected value of $\delta_f(x,S)$ may not be worth the added bookkeeping if one cares only about the average cost. However, using balanced trees makes an exponential reduction in the probability that a request is intolerably expensive. For a request involving key $x$ to require searching more than $t$ levels of the tree, $\delta_f(x,S)$ would have to have at least $2^t$ elements. This means that the probability of a request requiring more than $t$ steps is no more than $1/2^t$, and if $f$ is chosen from $H_2$ or $H_3$, the probability is less than $1/2^{4t}$.

<a id="pdf-1c24478649f7-p006-b002"></a>
<!-- pdf-source: page=6; block=2; confidence=0.99 -->
**Proposition 5.** Given any single hash function, let $E_1$ be the expected cost with respect to that function of a random request after $k$ random insertions have been made. Let $E_2$ be the expected cost (averaging over a universal$_2$ class of hash functions) of any request after any $k$ insertions have been made. Then $E_1\ge(1-\epsilon)E_2$ where $\epsilon=|B|/|A|$.

<a id="pdf-1c24478649f7-p006-b003"></a>
<!-- pdf-source: page=6; block=3; confidence=0.99 -->
**Proof.** Let $a=|A|$ and $b=|B|$. Let $S$ be the set of elements of $A$ which were inserted prior to the request on the element $x$. Proposition 2 implies that $E_2\le1+|S|/b$. We will show that $E_1\ge1+|S|(1/b-1/a)$, assuming that $S$ and $x$ were chosen randomly. A simple calculation then verifies that $E_1\ge(1-b/a)E_2$.

In the proof of Proposition 1, it was shown that $\delta_f(A,A)\ge a^2(1/b-1/a)$ for any hash function $f$. Thus if $x$ and $y$ are chosen at random from $A$, then $\operatorname{Expected}(\delta_f(x,y))=(1/a^2)\delta_f(A,A)\ge1/b-1/a$. Recall that $\delta_f(x,S)=\sum_{y\in S}\delta_f(x,y)$. Since the expectation of a sum is the sum of the individual expectations, $\operatorname{Expected}(\delta_f(x,S))\ge|S|(1/b-1/a)$. Thus, $E_1\ge1+|S|(1/b-1/a)$.

## Some universal classes. The next section introduces a first class $H_1$, suited to keys represented as bit strings that can conveniently be multiplied by the computer.

<a id="pdf-1c24478649f7-p007-b001"></a>
<!-- pdf-source: page=7; block=1; confidence=0.90 -->
For sets $A=\{0,\ldots,a-1\}$ and $B=\{0,\ldots,b-1\}$, choose prime $p\ge a$ and a map $g:\mathbb Z_p\to B$ whose fibers have size at most $\lceil p/b\rceil$; reduction modulo $b$ is one choice. For nonzero $m\in\mathbb Z_p$ and $n\in\mathbb Z_p$, set $h_{m,n}(x)=(mx+n)\bmod p$ and $f_{m,n}=g\circ h_{m,n}$. Let $H_1=\{f_{m,n}:m\ne0\}$.

<a id="pdf-1c24478649f7-p007-b002"></a>
<!-- pdf-source: page=7; block=2; confidence=0.99 -->
**Lemma 6.** When $H_1$ is defined as above, then for any $x,y\in A$ with $x\ne y$, $\delta_{H_1}(x,y)=\delta_g(\mathbb Z_p,\mathbb Z_p)$.

<a id="pdf-1c24478649f7-p007-b003"></a>
<!-- pdf-source: page=7; block=3; confidence=0.98 -->
**Proposition 7.** The class $H_1$ is universal$_2$.

**Proof.** Let $n_i$ be the number of elements in $\{t\in\mathbb Z_p:g(t)=i\}$. Since $g$ was chosen so that $n_i\le\lfloor p/b\rfloor$ for each $i$, for a given $r\in\mathbb Z_p$ there are no more than $(p-1)/b$ choices for $s$ such that $r\ne s$ but $g(r)=g(s)$. Since there are $p$ choices for $r$, $p(p-1)/b\ge\delta_{H_1}(x,y)$. Recalling that for $x=y$, $\delta_{H_1}(x,y):=0$, this shows that $H_1$ is universal$_2$.

<a id="pdf-1c24478649f7-p007-b004"></a>
<!-- pdf-source: page=7; block=4; confidence=0.90 -->
With $p=2^j-1$, a $2j$-bit input split into high and low $j$-bit parts can be reduced modulo $p$ by adding those parts, since $2^j\equiv1\pmod p$; reduction then needs at most a comparison and subtraction. If $b$ is a power of two, the final reduction to $B$ uses low bits.

<a id="pdf-1c24478649f7-p007-b005"></a>
<!-- pdf-source: page=7; block=5; confidence=0.99 -->
Suppose for $m\in\mathbb Z_p$ we define $h_m(x)=mx\pmod p$, and as before define $f_m(x)$ as $g(h_m(x))$. Let $H=\{f_m\mid m\in\mathbb Z_p\text{ and }m\ne0\}$. It can be shown that this class of functions comes within a factor of two of being universal$_2$, that is, $\delta_H(x,y)\le2(|H|/|B|)$ for any $x$ and $y$. On the other hand, this bound cannot be improved significantly. For instance, let $b=|B|$, and choose $k$ so that $p=kb+k+1$ is prime. Let $g(x)=x\pmod b$. Let $x=1$ and $y=b+1$. It can be shown that the $2k$ functions $f_1,f_2,\ldots,f_k,f_{p-k},f_{p-k+1},\ldots,f_{p-1}$ each map $x$ and $y$ to the same value. Thus, $\delta_H(x,y)=2k$, while
\[
\frac{|H|}{|B|}=\frac{p-1}{b}=\frac{kb+k}{b}=\left(1+\frac1b\right)k.
\]

<a id="pdf-1c24478649f7-p008-b001"></a>
<!-- pdf-source: page=8; block=1; confidence=0.99 -->
Thus, $\delta_H(x,y)=2k$, while
\[
\frac{|H|}{|B|}=\frac{p-1}{b}=\frac{kb+k}{b}=\left(1+\frac1b\right)k.
\]

<a id="pdf-1c24478649f7-p008-b002"></a>
<!-- pdf-source: page=8; block=2; confidence=0.99 -->
**Proposition 8.** Suppose $B=\{0,1,\ldots,b-1\}$ where $b$ is a power of two and $H$ is a class of functions from $A$ to $B$ with the property that for some real number $r$, for each $x,y\in A$ with $x\ne y$, and for each $i\in B$, $|\{f\in H\mid f(x)\mathbin{\oplus}f(y)=i\}|\le r|H|$. Define the class $J$ of hash functions from $A\times A$ to $B$ as follows: for $f,g\in H$, define $h_{f,g}((x_1,x_2))=f(x_1)\mathbin{\oplus}g(x_2)$, and let $J=\{h_{f,g}\mid f,g\in H\}$. Then for all $x,y\in A\times A$ with $x\ne y$, and for all $i\in B$, $|\{h\in J\mid h(x)\mathbin{\oplus}h(y)=i\}|\le r|J|$.

<a id="pdf-1c24478649f7-p008-b003"></a>
<!-- pdf-source: page=8; block=3; confidence=0.93 -->
**Proposition 8.** Under the preceding hypothesis, for distinct $x,y\in A\times A$ and every $i\in B$, $|\{h\in J:h(x)\mathbin{\oplus}h(y)=i\}|\le\gamma |J|$. Hence the construction extends the hash domain from $A$ to $A\times A$.

<a id="pdf-1c24478649f7-p008-b004"></a>
<!-- pdf-source: page=8; block=4; confidence=0.79 -->
**Proof.** Write $x=(x_1,x_2)$ and $y=(y_1,y_2)$; after interchanging coordinates if needed, assume $x_1\ne y_1$. For a fixed $i$, count pairs $f,g\in H$ satisfying $f(x_1)\oplus g(x_2)\oplus f(y_1)\oplus g(y_2)=i$ by summing over values of $g(x_2)\oplus g(y_2)$. For each such value, the hypothesis bounds the compatible $f$ count by $\gamma|H|$, so the total is at most $\gamma|H|^2=\gamma|J|$.

<a id="pdf-1c24478649f7-p008-b005"></a>
<!-- pdf-source: page=8; block=5; confidence=0.77 -->
Repeated application of Proposition 8 extends a universal family to arbitrarily long keys; if the original functions run in constant time, the extended functions run in time proportional to key length. Applying it to $H_1$ may incur a small excess over the universal bound when $|B|$ is small relative to $p$; allowing $m=0$ is suggested as an alternative, yielding a universal class with $\gamma=1/|B|$.

<a id="pdf-1c24478649f7-p008-b006"></a>
<!-- pdf-source: page=8; block=6; confidence=0.91 -->
The next family, denoted $H_3$, is presented as a multiplication-free universal class, interpretable as linear transformations over the two-element field.

<a id="pdf-1c24478649f7-p009-b001"></a>
<!-- pdf-source: page=9; block=1; confidence=0.83 -->
**Definition.** Let $A$ be the set of $i$-bit strings and $B$ the set of $j$-bit strings. Let $M$ consist of length-$i$ arrays $m$ with entries in $B$, interpreted as Boolean matrices. If $m(k)$ is entry $k$ and $x_k$ is bit $k$ of $x$, define $f_m(x)=\bigoplus_{k=1}^{i} x_k m(k)$. Set $H_3=\{f_m:m\in M\}$.

<a id="pdf-1c24478649f7-p009-b002"></a>
<!-- pdf-source: page=9; block=2; confidence=0.98 -->
**Proposition 9.** The class $H_3$ is universal.

<a id="pdf-1c24478649f7-p009-b003"></a>
<!-- pdf-source: page=9; block=3; confidence=0.84 -->
**Proof.** Induct on input length $i$, using Proposition 8. For $i=1$, $A=\{0,1\}$, $M=B$, and $f_m(0)=0$, $f_m(1)=m$; for each output $u\in B$, exactly one function has $f_m(0)\oplus f_m(1)=u$, giving the Proposition 8 condition with $\gamma=1/|H_3|$. Proposition 8 gives the induction step, so every $H_3$ is universal.

<a id="pdf-1c24478649f7-p009-b004"></a>
<!-- pdf-source: page=9; block=4; confidence=0.98 -->
The class $H_2$ of hash functions presented below is similar to $H_3$, but the functions in $H_2$ require less time and more space. This is accomplished by first mapping the key into a longer bit string, but one with fewer 1's. Specifically, suppose $A$ can be viewed as the set of $i$-digit numbers written in base $\alpha$. For $x\in A$, let $x_k$ denote the $k$th digit of $x$. Define $g$ to be the function which maps $x$ into the bit string of length $i\alpha$ which has 1's in positions $x_1+1,x_1+x_2+1,x_1+x_2+x_3+1,\ldots$. Then $|A|=\alpha^i$ and $|B|=2^{i\alpha}$. If $H_3$ is the class defined above for $i\alpha$-bit keys, then $H_2=\{f\circ g\mid f\in H_3\}$. The fact that $H_2$ is universal$_2$ follows immediately from the facts that $g$ is 1 to 1 and $H_3$ is universal$_2$.

<a id="pdf-1c24478649f7-p009-b005"></a>

The paper notes that implementations of the extended $H_1$ family on IBM 360 reportedly used about four fast instructions per key byte, then introduces two theorems summarizing practical and theoretical implications.

<a id="pdf-1c24478649f7-p009-b006"></a>
<!-- pdf-source: page=9; block=6; confidence=0.99 -->
**Theorem 10.** Using a standard model of computation, where multiplication, choosing of random numbers, and memory references take unit time, any sequence of $r$ requests to an associative memory can be processed in expected time $O(r)$.

<a id="pdf-1c24478649f7-p009-b007"></a>
<!-- pdf-source: page=9; block=7; confidence=0.75 -->
**Proof step.** Proposition 3 implies that using a universal hash family and choosing $|B|$ approximately equal to $r$ bounds the expected number of memory operations; the extracted page ends before the argument is completed.

<a id="pdf-1c24478649f7-p010-b001"></a>
<!-- pdf-source: page=10; block=1; confidence=0.96 -->
With a universal hash class, a class member can be selected once and each request handled in constant time on average over the class.

<a id="pdf-1c24478649f7-p010-b002"></a>

Theorem 11

<a id="pdf-1c24478649f7-p010-b003"></a>
<!-- pdf-source: page=10; block=3; confidence=0.99 -->
**Theorem 11.** Using a standard model, where Boolean operations on machine addresses, choosing of random numbers, and memory references take unit time, any sequence of requests to an associative memory can be processed in expected time linear in the number of bits in the input.

<a id="pdf-1c24478649f7-p010-b004"></a>
<!-- pdf-source: page=10; block=4; confidence=0.90 -->
**Proof.** Use the class $H_2$ or $H_3$.

<a id="pdf-1c24478649f7-p010-b005"></a>
<!-- pdf-source: page=10; block=5; confidence=0.93 -->
Randomizing the hash function after the data is fixed makes the linear expected-time guarantees of Theorems 10 and 11 apply probabilistically, even across different input data. If changing a hash function is costly, one may choose one universal hash function once, monitor collisions and rehash when they become excessive, or sample candidates instead of searching extensively. Universal classes also simplify average-performance analysis because the hash function is independent of the algorithm's key requests.

<a id="pdf-1c24478649f7-p011-b001"></a>
<!-- pdf-source: page=11; block=1; confidence=0.92 -->
Two applications illustrate the approach: randomized nearest-neighbor search in the plane, and sparse polynomial multiplication using associative memory with a universal hash function.

<a id="pdf-1c24478649f7-p011-b002"></a>

For sparse polynomials $P,Q$ with respectively $n,m$ nonzero terms, let $CP_i,EP_i$ and $CQ_j,EQ_j$ denote their coefficients and exponents. Assuming constant-time scalar arithmetic and associative-memory operations, the algorithm accumulates coefficient products under summed exponents and runs in average time $O(nm)$.

<a id="pdf-1c24478649f7-p011-b003"></a>
<!-- pdf-source: page=11; block=3; confidence=0.98 -->
Choose a hash function. For each $i=1,\ldots,n$ and $j=1,\ldots,m$, retrieve $K$ at key $EP_i+EQ_j$ (returning zero if absent), then store at that key the value $K+CP_i\cdot CQ_j$. Finally print all stored key-value pairs.
