# Specification of Circuit Compilation

**Claim.** Compiling a circuit tree after an acyclic gate list extends that list acyclically, computes the tree's value at its root, and satisfies the stated bounds on root index, list length, depth, and newly appended gates.

**Proof.** Use structural induction on the circuit tree. For a negative literal, compilation appends one NOT gate whose input is the literal's input vertex. That vertex is less than $n$, so the appended list remains acyclic (`BoolCircuit.GatesAcyclic.snoc`). The new gate's output is the root; the last-vertex evaluation and depth facts (`BoolCircuit.vertexValue_last`, `BoolCircuit.vertexDepth_last`) show that it computes the negated input and has depth one. The size bound follows because the literal has size one, and the appended gate has a single distinct input and satisfies the fan-in bound. For a positive literal, compilation leaves the gate list unchanged and returns the input vertex. The input-vertex evaluation and depth facts (`BoolCircuit.vertexValue_input`, `BoolCircuit.vertexDepth_input`) give the value and depth claims, while the length and new-gate claims are immediate.

For a node with children $cs$, compile the children and apply the list compilation specification (`BoolCircuit.compileTrees_spec`). Write the resulting list and roots as $r$, and append a gate $g$ whose inputs are the deduplicated child roots. The list specification gives acyclicity and the child root values. Each such root is an earlier valid vertex, so appending $g$ preserves acyclicity (`BoolCircuit.GatesAcyclic.snoc`). To check evaluation, the list of child-root values agrees with the list of child evaluations. Deduplicating the roots does not change either an “any” or an “all” Boolean aggregate (`BoolCircuit.any_dedup`, `BoolCircuit.all_dedup`); these aggregates are exactly the evaluations of OR-nodes and AND-nodes (`BoolCircuit.TreeCircuit.eval_node_false`, `BoolCircuit.TreeCircuit.eval_node_true`). Thus the last gate computes the node's value. Its depth is one more than the maximum child depth, and the list depth bound gives the required estimate using the node depth formula (`BoolCircuit.vertexDepth_last`, `BoolCircuit.TreeCircuit.depth_node`). The list length bound, together with the node size formula, gives the claimed size estimate (`BoolCircuit.TreeCircuit.size_node`). Previously appended gates retain their well-formedness and fan-in bounds by the list specification; the new gate has distinct inputs by deduplication and has at most one input per child, giving the required bound from the node's maximum fan-in (`BoolCircuit.TreeCircuit.maxFanin_node`).
