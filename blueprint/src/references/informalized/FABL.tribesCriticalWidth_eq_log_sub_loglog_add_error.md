# Width Error Identity

**Claim.** For every natural number $w$, the width equals the base-two logarithm of the critical dimension minus the base-two logarithm of the logarithm of the critical dimension, plus the critical width error.

**Proof.** By definition, the critical width error is the width minus the difference of the two logarithmic terms. Rearranging this defining equality gives the stated identity.
