# Composed Threshold Identity

**Claim.** For every real number $\epsilon$, if $t=(\sqrt{\epsilon}+\frac12)/2$, then $1-2t=\frac12-\sqrt{\epsilon}$.

**Proof.** Substitute the definition of $t$: $1-2t=1-2(\sqrt{\epsilon}+1/2)/2=1-(\sqrt{\epsilon}+1/2)=1/2-\sqrt{\epsilon}$.
