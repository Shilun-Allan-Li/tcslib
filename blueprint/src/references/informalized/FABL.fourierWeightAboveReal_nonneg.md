# Nonnegativity of Fourier weight tails

**Claim.** For every real threshold, the Fourier weight above that threshold is nonnegative.

**Proof.** The tail is a finite sum of squared Fourier coefficients, since each weight is the square of a real number. Every summand is nonnegative, so the sum is nonnegative.
