# Affine moment at zero

**Claim.** At $t=0$, the average of $(1+ctX(x))^r$ over a finite nonempty set is $1$.

**Proof.** At $t=0$, every base equals $1$, and hence every summand is $1^r=1$. The average of the constant function with value $1$ is $1$.
