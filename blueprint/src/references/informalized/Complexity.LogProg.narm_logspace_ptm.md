# Logspace Simulation Preserves Output Probabilities

**Claim.** If the register program has polynomially bounded registers and all its oracle languages are in $\text{LOGSPACE}$, then a finite-state nondeterministic machine uses logarithmic space and preserves, for every qualifying input and choice length, the probability of each one-bit output.

**Proof.** For each oracle language, choose a deterministic logarithmic-space decider and its space constant. Sum these constants to obtain a uniform bound for the banked oracle simulator. The polynomial register bound gives, by `log_poly_bound`, a constant $K$ such that every register's binary representation has length at most $W=K\,\mathrm{logSpace}(n)$ on inputs of length $n$; this uses `length_bits_le_log` and monotonicity of the logarithm, just as in the polynomial-register estimate. The possible virtual oracle queries have length bounded by a polynomial in $n+1$, so a second application of `log_poly_bound` bounds the banked oracle space on those queries by $B=C\,\mathrm{logSpace}(n)+1$ for a fixed constant $C$. The validity conditions and register bounds then imply the guard required by the simulation: `npre_of_npreS` transfers validity to the banked oracle deciders, and `NHalts.mono` upgrades the halting hypothesis to this guarded condition. Apply the simulation theorem `narm_space_randProb`. It constructs a finite-state nondeterministic machine that halts at a common time, uses at most $m(W+2)+k_D(2B+1)$ space, preserves the yes-answer relation, and, for each bit, has output probability equal to the register program's answer probability. Since $W$ and $B$ are each bounded by a constant multiple of $\mathrm{logSpace}(n)$ (using $1\leq\mathrm{logSpace}(n)$), this space is at most $(mC+2m+k_D(2C+3))\mathrm{logSpace}(n)$ after enlarging constants as in the proof. This gives one machine and one logarithmic-space constant for all inputs. For any input and length satisfying the stated hypotheses, the same guarded simulation applies, yielding the asserted halting and probability equalities.
