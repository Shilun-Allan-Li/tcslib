# Even-Power Coefficient Vanishing

**Claim.** For every natural number $j$, the coefficient assigned to the even exponent $2j$ is zero.

**Proof.** The exponent $2j$ is even, so it is not odd. Thus the condition selecting the nonzero branch in the definition of the coefficient fails, and the definition assigns the value zero.
