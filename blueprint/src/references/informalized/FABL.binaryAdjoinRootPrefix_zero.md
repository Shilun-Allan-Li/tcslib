# Zero-Length Root-Power Prefix

**Claim.** For any length-$\ell$ binary vectors $m$ and $y$, the root-power prefix of length zero is zero.

**Proof.** The prefix sums over indices $i$ in the range from $0$ to $0$. This range is empty, so its sum is zero.
