# Embedded Reference Step Correspondence

**Claim.** A single step of the source machine can be matched by the embedded reference action, preserving the host input position and output, updating administrative tapes as specified, and choosing a tag valid at the stepped source position.

**Proof.** First identify the embedded machine's buffer tape with the source configuration's current input symbol, and its embedded source work tapes with the source work-tape symbols. These identifications follow from the buffer representation of the input symbol (`Turing.FinTM.bufferTape_inputSymbol`) and from the fact that the middle tape block is the buffer (`Turing.FinTM.tapeBlocks_buffer`). Split on whether the source state is halted. If it is halted, the source step leaves the configuration unchanged (`Turing.MultiTapeTM.step_of_halt`). The embedded action then makes no effective movement on the input or source tapes, leaves the output unchanged, and performs precisely the prescribed administrative tape operations. Choose the same tag; the boundary condition is inherited because the source input position is unchanged. If the source is in a state, let its transition action be $a$, and let $m$ be the virtual input movement used by the embedded action. The correctness of virtual movement says both that the shifted source input position advances by exactly the amount represented by $m$ and that the updated position admits the new tag (`Turing.FinTM.virtualMove_correct`). Choose that new tag. The source step is exactly the application of $a$ (`Action.apply` and the definition of `MultiTapeTM.step`). The embedded action sees the same input and work symbols as the source, so it uses $a$'s source-tape operations; on the administrative tapes it uses the given operations. Its output is empty, hence the host output remains unchanged. The input head also remains fixed because the embedded action's host input movement is zero, whose effect is identity (`Turing.moveInputPos_zero`). Comparing the state, input position, tape contents, tape-head positions, and output gives the claimed configuration equality.
