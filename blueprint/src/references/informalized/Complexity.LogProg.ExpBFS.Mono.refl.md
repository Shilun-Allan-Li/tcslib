# Reflexivity of Boolean Implication

**Claim.** Every integer at which a Boolean-valued function $M$ is true is also one at which $M$ is true.

**Proof.** Fix an integer $z$ and suppose $M(z)=\mathrm{true}$. The required conclusion is the same equality, so it follows directly from the supposition.
