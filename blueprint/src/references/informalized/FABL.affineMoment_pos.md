# Positivity of the affine moment

**Claim.** If every base $1+ctX(x)$ is positive and $\Omega$ is finite and nonempty, then the average of $(1+ctX(x))^r$ over $\Omega$ is positive.

**Proof.** Each summand is positive, since a positive real raised to any real power is positive. The average of a positive function over a finite nonempty set is positive, so the affine moment is positive.
