# Correctness of the Round Programs

**Claim.** For every Boolean word $x$ and streaming seam state $s$, pairing the encoded seam word of $s$ with $x$ gives a request on which the next-state program returns the encoding of the state after one streaming round on $x$, and the chunk program returns exactly that round’s output.

**Proof.** First identify the request’s fresh field, consumed field, phase field, and unread suffix: on the paired request these are respectively the unary encodings of the state’s fresh count, consumed count, and phase, and $x$ with the consumed prefix removed. This is the request-field decomposition supplied by `satReq_fields`. Now write the state as $(j,p,q)$ and split into the phase-$4$ case and the remaining phases. In phase $4$, both programs give the halted-round result directly: the state is retained and the emitted chunk is empty. Otherwise split according to the unread suffix. If it is empty, the round moves to phase $4$ and emits the end marker. If its first bit is false, the consumed count increases by one, and the phase becomes $4$ when the old phase is $0$, and otherwise becomes $0$; the emitted chunk is the false bit. If the first bit is true and the old phase is $0$, the consumed count increases by one, the phase becomes $1$, and the output is true. In the remaining true-bit cases, parse the literal beginning at that bit. If parsing fails, `satToken_failure` says the token splitter has no polarity remainder, so the request programs select the phase-$4$ result with empty output. If parsing succeeds with literal $l$ and remainder `rest`, the parser reconstruction theorem says the input begins with the serialization of $l$ followed by `rest`; `satToken_literal` then identifies the polarity suffix as the literal’s sign followed by `rest`, and hence identifies the current literal as exactly the serialized literal. Finally split on whether `rest` begins with true. This is precisely the link condition tested by the request program, by the equivalence between a one-bit true prefix and a true head. When the link is present, the round increments the fresh count, advances the consumed count by the serialized-literal length, remains in phase $3$, and emits the two fresh-variable literals and the current literal. When it is absent, it advances the consumed count by that length, sets phase $2$ if the old phase is $1$ and phase $3$ otherwise, and emits the current literal. In every branch, the paired-field encoding identities reduce the program’s packed response to the corresponding streaming-round state and output.
