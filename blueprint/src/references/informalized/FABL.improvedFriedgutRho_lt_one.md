# Strict Upper Bound for Rho

**Claim.** For every real number $\eta>0$, the quantity $\rho(\eta)=\eta/(2+\eta)$ satisfies $\rho(\eta)<1$.

**Proof.** The denominator $2+\eta$ is positive. Thus $\eta/(2+\eta)<1$ is equivalent to $\eta<2+\eta$, which follows from $0<2$.
