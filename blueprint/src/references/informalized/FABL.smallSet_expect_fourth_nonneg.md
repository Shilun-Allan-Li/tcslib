# Nonnegative fourth moment

**Claim.** For every real-valued function on the Boolean cube, the uniform expectation of its fourth power is nonnegative.

**Proof.** At every point $x$, the fourth power $f(x)^4$ is nonnegative. The uniform expectation is a finite weighted average with nonnegative weights, so it is nonnegative as well.
