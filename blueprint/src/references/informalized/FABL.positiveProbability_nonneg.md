# Nonnegativity of Positive Probability

**Claim.** For any sign-valued function $f$ on the Boolean cube, the uniform probability that $f$ equals $1$ is nonnegative.

**Proof.** The indicator of the event $f(x)=1$ is nonnegative at every point. Its uniform expectation, which is the positive probability, is therefore nonnegative.
