# Membership in the finite vertex list

**Claim.** Every index in $\mathrm{Fin}(N)$ belongs to the list of all indices in $\mathrm{Fin}(N)$.

**Proof.** The list is obtained by applying the identity function to each index in $\mathrm{Fin}(N)$. In the characterization of membership in a list produced this way, take the witnessing index to be $x$ itself; its image under the identity is $x$.
