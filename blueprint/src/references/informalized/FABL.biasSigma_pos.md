# Positivity of the Bias Scale

**Claim.** If $0<p<1$, then the square root of $4p(1-p)$ is positive.

**Proof.** Because $p>0$ and $1-p>0$, and $4>0$, their product $4p(1-p)$ is positive. The square root of a positive real number is positive, so the bias scale is positive.
