# Boolean cube cardinality

**Claim.** For every natural number $n$, the set of length-$n$ vectors over the two-element field has cardinality $2^n$.

**Proof.** A vector of length $n$ over the two-element field is a function from the $n$ coordinates to a set with two elements. The number of such functions is $2^n$, as asserted.
