# Real-valued quantile on the unit interval

**Claim.** For $0<\alpha<1$, the real-valued extension of the standard Gaussian upper quantile at $\alpha$ agrees with the standard Gaussian upper quantile defined on the open unit interval.

**Proof.** By definition, the real-valued extension uses the interval quantile whenever its input lies in $(0,1)$. Since $\alpha$ lies in that interval, its value is the quantile at the subtype point represented by $\alpha$.
