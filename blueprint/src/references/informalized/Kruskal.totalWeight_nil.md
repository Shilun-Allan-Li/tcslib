# Weight of the Empty Edge List

**Claim.** For any number of vertices, the total weight of the empty list of weighted edges is $0$.

**Proof.** By definition, the total weight is the sum of the edge weights in the list. The empty list contains no edges, so this is an empty sum, which equals $0$.
