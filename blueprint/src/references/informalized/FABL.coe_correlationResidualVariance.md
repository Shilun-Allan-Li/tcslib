# Residual Variance Formula

**Claim.** For $0<\rho<1$, the real value of the nonnegative residual variance $1-\rho^2$ is exactly $1-\rho^2$.

**Proof.** The residual variance is defined as the nonnegative real number whose underlying real value is $1-\rho^2$. Coercing that nonnegative real number back to the reals returns its defining value, so the equality is definitional.
