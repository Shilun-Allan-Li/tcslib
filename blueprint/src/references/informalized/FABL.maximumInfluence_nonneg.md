# Nonnegative maximum influence

**Claim.** For every Boolean function on a finite sign cube, its maximum coordinate influence is nonnegative.

**Proof.** By definition, the maximum influence is the coercion to $\mathbb R$ of a supremum taken in the nonnegative reals. Every nonnegative-real number has nonnegative real coercion, so the claimed inequality follows.
