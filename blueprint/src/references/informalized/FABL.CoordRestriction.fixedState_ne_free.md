# Fixed States Are Nonfree

**Claim.** For every sign $s\in\{\pm1\}$, the restriction state determined by $s$ is not free.

**Proof.** A sign is either $1$ or $-1$. If $s=1$, its determined state is fixed at $1$; if $s=-1$, it is fixed at $-1$. In either case the state is distinct from the free state.
