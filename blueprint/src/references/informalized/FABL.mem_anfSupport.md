# Characterization of ANF Support

**Claim.** A subset $S$ belongs to the support of the coefficient function $c$ exactly when $c(S)$ is nonzero.

**Proof.** By definition, the support consists of those subsets selected from the full collection for which the coefficient is nonzero. Membership in the filtered collection is therefore equivalent to $c(S)\ne0$.
