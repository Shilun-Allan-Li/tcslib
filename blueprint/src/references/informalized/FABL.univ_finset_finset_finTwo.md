# Subsets of a two-element set

**Claim.** The collection of all subsets of a two-element set is precisely the empty set, the two singleton sets, and the whole set.

**Proof.** A subset of the two-element set is determined by whether it contains each of the two elements. The four possible choices give, respectively, the empty set, either singleton, or the whole set. Conversely, each of these four sets is a subset, so the two collections are equal.
