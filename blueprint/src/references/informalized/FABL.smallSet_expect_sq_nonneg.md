# Nonnegative second moment

**Claim.** For every real-valued function on the Boolean cube, the uniform expectation of its square is nonnegative.

**Proof.** Each value $f(x)^2$ is nonnegative. Its uniform expectation is a finite average with nonnegative weights, hence is nonnegative.
