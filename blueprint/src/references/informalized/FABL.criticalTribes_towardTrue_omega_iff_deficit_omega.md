# Equivalent Asymptotic Bounds for the Probability Deficit

**Claim.** The function $\log(N_w)/N_w$ is $O(d_w)$ as $w\to\infty$ if and only if it is $O((1/2+d_w)-1/2)$ as $w\to\infty$.

**Proof.** For every $w$, $(1/2+d_w)-1/2=d_w$. Thus the two comparison functions are pointwise identical, and the two big-$O$ statements are equivalent.
