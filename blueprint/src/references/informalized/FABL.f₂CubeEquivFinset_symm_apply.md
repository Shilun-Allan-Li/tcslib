# Binary vector associated to a finite set

**Claim.** The inverse equivalence sends a finite set $S$ to the vector whose $i$th coordinate is $1$ when $i\in S$ and $0$ otherwise.

**Proof.** The inverse equivalence is defined by the indicator vector of $S$: at each index $i$, its coordinate is $1$ if $i$ belongs to $S$ and $0$ otherwise. The asserted formula is therefore its defining expression.
