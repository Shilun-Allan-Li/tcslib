# Zero-Dimensional Odd Fourier Maximum

**Claim.** For every function from the zero-dimensional Boolean cube to the signs, the maximum of zero and its Fourier coefficients indexed by odd-cardinality subsets is zero.

**Proof.** There are no odd-cardinality subsets of the empty coordinate set. Indeed, its only subset is empty, whose cardinality is zero and hence is not odd. Thus the collection of odd Fourier frequencies is empty, so the set whose maximum defines the nonnegative odd Fourier maximum consists only of zero. Its maximum is zero.
