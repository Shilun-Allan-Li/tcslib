# Injectivity of child group indexing

**Claim.** For natural numbers $r,q$, the map taking $(g,j)$ to its child group index is injective.

**Proof.** The child group index is defined by an equivalence from the product of the two finite index sets to the set of size $r^{q+1}$. Every equivalence is injective, so equal child indices force the original pairs to be equal.
