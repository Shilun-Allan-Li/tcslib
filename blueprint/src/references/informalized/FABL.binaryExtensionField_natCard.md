# Cardinality of the Binary Extension

**Claim.** For every positive integer $\ell$, the binary extension field has exactly $2^\ell$ elements.

**Proof.** The cardinality formula for a finite Galois field gives $p^\ell$ elements in $\mathrm{GaloisField}(p,\ell)$ when $\ell>0$. Taking $p=2$ and using $\ell\ne0$ yields cardinality $2^\ell$.
