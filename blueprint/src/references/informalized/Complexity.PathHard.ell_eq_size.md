# Bit Length and Binary Size

**Claim.** For every natural number $m$, the length of the binary bit list of $m+1$ equals the binary size of $m+1$.

**Proof.** By definition, $\ell(m)$ is the length of the bit list of $m+1$. The standard characterization of natural-number binary size identifies that size with the length of its bit list. Applying this characterization to $m+1$ gives the result.
