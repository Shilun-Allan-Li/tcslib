# Consistency error bound from acceptance and distances

**Claim.** The rank-one consistency error for $\gamma,A$ is at most the test's rejection probability plus twice the relative Hamming distance from $\ell$ to $x\mapsto\langle\gamma,x\rangle$ and twice the relative Hamming distance from $q$ to the matrix character defined by $A$.

**Proof.** First use the identity expressing consistency error as the expectation of the disagreement indicator, and the identity expressing test rejection probability as the expectation of its rejection indicator. Write $\ell_0(x)=\langle\gamma,x\rangle$ and let $q_0$ be the matrix character defined by $A$. For each $x,y,z$, the ideal disagreement between $\ell_0(x)\ell_0(y)$ and $q_0(xy^{\mathsf T})$ is bounded by the observed test rejection indicator plus the indicators of the four possible query errors: replacing $\ell_0(x)$ or $\ell_0(y)$ by $\ell$, and replacing either of the two queried values of $q_0$ by $q$. This is the pointwise error decomposition (`rankOne_rejection_indicator_le_observed_add_query_errors`). The two ideal character queries, at a matrix $B$ and at $B+xy^{\mathsf T}$, sum to the character of $xy^{\mathsf T}$: additivity of the matrix character (`binaryMatrixCharacter_add`) and cancellation in characteristic two give this identity. Average the pointwise bound over $x,y,z$. The test indicator yields the rejection probability. Each error in an $\ell$ query averages to its relative Hamming distance, by the identification of mismatch probability with relative Hamming distance (`uniformProbability_ne_eq_relativeHammingDist`). Each error in a $q$ query does so as well: uniform unflattening preserves relative Hamming distance (`relativeHammingDist_unflattenBinaryMatrix`), and translating the uniformly sampled matrix by $xy^{\mathsf T}$ preserves the expected character mismatch (`expect_matrixCharacter_mismatch_add`). Thus each of the two types of query error contributes twice its respective distance, proving the bound.
