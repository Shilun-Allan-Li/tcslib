# One-Step Program Simulation

**Claim.** When the abstract state has label $\ell$, read position at most $|x|$, and all registers at most $B$, the compiled machine reaches the encoding of its one-step successor in at most $2B+3$ steps.

**Proof.** Write the state as label, register values, read position, and output. Its encoding places the input head at the position corresponding to the read position, represents each register $v$ by a unary tape with $v$ marked cells and its head at the right endpoint, and preserves the output. The encoded input symbol agrees with the next abstract input symbol (`enc_inputSymbol`). Now consider the instruction at $\ell$. Halt, jump, and single-bit output are implemented in one machine transition; the control action preserves the tapes and head positions, and makes exactly the abstract change to the label or output (`apply_ctl`). Increment is also one transition: it writes a mark at the register's endpoint and moves that head right, extending the unary representation by one (`apply_act`, `tapes_update`, `heads_update`, `update_ones_succ`). For decrement, the machine first moves left and then inspects the cell. If the register is zero, it sees no mark and leaves the unary tape and abstract value at zero; otherwise it erases the last mark, restoring the representation of the value one smaller (`ones_neg`, `ones_lt`, `update_ones_pred`, `tapes_update`, `heads_update`). This takes two transitions. A zero test likewise moves left, then branches according to whether it sees a mark; its second transition restores the head to the register's right endpoint, so the tape encoding is unchanged. For printing a register of value $v$, the first transition enters the leftward walk. The printing walk traverses its $v$ marked cells and emits $v$ true bits (`print_walk`); the return walk restores the register head and returns to the main control state (`back_walk`). Including the first transition, this takes $1+(v+1)+(v+1)=2v+3\le 2B+3$ transitions. Finally, for a read instruction, the encoded input symbol selects the end, false, or true branch consistently with the abstract step; the input head advances exactly when a bit is consumed. This takes one transition. Each case therefore reaches the exact encoded successor within the stated bound.
