# Randomized Simulation of a Nondeterministic Program

**Claim.** Under the uniform choice-sequence halting and guard hypotheses, there is a time $T$ at which every compiled run halts, and for each answer bit the probability of producing that bit after $out$ equals the register program's probability of returning it after $N$ choices.

**Proof.** Induct on $N$. When $N=0$, the assumed halting condition contradicts the live initial configuration. For the induction step, the guard holds initially by `NHalts.guard`. If the instruction is deterministic, `astep_cases` separates a live next configuration from a final answer. In the live case, `NHalts.of_det` supplies the induction hypothesis for the remaining choices, and `ndet_live` gives a fixed-length compiled prefix reaching the matching compiled configuration. Every run of the combined length therefore halts: split its choices after the prefix, use `runWith_append`, and apply the suffix halting conclusion. For each answer bit, `randProb_narun_det` removes the first abstract deterministic step from the probability, while `randProb_runWith_seg` removes the compiled prefix; the induction hypothesis equates the resulting probabilities. In the halting case, `ndet_halt` gives a fixed-length compiled simulation ending with the final answer. All runs of that length reach the same halted output, so `randProb_runWith_const` reduces the compiled probability to whether that output has the specified bit. On the register-program side, `randProb_narun_det` reduces to the halted abstract configuration, and `randProb_narun_const` (through the constant-event calculation) gives the same probability. If the instruction is a choice, apply `NHalts.of_choose` and the induction hypothesis to both branches. Set the common compiled time to one plus the larger of the two branch times. The first compiled choice step reaches the matching branch configuration (`ncompileTM_stepWith_choose`), and the branch halting conclusions, extended to the common time by `runWith_append_of_halt`, show that every run halts then. Finally, `randProb_narun_choose` expresses the abstract answer probability as the average of the two branch probabilities. The compiled first choice bit has the same equal-weight branch split by `randProb_runWith_choose`; `randProb_runWith_mono` adjusts each branch to the common time, and the two induction equalities identify the averages.
