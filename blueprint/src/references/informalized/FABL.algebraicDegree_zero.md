# Degree of the zero coefficient function

**Claim.** The coefficient function that assigns zero to every subset has algebraic degree zero.

**Proof.** The zero coefficient function has empty support, since no subset has a nonzero coefficient. The supremum of the cardinalities over this empty support is zero, so its algebraic degree is zero.
