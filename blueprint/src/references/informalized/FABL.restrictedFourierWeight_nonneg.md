# Nonnegative Restricted Fourier Weight

**Claim.** For every real-valued function on the sign cube, every coordinate set $J$, and every $S\subseteq J$, the restricted Fourier weight is nonnegative.

**Proof.** By definition, the restricted Fourier weight is a finite sum of squared real Fourier coefficients. Each square is nonnegative, so their sum is nonnegative.
