# Empty initial coordinate set

**Claim.** Among $n$ coordinates, the set of the first zero coordinates is empty.

**Proof.** Membership in the first-zero set would require a coordinate index to be less than zero, which is impossible. Thus the set has no elements and equals the empty set.
