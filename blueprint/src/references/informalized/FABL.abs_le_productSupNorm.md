# Pointwise product supremum norm bound

**Claim.** For a finite nonempty set $\Omega$, every function on $\Omega^n$ is pointwise bounded in absolute value by its supremum norm over $\Omega^n$.

**Proof.** The point $x$ is an element of the product space $\Omega^n$. The supremum of $|f(y)|$ over all points $y$ in that space is consequently at least the particular value $|f(x)|.
