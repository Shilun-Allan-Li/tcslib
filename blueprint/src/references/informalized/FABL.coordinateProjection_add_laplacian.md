# Projection and coordinate Laplacian sum

**Claim.** The coordinate projection of a function plus its coordinate Laplacian equals the original function.

**Proof.** By definition, the coordinate Laplacian is the original function minus its coordinate projection. Adding the projection back cancels the subtracted term, leaving the original function.
