# Sign Values Under Linear Reindexing

**Claim.** Composing a sign-valued function with an invertible linear map preserves absolute value one at every input.

**Proof.** Fix an input $x$. The reindexed function takes the value $f(Mx)$ there. The hypothesis on $f$ applies to every input, in particular to $Mx$, and gives $|f(Mx)|=1$.
