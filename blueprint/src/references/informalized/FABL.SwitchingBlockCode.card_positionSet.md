# Count of Fixed-Size Position Sets

**Claim.** For nonnegative integers $w$ and $i$, the number of $i$-element subsets of a set of $w$ positions is $\binom{w}{i}$.

**Proof.** The position sets are precisely the $i$-element subsets of the $w$-element set of positions. The standard counting formula for such subsets gives $\binom{w}{i}$.
