# Distributional Error as Sample Error

**Claim.** The protocol’s distributional error under the hard input distribution equals the probability, over hard samples, that the protocol errs on the input pair generated by the sample.

**Proof.** By definition, distributional error is the input law’s mass of the set of input pairs on which the protocol’s output disagrees with disjointness. The hard input law is the image of the uniform hard-sample law under the map sending a sample to its generated input pair. The measure of any set under an image law is the original measure of its preimage (\texttt{inputDist_measureReal_eq_preimage}). The preimage of the input error set is exactly the event that the protocol errs on the input pair generated by the sample, giving the equality.
