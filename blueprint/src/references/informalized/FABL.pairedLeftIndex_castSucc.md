# Compatibility of Left Indices Under Extension

**Claim.** For an index $j$ among the first $k$ pairs, its left index in the enlarged set agrees with the corresponding index embedded into the first $r+2k$ coordinates.

**Proof.** Both indices have the same value, namely $r+2j$: extending $j$ by the final-index embedding leaves its value unchanged, and embedding the coordinate into the first $r+2k$ positions also leaves that value unchanged. Equality of these finite indices follows from equality of their values.
