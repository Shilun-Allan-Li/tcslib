# Improvement constant as a power

**Claim.** For natural numbers $r$ and $k$, the improvement constant is the $1/(2r)$ real power of the factorial ratio.

**Proof.** Unfolding the definitions, both sides are the same real power of the same factorial quotient, so the equality holds directly.
