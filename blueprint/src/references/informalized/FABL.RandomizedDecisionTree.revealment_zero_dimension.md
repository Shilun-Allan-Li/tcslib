# Revealment in zero dimensions

**Claim.** For a randomized decision tree on zero coordinates, revealment under any input law is zero.

**Proof.** When $n=0$, there are no coordinates, so the coordinate set is empty. The empty-set branch of the definition of revealment assigns it the value $0$.
