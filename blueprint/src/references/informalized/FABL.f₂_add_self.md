# Self-addition in the binary field

**Claim.** For every $a\in\mathbb F_2$, $a+a=0$.

**Proof.** In the additive group, the sum of an element and its additive inverse is zero. In $\mathbb F_2$, negation fixes every element, so $a+a=0$.
