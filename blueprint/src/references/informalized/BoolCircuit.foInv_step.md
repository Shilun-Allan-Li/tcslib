# Preservation Under One Reduction Step

**Claim.** If a state satisfies the fanout reduction invariants for $old$, and appending $g$ preserves acyclicity while $g$ has distinct arguments, at most two arguments, and exactly one argument when it is a NOT gate, then one fanout reduction step with $g$ satisfies the invariants for $old$ followed by $g$.

**Proof.** Write the current state as a reduced list $gs$, a vertex map $tap$, and count $N$. The count invariant gives $N=n+|old|$. Set $base=n+|gs|$. The step appends a remapped copy $g'$ of $g$ and, for each argument $a$ of $g$, a one-input AND buffer reading $tap(a)$. The new map sends the newly computed vertex $n+|old|$ to $base$, sends each old argument $v$ of $g$ to the corresponding buffer position $base+1+\operatorname{idxOf}(v)$, and leaves other vertices at their former taps. Since $g$ is acyclic after the prefix, every argument $a$ of $g$ is below $n+|old|$; the old tap bound therefore puts each $tap(a)$ below $base$.

The new gates read only these earlier tap vertices, so the appended block respects acyclicity; the previous reduced list was already acyclic. The new list length is $|gs|+1+|g.args|$, and the updated count is $n+|old|+1$. These formulas also show that every new mapped vertex lies within the range of the resulting list. For injectivity, separate the cases in the definition of the new map: the new vertex maps to $base$, argument vertices map to distinct buffer positions because the old arguments are distinct and the old tap map is injective, and untouched vertices retain their distinct old taps. The ranges are disjoint, since old taps lie below $base$ while buffer positions lie above it.

For values, first note that adding $g$ to the end of the original list does not change any earlier computed value. The new vertex is computed by $g'$, and remapping preserves the evaluation of a gate when each remapped input has the same value as its original input (BoolCircuit.DAGGate.eval_remap). An argument vertex is represented by its buffer: the one-input AND gate copies the value at its tap (BoolCircuit.DAGGate.eval_singleton), and the buffer's value agrees with the old argument's value by the prior value invariant and the fact that earlier gates retain their values. Untouched vertices keep their previous taps and values.

For fanout, the old list contributes its previous fanout, while the appended block contributes two uses of each argument tap: one in $g'$ and one in that argument's buffer. Distinctness and injectivity ensure each buffer contributes exactly one occurrence to the relevant tap. Thus argument taps, whose old fanout is zero by the invariant, reach fanout two; all other vertices receive no new uses. Fanout counts add across concatenated lists (BoolCircuit.fanoutIn_append), and acyclicity ensures no old gate reads a vertex at or beyond the old list's computed range (BoolCircuit.fanoutIn_eq_zero_of_le). These facts establish the global fanout bound and show that every new mapped vertex has fanout zero.

The old gates retain their argument conditions. The remapped copy has distinct arguments by injectivity of the old tap map on the argument vertices; its argument count and NOT condition are inherited from $g$. Each buffer has one distinct argument, is not a NOT gate, and has at most two arguments. Finally, the new length is $|gs|+1+|g.args|$, which is at most $|gs|+3$ because $g$ has at most two arguments. Combining this with the prior bound $|gs|\le 3|old|$ gives the required bound $3(|old|+1)$.
