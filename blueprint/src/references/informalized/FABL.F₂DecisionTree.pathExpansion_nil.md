# Expansion of the Empty Path List

**Claim.** The path expansion of the empty list of real-output paths on $n$ coordinates is the zero function.

**Proof.** At any vector $x$, the expansion is the sum of the mapped terms from the empty list. That sum is zero, so the expansion agrees pointwise with the zero function.
