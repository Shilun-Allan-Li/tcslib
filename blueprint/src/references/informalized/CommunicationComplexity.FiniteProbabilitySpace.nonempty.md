# Nonemptiness of a finite probability space

**Claim.** Every finite probability space is nonempty.

**Proof.** The whole space has measure one, so in particular it has nonzero measure. A set of nonzero measure cannot be empty, since the empty set has measure zero. Hence the whole space is nonempty.
