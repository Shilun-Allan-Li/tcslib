# A Sign Above One

**Claim.** If an integer sign $s\in\{-1,1\}$ satisfies $1\le s$, then $s=1$.

**Proof.** A sign is either $1$ or $-1$. The value $-1$ does not satisfy $1\le -1$, so the hypothesis forces the other possibility, $s=1$.
