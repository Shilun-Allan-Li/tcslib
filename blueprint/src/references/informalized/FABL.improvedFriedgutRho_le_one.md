# Upper Bound for Rho

**Claim.** For every real number $\eta>0$, the quantity $\rho(\eta)=\eta/(2+\eta)$ satisfies $\rho(\eta)\le 1$.

**Proof.** Because $2+\eta>0$, the inequality $\eta/(2+\eta)\le 1$ is equivalent to $\eta\le 2+\eta$. The latter follows from $0<2$.
