# Nonnegativity of the Odd Fourier Maximum

**Claim.** For every n and every Boolean function f, the nonnegative odd Fourier maximum of f is nonnegative.

**Proof.** Zero is explicitly included among the values over which the nonnegative odd Fourier maximum is taken. A maximum of a finite set is at least each member of that set, and therefore is at least zero.
