# Second Coordinate of the Pair Triple

**Claim.** For any pair of signs $(a,b)$, the second coordinate of the triple $(a,b,-b)$ is $b$.

**Proof.** By the definition of the triple as the function with entries $(a,b,-b)$, evaluating at the second coordinate returns $b$.
