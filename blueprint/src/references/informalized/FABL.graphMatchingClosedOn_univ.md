# Closure of the Full Vertex Set

**Claim.** The full vertex set contains the matching partner of every vertex.

**Proof.** Every matching partner is itself a vertex of the graph, and every vertex belongs to the full vertex set. Hence the full vertex set contains the partner of each of its vertices.
