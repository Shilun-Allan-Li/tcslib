# Interleaved seed cardinality

**Claim.** The set of ordered quadruples whose four entries each lie in a three-element set has cardinality $81$.

**Proof.** An ordered quadruple from four copies of a three-element set has $3$ choices in each coordinate. Thus the product cardinality is $3\cdot3\cdot3\cdot3=81$.
