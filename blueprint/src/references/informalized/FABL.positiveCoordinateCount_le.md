# Positive Coordinate Count Bound

**Claim.** For any sign vector on $n$ coordinates, the number of coordinates equal to $1$ is at most $n$.

**Proof.** The set of coordinates where the vector equals $1$ is a subset of all $n$ coordinates, so its cardinality is at most that of the full coordinate set. The latter has cardinality $n$.
