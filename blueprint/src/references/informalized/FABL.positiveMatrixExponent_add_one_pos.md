# Positivity After Adding One

**Claim.** If $\omega$ is a positive rational number, then $\omega+1>0$.

**Proof.** Because $\omega$ belongs to the set of positive rationals, we have $0<\omega$. Also $0<1$. Adding these inequalities gives $0<\omega+1$.
