# Nonnegativity of the Fourier one-norm

**Claim.** For every real-valued function on the sign cube, its Fourier one-norm is nonnegative.

**Proof.** The Fourier one-norm is a finite sum of absolute values of real Fourier coefficients. Each summand is nonnegative, so their sum is nonnegative.
