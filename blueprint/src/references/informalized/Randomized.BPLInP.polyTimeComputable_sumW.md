# Polynomial-Time Encoded Summation

**Claim.** The function that sums the two encoded natural numbers in a bit string and returns the resulting encoding is polynomial-time computable.

**Proof.** The single-step operation first decodes the paired input, adds the two decoded values in binary, and pairs that sum with the remaining component. Each decoding map and the binary addition map is polynomial-time computable; pairing and composition therefore make this whole step polynomial-time computable (\texttt{polyTimeComputable\_pairFstD}, \texttt{polyTimeComputable\_pairSndD}, \texttt{polyTimeComputable\_add}, \texttt{PolyTimeComputable.pairEncode}, and \texttt{PolyTimeComputable.comp}). The initial input is formed by pairing the empty string with the given string, also a polynomial-time operation (\texttt{polyTimeComputable\_const}, \texttt{polyTimeComputable\_id}, and \texttt{PolyTimeComputable.pairEncode}).

Iterate the single-step operation for $|w|+1$ rounds. After $i$ rounds, the first component encodes the sum of the first $i$ decoded values obtained by repeatedly taking the second component, while the second component is the result of applying that decoder $i$ times (\texttt{iterate\_sumStep}). To invoke the polynomial-time iteration theorem (\texttt{polyTimeComputable\_iterate}), it remains to bound the length of every intermediate result for $i\le |w|+1$. Each summand is less than $2^{|w|}$: the value of a bit string of length $m$ is less than $2^m$ (\texttt{bitsVal\_lt\_two\_pow}), and repeated second-component decoding never increases the length (\texttt{length\_pairFstD\_le} and \texttt{length\_iterate\_pairSndD\_le}). Thus the sum is at most $(|w|+1)2^{|w|}$, which is less than $2^{2|w|+1}$. The binary representation of that sum has length at most $2|w|+1$ (\texttt{length\_bits\_le}); the remaining component has length at most $|w|$. The paired encoding consequently has polynomially bounded length, as required by the iteration theorem. Finally, projecting the first component yields the encoded sum, and polynomial-time computability is preserved by composition (\texttt{polyTimeComputable\_pairFstD} and \texttt{PolyTimeComputable.comp}).
