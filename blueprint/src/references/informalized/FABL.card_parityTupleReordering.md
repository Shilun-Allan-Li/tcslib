# Tuple Reorderings

**Claim.** For natural numbers $q$ and $k$, the set of $q$-tuples of permutations of a $k$-element set has cardinality $(k!)^q$.

**Proof.** There are $k!$ permutations of a $k$-element set. A $q$-tuple is a function from a $q$-element set into this permutation set, so the number of tuples is $(k!)^q$.
