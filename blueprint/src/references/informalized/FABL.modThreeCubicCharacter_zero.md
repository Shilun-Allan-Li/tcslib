# Character Value at Zero

**Claim.** For the additive character $\chi$ of $\mathbb Z/3\mathbb Z$, the value at zero is $\chi(0)=1$.

**Proof.** An additive character is a homomorphism from the additive group to the multiplicative group, so it sends the additive identity to the multiplicative identity. Hence $\chi(0)=1$.
