# Profile at zero

**Claim.** The closed Gaussian profile has value $0$ at $0$.

**Proof.** The closed Gaussian profile equals the Gaussian isoperimetric profile only for inputs strictly between $0$ and $1$; at all other inputs it is $0$. Since $0$ is not strictly between $0$ and $1$, its value there is $0$.
