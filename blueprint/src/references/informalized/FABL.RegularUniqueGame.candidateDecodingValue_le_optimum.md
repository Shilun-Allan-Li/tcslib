# Candidate Decoding Value Bound

**Claim.** For a regular unique game with nonempty label set, the expected edge agreement obtained by independently choosing labels from each vertex’s candidate set, using the default label for an empty set, is at most the optimum value of the associated constraint satisfaction instance.

**Proof.** By the candidate decoding assignment law identity (`pmfExpectation_candidateDecodingAssignmentLaw_value`), the candidate decoding value is the expected value of the associated constraint satisfaction instance under the random assignment generated by the candidate sets. For every assignment, its instance value is at most the optimum (`CSPInstance.value_le_optimum`). Applying monotonicity of expectation (`pmfExpectation_mono`) therefore bounds the expected instance value by the expectation of the constant optimum. The expectation of a constant equals that constant (`pmfExpectation_const`), giving the claimed bound.
