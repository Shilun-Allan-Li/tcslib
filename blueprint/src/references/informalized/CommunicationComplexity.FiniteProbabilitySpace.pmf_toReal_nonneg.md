# Nonnegative probability weights

**Claim.** For each point $\omega$ in a finite probability space, the associated probability mass, viewed as a real number, is nonnegative.

**Proof.** The mass at $\omega$ is an extended nonnegative real number. The real-valued conversion of any extended nonnegative real is nonnegative, so the claimed inequality follows directly.
