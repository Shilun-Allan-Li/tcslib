# Nonnegative second moment

**Claim.** For every real-valued function on the $n$-dimensional sign cube, the uniform expectation of its square is nonnegative.

**Proof.** For every point $x$, the square $f(x)^2$ is nonnegative. The uniform expectation is a finite weighted average with nonnegative weights, and therefore is nonnegative.
