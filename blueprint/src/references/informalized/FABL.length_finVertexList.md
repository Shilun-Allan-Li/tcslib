# Finite Vertex List Length

**Claim.** For every natural number $N$, the list of vertices indexed by $\mathrm{Fin}(N)$ has length $N$.

**Proof.** The finite vertex list is the list obtained by enumerating the values of the identity function on $\mathrm{Fin}(N)$. Such an enumeration has one entry for each of the $N$ indices, hence its length is $N$.
