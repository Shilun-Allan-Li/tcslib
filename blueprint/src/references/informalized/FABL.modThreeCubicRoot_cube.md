# Cubic Root Identity

**Claim.** For $\zeta=\exp(2\pi i/3)$, one has $\zeta^3=1$.

**Proof.** Cubing the exponential multiplies its exponent by $3$, so $\zeta^3=\exp(2\pi i)$. The complex exponential has period $2\pi i$, hence this value is $1$.
