# EXP to Two-Level Existential Polynomial Time

**Claim.** If every language in $\mathrm{EXP}$ has polynomial-size Boolean circuits, then every language in $\mathrm{EXP}$ belongs to $\Sigma_2^P$.

**Proof.** Fix $L\in\mathrm{EXP}$. Choose a machine $M$ and constants $c,c_0$ witnessing its exponential-time decision bound. The characterization of $\Sigma_2^P$ (\texttt{mem\_SigmaP\_two\_iff}) reduces the claim to an existential certificate followed by a universal test against a language in coNP; use the inner language associated to $M$ and the tableau verifier (\texttt{innerLang\_mem\_coNP}).

For an input $x$, let $W$ be the prescribed polynomial width large enough to cover the run of $M$ on $x$. The width bounds ensure both that the input fits in the encoding and that the machine halts within $2^W-1$ steps (\texttt{width\_ok}). The circuit description for the corresponding tableau instance has length within the existential certificate budget (\texttt{desc\_len\_le}).

For completeness, suppose $x\in L$. The final-configuration characterization of acceptance gives an accepting run by time $2^W-1$ (\texttt{mem\_iff\_final}). Use the circuit's encoded description as part of the existential witness, preceded by a sufficiently long string of true bits and a false marker. Removing that marker recovers the description (\texttt{dropMarker\_marker}). For any universally chosen test string, the verifier's parsed fields agree with the intended input, description, time, address, and index; the resulting atom evaluations are therefore the same (\texttt{evalAtom\_congr}). The length check identifies the verifier's atom list with the numerical predicates for the decoded tableau (\texttt{atoms\_vin}); the circuit family's answers on these bounded time and address indices agree with the actual machine run (\texttt{ansD\_family}). Since the run accepts, every required numerical check passes (\texttt{complete\_numeric}). The decoded time and address are in range because every encoded word of width $W$ represents a number below $2^W$ (\texttt{ctrVal\_lt}). Thus the proposed witness passes every universal check.

Conversely, suppose an existential witness passes every universal test. Fix any time and address in range and any tableau index up to the input length plus one. Choose the universal test encoding these values, using the canonical fixed-width words; those words decode to the chosen time and address (\texttt{ctrVal\_enumWord}). The length-check atom is valid for this test (\texttt{lenAll\_inst}), so the verifier's atom list again coincides with the numerical checks (\texttt{atoms\_vin}). Passing the test forces each such numerical check to hold. Since the choices were arbitrary, all checks hold, and the soundness theorem for the numerical verifier yields acceptance by time $2^W-1$ (\texttt{sound\_numeric}). The final-configuration characterization then gives $x\in L$ (\texttt{mem\_iff\_final}). This proves the required existential-universal characterization for every $x$, hence $L\in\Sigma_2^P$.
