# Value of a Threshold Sign

**Claim.** For every real number $t$, the real value of the threshold sign is $1$ when $t\ge 0$ and $-1$ otherwise.

**Proof.** Split into the cases $0\le t$ and $0\nleq t$. In the first case the threshold sign is $1$, whose real value is $1$; in the second it is $-1$, whose real value is $-1$. These are exactly the two branches of the claimed expression.
