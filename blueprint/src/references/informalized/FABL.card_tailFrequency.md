# Cardinality of a Shifted Set

**Claim.** Shifting every element of a finite coordinate set up by one preserves its cardinality.

**Proof.** The shift is given by an embedding, so it is injective. Mapping a finite set along an injective map preserves its cardinality; hence the shifted set has the same cardinality as the original set.
