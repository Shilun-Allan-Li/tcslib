# Support of the Empty Path

**Claim.** A path with no assigned coordinates has empty support.

**Proof.** A coordinate belongs to the support precisely when the path assigns a value there. The empty path assigns none at every coordinate, so no coordinate belongs to its support; therefore the support is empty.
