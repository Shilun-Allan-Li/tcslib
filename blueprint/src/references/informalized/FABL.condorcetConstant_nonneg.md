# Nonnegativity of the Condorcet Constant

**Claim.** For every real number $\epsilon$, the Condorcet constant $\sqrt{\max\{0,\log(2/\epsilon)/2\}}$ is nonnegative.

**Proof.** The real square root of any real number is nonnegative. Applying this fact to the expression defining the Condorcet constant proves the claim.
