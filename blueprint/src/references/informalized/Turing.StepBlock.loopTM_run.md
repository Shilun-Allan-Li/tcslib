# Bounded Simulation of Repeated Steps

**Claim.** Under the stated hypotheses, the counter-loop machine reaches a configuration representing the source machine after $t$ steps, with unchanged output and the asserted tape agreement. Its running time has the stated bound, improves to the bound for any earlier halt, and no earlier time is either terminal state.

**Proof.** Split according to whether the source machine has halted by time $t$.

1. Suppose it has halted. Choose its first halting time $u\le t$ (Turing.MultiTapeTM.exists_first_halt). This time is positive: if $u=0$, the source configuration at time zero would already be halted, contradicting the assumed live state of $c$. Put $r=u-1$. Every source configuration through time $r$ is live, by the first-halting property. The orbit representation result (Turing.StepBlock.loopOrbit_rep) identifies the simulated configuration after each such number of rounds, and the round bound and intermediate-exit exclusion (Turing.StepBlock.loopOrbit_round) apply to each round. At round $u$, the representation result identifies the source’s first halted configuration. The counter-loop escape theorem (Turing.counterLoopTM_run_escape) therefore gives the run ending at the escape state after those rounds, with no earlier terminal state. Its time is the sum of the round durations and the counter overhead. Summing the per-round bound gives at most $u\,50(L+1)$ for the rounds; the counter-overhead estimate (Turing.counterOverhead_le_of_le), using the numeral hypothesis, bounds the overhead. This yields the claimed total bound. If the source halts by any $t'\le t$, its first halting time $u$ is at most $t'$, so the same estimates give the stated sharper bound. The orbit representation gives the final representation and output; the specified tape update changes cells only in the indicated interval, hence agrees with the original tape outside it.

2. Suppose instead that the source is still live at time $t$. It remains live at every time at most $t$ (Turing.MultiTapeTM.runFrom_state_ne_none_of_le). Thus the orbit representation and round estimates apply for all $t$ rounds. The counter-loop completion theorem (Turing.counterLoopTM_run_done), using the binary numeral identity, runs those rounds and then underflows the counter, reaching the completed state. The time estimate for this run is supplied by Turing.counterLoop_time_le, which combines the round bounds with the counter overhead. The final orbit representation supplies the represented configuration and unchanged output. Here no $t'\le t$ is a halting time, so the conditional early-halt bound is vacuous. Again, the defined tape update is supported on the specified interval, and the completion theorem ensures that neither terminal state occurred before the final time.
