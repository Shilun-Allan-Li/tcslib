# Biased Coefficient of the Biased View

**Claim.** The biased Fourier coefficient of the biased view of $f$ at $S$ equals the biased Fourier coefficient of $f$ at $S$.

**Proof.** By definition, the biased view is the same function $f$ with the indicated $L^2$ interpretation. Substituting that definition into the coefficient leaves both sides identical.
