# Interior Gaussian Isoperimetric Value

**Claim.** For any α in the unit interval whose value lies strictly between 0 and 1, the Gaussian isoperimetric function equals the standard Gaussian density evaluated at the corresponding upper quantile.

**Proof.** Since α lies in the open interval (0,1), the defining conditional for the Gaussian isoperimetric function takes its interior branch. That branch is exactly the standard Gaussian density at the upper quantile associated with α, giving the claimed equality.
