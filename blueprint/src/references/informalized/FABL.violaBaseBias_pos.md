# Positivity of the Base Bias

**Claim.** For every $\varepsilon>0$ and natural number $d$, the base bias $(\varepsilon/9)^{2^{\max(d-1,0)}}$ is positive.

**Proof.** Since $\varepsilon>0$, the base $\varepsilon/9$ is positive. The exponent $2^{d-1}$ is positive for every natural number $d$. A positive real number raised to a positive real exponent is positive, so the base bias is positive.
