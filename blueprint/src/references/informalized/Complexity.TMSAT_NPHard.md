# TMSAT Is NP-Hard

**Claim.** For every machine-code scheme with a total decoder and the stated padding property, every language in NP has a polynomial-time many-one reduction to its associated TMSAT language.

**Proof.** 1. Let $L$ be in NP. Choose a polynomial-time verifier $V$ and constants $C_0,c_0$ such that membership in $L$ is equivalent to the existence of a certificate $u$ of length $C_0(|x|+1)^{c_0}$ for which $x\mathbin{++}u$ is accepted by $V$. The polynomial-time characterization of $\mathsf P$ supplies a deterministic machine deciding $V$ in time $A(n+1)^d$ for some constants ($\texttt{mem_P_iff}$).

2. Build a polynomial-time wrapper that checks whether an input has the required paired format, extracts its two components, concatenates them, and runs the verifier on that concatenation; malformed inputs receive a fixed rejecting output. The proof establishes its polynomial-time computability from machines for pair validity, pair concatenation, and the verifier, using the constant-output and conditional-composition results ($\texttt{computesFunInTime_pairValid}$, $\texttt{computesFunInTime_pairConcat}$, $\texttt{polyTimeComputable_const}$, $\texttt{polyTimeComputable_ite}$, and $\texttt{PolyTimeComputable.comp}$). Converting this wrapper to a one-work-tape binary machine preserves polynomial time ($\texttt{one_work_tape_binary}$), and that machine is represented by a code-machine description ($\texttt{exists_codeTM}$). Let $\alpha_0$ be its encoding. The decoder's encode law ensures that decoding $\alpha_0$ recovers this machine ($\texttt{MachineCode.decode_encode}$).

3. Define the reduction to output the TMSAT instance containing $\alpha_0$, the original input, the exact certificate-length bound in unary, and a unary time limit $T'(|x|)$. The time limit is chosen as a polynomial large enough for the wrapper to process the paired input and run the verifier, whose running time is polynomial in the combined input length. The deadline estimate verifies this polynomial bound ($\texttt{tmsat_deadline_bound}$); monotonicity of computation time permits using the larger deadline ($\texttt{ComputesInTime.mono}$). The paired-input length calculation accounts for the encoding overhead ($\texttt{universal_pair_length}$).

4. This output map is polynomial-time computable. The exact certificate length and time limit can each be written in unary in polynomial time ($\texttt{tmsat_certificate_unary}$ and $\texttt{poly_unary_computes}$); the fixed-code pairing and the remaining pair encodings are polynomial-time computable by the pairing and fixed-prefix results ($\texttt{PolyTimeComputable.pairEncode}$, $\texttt{computesFunInTime_pairEncodeFixed}$, and $\texttt{PolyTimeComputable.comp}$). Finally, the certificate-equivalence argument shows that $x\in L$ exactly when this output belongs to TMSAT ($\texttt{tmsat_reduction_correct}$). Thus every NP language reduces to TMSAT in polynomial time.
