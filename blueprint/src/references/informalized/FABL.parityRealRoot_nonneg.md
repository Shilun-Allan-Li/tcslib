# Nonnegativity of the real root

**Claim.** For natural numbers $n$ and $h$, the real number $n^{1/h}$ is nonnegative.

**Proof.** The base $n$, viewed as a real number, is nonnegative. A real power of a nonnegative base is nonnegative, so the defined real root is nonnegative.
