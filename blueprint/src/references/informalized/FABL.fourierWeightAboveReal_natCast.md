# Real and natural tail thresholds agree

**Claim.** For a natural-number threshold, the Fourier weight tail defined using real cardinalities equals the tail defined using natural cardinalities.

**Proof.** Unfold both tail sums. For each subset, its natural cardinality exceeds the natural threshold exactly when its cardinality, viewed as a real number, exceeds that same threshold viewed as a real number. The two filtered sums consequently have identical index sets and identical summands.
