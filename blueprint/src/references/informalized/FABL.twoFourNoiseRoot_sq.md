# Square of the noise root

**Claim.** If $r=\sqrt{1/3}$, then $r^2=1/3$.

**Proof.** The radicand $1/3$ is nonnegative. For a nonnegative real number, squaring its real square root recovers the original number; hence $r^2=1/3$.
