# Size of the first two-thirds set

**Claim.** For every positive natural number $m$, the set of the first $2m$ indices among $3m$ indices has cardinality $2m$.

**Proof.** The set is the initial interval of indices strictly below $2m$. An initial interval in the natural-number order with endpoint $2m$ contains exactly $2m$ elements, namely the indices from $0$ through $2m-1$.
