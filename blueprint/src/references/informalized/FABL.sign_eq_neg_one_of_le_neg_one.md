# Sign Bounded Above by Negative One

**Claim.** If a sign $s\in\{-1,1\}$ satisfies $s\le -1$, then $s=-1$.

**Proof.** A sign is either $1$ or $-1$. The value $1$ cannot satisfy $1\le -1$, so the assumed inequality rules it out. Hence $s=-1$.
