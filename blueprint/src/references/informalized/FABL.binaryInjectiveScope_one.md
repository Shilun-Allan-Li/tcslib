# Value of the binary injection at one

**Claim.** For distinct $u,v\in V$, the injection from the two-element set that assigns $u$ to the first element and $v$ to the second takes the value $v$ at the second element.

**Proof.** By its definition, the injection evaluates at an element of the two-element set by choosing $u$ at the first element and $v$ at the second. Evaluating at the second element therefore gives $v$.
