# Indicator on Matching Vectors

**Claim.** If a binary vector matches a path, the indicator of that path’s cylinder at the vector is one.

**Proof.** A matching vector belongs to the path’s cylinder by definition. The indicator of a set takes the value one at every point in the set, so the path indicator at this vector is one.
