# Third Index Distinctness

**Claim.** For each seed $s\in\{0,1,2\}$, the third index differs from the first index $s$: it is $2$ if $s=0$, $0$ if $s=1$, and $1$ if $s=2$.

**Proof.** Check the three seeds in turn. The corresponding third indices are $2,0,1$, respectively, and none equals its seed.
