# `A0 n d w`: the largest admissible code

**Definition.** `A0 n d w : ℕ` is the maximum cardinality of an admissible code
in `{0,1}^n`: it ranges over all `C : Finset (BitVec n)` in
`(Finset.univ).powerset` that satisfy `AdmissibleCode n d w C` (pairwise Hamming
distance at least `d`, all weights at most `w`) and takes the `Finset.sup` of
`Finset.card` over them.

Notes on the Lean form:

- The filter needs a `DecidablePred (AdmissibleCode n d w)` instance, which is
  supplied non-constructively by a local `let _ := Classical.decPred _`; hence
  the `noncomputable def`.
- Quantifying over `Finset.univ.powerset` rather than "all finsets" keeps the
  index a `Finset`, so `Finset.sup` applies and the maximum is attained.
- `Finset.sup` of an empty family is `0`, so `A0 n d w = 0` when no admissible
  code exists — the definition never diverges.
- It lives in the root namespace (outside `CodingTheory.Johnson`) with
  `open CodingTheory.Johnson` in scope.

**Used in.** `A0_le_of_forall_le` (any uniform bound on admissible codes lifts
to `A0`, via `Finset.sup_le`) and hence `binary_johnson_bound_radius`, the
radius form of the binary Johnson bound `A0 n d w ≤ 2 * n`.
