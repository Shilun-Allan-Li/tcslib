# Size of the Odd Weight Variable Set

**Claim.** For every natural number $m$, the disjoint union of a set with $m+2$ elements and a set with $m+1$ elements has cardinality $2(m+2)-1$.

**Proof.** The cardinality of a disjoint union is the sum of the cardinalities of its two parts, so the total is $(m+2)+(m+1)=2(m+2)-1$.
