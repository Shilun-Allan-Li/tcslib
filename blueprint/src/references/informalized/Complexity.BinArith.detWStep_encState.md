# Encoded Determinant-State Step

**Claim.** For every natural number $p$ and determinant state $s$, applying the encoded determinant step to the encoding of $s$ at modulus $p$ gives the encoding of the state obtained by applying the determinant-state step at modulus $p$.

**Proof.** Write the state as $(R,d,m,rc)$ and split into the cases in the definition of the state transition. If $p<2$, both transitions leave the state unchanged. If $R$ is empty, the encoded row list is empty as well, and the empty-row branch agrees. Otherwise write $R=r_0::rs$; the encoded matrix is then nonempty (`encMat_eq_nil_iff`). If $m\le rc$, both transitions take the terminal branch, whose encoded state agrees. In the remaining cases, consider the pivot entry, the first entry of $r_0$. If it is zero, the two transitions rotate the rows, update the determinant factor according to the parity of $m$, and increment $rc$. The row encoding concatenation law (`encWords_append_singleton`) and the definitions of modular arithmetic and binary encoding show that these fields agree. If the pivot is nonzero, both transitions eliminate it from the remaining rows, update the determinant factor, decrease $m$, and reset $rc$. The encoded input exposes the pivot and remaining rows through the pair projections (`pairFstD_encMat_cons`, `pairSndD_encMat_cons`, `pairFstD_encRow`, and `pairSndD_encRow`). The encoded modular power computes the same inverse-power exponent (`powMod_pairEncode`), and the encoded row transformation agrees with pivot elimination (`rowW_eq`). Mapping this transformation over the decoded rows is justified by the mapping behavior of the encoded iteration (`mapW_pairEncode`) and the fact that decoding the matrix encoding recovers its rows (`decWords_encMat`). The determinant-factor update and the counter update agree by their definitions. Thus the encoded transition matches the ordinary state transition in every case.
