# Counter Programs Preserve Unary Logspace

**Proof.** Let the two oracle languages be the length-index and bit-index languages of $u$; both are in logarithmic space by hypothesis. Fix either output question: whether position $p$ is a $1$ in $g(n)$, or whether $p<|g(n)|$. The proof uses the alternating machine supplied by the counter-program simulation. These bounds follow from the run estimates for registers, position, and output (`Complexity.CounterProg.run_regs_le`, `Complexity.CounterProg.run_pos_le`, and `Complexity.CounterProg.run_init_out_le`). The chosen simulation bound $B=(N+1)^2$, where $N=C(n+1)^c$, therefore bounds all configurations along the run. The simulation theorem (`Complexity.CPSim.sim_run`) says the alternating machine follows this bounded run and returns the selected bit or length answer; the initial simulation configuration is established using the valid-query initialization fact (`Complexity.CPSim.preS_A`). Its resource bound is polynomial in the query length: the unary parameter $n$ is at most the encoded query length, and the quadratic bound in $N$ is bounded by a constant times a fixed power of that length. Invalid encodings are rejected immediately. The proof packages the two cases into one Boolean choice and then recovers the two conjuncts of unary logspace.
