# Real value of a sign

**Claim.** For every sign $s\in\{\pm1\}$, its real value is $1$ if $s=1$ and $-1$ otherwise.

**Proof.** Every sign is either $1$ or $-1$. If $s=1$, its real value is $1$; if $s=-1$, its real value is $-1$. These two cases give exactly the stated conditional formula.
