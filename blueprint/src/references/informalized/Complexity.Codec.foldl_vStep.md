# Summary of cell updates

**Claim.** After processing the first $J$ cells, the validation state records whether the list is empty, the head data from its first cell when present, which tapes were visited and the symbol at each tape's last visited cell, whether head data occurs exactly at index zero and each tape is marked at most once, and whether every processed cell satisfies the blank-together condition.

**Proof.** Proceed by induction on $J$. At $J=0$, the fold returns the initial state: its first flag is true, its head data is absent, no tape is visited, all stored symbols are absent, and both validity flags are true. These values agree with the stated empty-list conditions. For the step from $J$ to $J+1$, append the cell $f(J)$ and apply the update to the state for the first $J$ cells. The update clears the first flag, and retains the old head data unless the old first flag says this is the first cell, in which case it stores the new cell's head data. Thus the head-data formula holds whether $J=0$ or $J>0$. For each tape, the visited flag is the disjunction of its prior value and its mark at $J$, exactly expressing existence of a mark among the first $J+1$ cells. Its stored symbol is replaced by the current cell's symbol when the tape is marked there, and otherwise retained; hence it is absent if there were no marks, and equals the symbol at any marked index later than all other marked indices. The first validity flag is the conjunction of its previous value, the condition that head data has the required presence or absence at the newly processed index, and the condition that no tape marked at an earlier index is marked again now. Splitting indices below $J+1$ into those below $J$ and the new endpoint proves equivalence with the stated global conditions: a repeated mark involving the new endpoint is exactly a prior mark together with a mark at $J$. The second validity flag conjoins its previous value with the blank-together condition for $f(J)$, so it holds exactly when that condition holds at every processed index.
