# Sign Indicator Identity

**Claim.** For every sign $b\in\{-1,1\}$, the value that is $1$ when $b=1$ and $-1$ otherwise equals $b$.

**Proof.** A sign is either $1$ or $-1$. In the first case the conditional value is $1$, and in the second it is $-1$; in each case it equals $b$.
