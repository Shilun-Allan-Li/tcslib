# Critical Size Error Identity

**Claim.** For every natural number $w$, the critical size, viewed as a real number, equals $(\log 2)2^w$ minus the critical size error at $w$.

**Proof.** By definition, the critical size error is $(\log 2)2^w$ minus the critical size. Substituting this expression into the right-hand side and cancelling the two occurrences of $(\log 2)2^w$ leaves the critical size, as claimed.
