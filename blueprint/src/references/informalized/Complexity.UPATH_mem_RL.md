# Undirected Reachability in Randomized Log Space

**Claim.** The language of encodings of finite undirected graphs with a designated source and target joined by a path is decidable by a randomized finite Turing machine using logarithmic space. It halts after a fixed number of random bits on each input, accepts yes-instances with probability at least $2/3$, and rejects no-instances on every random string.

**Proof.** Fix an input string $x$. The proof uses the symmetric graph walk encoded by `upGraph` to turn reachability into a randomized path-finding procedure. If $x$ has the required graph shape and symmetric adjacency relation, `ups_start` identifies the walk's probability as its hit probability, using $200(|x|+1)^4$ random bits; if no such shape exists, the probability is zero. Shape uniqueness (`ushape_unique`) ensures that any valid graph parameters extracted from membership in `UPATH` agree with those used to define the walk. For a yes-instance, `mem_UPATH_iff` gives a path from source to target. Padding the graph preserves reachability (`padGraph_reflTransGen_iff`), and `symmetric_inEdge` supplies the symmetry needed for the walk estimate. Since `padDegree_le` bounds the padded graph's degree by twice its number of vertices, `three_quarters_le_hitProb` yields success probability at least $3/4$, hence at least $2/3$. For a no-instance, `mem_UPATH_iff` shows that the target is not reachable; `hitProb_eq_zero_of_not_reachable` therefore makes acceptance probability zero, so rejection is certain. The walk's probabilistic specification is converted into a halting computation by `PSem.decides`; `NHalts.mono` strengthens its halting configurations to include the required logarithmic-space bound, supplied by `upA_npreS`. Finally, `narm_mem_RL`, using the logarithmic-space checks for the two path predicates (`pathAs_mem`), places the language in randomized log space.
