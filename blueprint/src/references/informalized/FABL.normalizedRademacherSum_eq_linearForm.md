# Normalized Sum as a Linear Form

**Proof.** By definition, the normalized Rademacher sum is the linear form whose constant coefficient is $(\sqrt n)^{-1}$. The normalized coefficient is defined by exactly the same expression, so replacing the coefficient by its name leaves the function unchanged.
