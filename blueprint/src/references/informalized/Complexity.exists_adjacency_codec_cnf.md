# Configuration and Adjacency CNF Encodings

**Claim.** For a deterministic binary Turing machine, there is a constant encoding scale and, for every input length and space window, a configuration code together with CNF formulas recognizing valid configurations, one-step adjacency, and accepting configurations, with the stated separation, variable-count, and serialized-size bounds.

**Proof.** Fix the machine and let $B$ be the sum of the coefficients needed for validity, adjacency, and acceptance formula sizes, together with the fixed overhead displayed in the proof. The absorption bound (`codec_absorb`) supplies a positive constant $C$, large enough to dominate the configuration-code coefficient, such that for every $u\ge 2$, $B C^2u^{M.k+3}\le C u^C$. Use the configuration codec and the three formulas constructed for this $C,n,s$. The codec length theorem (`configurationCodec_length`) gives length $C(s+n+1)$. The cross-input separation and same-input equality characterization follow respectively from `configurationCodec_input_eq` and `configurationCodec_eq_iff`: the latter identifies equal codes precisely with equality of the state, input-head position, tapes, and tape-head positions together with the output summary. The validity formula recognizes exactly the codes of length-$n$ inputs and configurations in the window, by `configurationValidity_eval`. For a fixed input, the adjacency formula recognizes exactly when the machine step from the first configuration has the same core and output summary as the second, by `configurationAdjacency_eval`; on distinct inputs it rejects every pair, by `configurationAdjacency_reject`. The acceptance formula recognizes exactly halting configurations whose output summary is accepting, by `configurationAcceptance_eval`. The variable bounds come from `configurationValidity_numVars`, the first component of `configurationAcceptance_bounds`, and the first component of `configurationAdjacency_bounds`. Finally, set $u=s+n+2$. Since $u\ge2$ and $3\le M.k+3$, we have $u^3\le u^{M.k+3}$. Each serialized-size estimate is therefore bounded by its coefficient times $C^2u^e$, with coefficient at most $B$ and exponent $e\le M.k+3$; the absorption inequality gives the required bound $C(s+n+2)^C$.
