# Uniform Distribution Probability

**Claim.** On a finite nonempty set $\alpha$, the uniform distribution assigns probability $1/|\alpha|$ to each $a\in\alpha$.

**Proof.** By definition, the uniform distribution assigns the same value, the reciprocal of the cardinality of $\alpha$, to every outcome. Evaluating at any $a$ gives the claim.
