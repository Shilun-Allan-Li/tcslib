# Cardinality of a Lifted Subset

**Claim.** Lifting a finite subset $T$ of $J$ into the full coordinate set preserves its cardinality.

**Proof.** The lifted set is the image of $T$ under the inclusion map from the subtype of elements of $J$ into the full coordinate set. This map is injective, so mapping the finite set along it preserves the number of elements.
