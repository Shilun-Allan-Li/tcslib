# Complement of a unit interval parameter

**Claim.** If $0\leq\delta\leq1$, then $1-\delta\in[0,1]$.

**Proof.** The inequalities $\delta\le1$ and $\delta\ge0$ give, respectively, $0\le1-\delta$ and $1-\delta\le1$. Together these say that $1-\delta$ belongs to $[0,1]$.
