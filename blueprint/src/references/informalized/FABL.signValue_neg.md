# Negation of a Sign Value

**Claim.** For every sign $s$, the real value of its negation is the negative of its real value.

**Proof.** A sign is either $1$ or $-1$. If $s=1$, its negation is $-1$, whose real value is $-1$; if $s=-1$, its negation is $1$, whose real value is $1$. In each case this is the negative of the real value of $s$.
