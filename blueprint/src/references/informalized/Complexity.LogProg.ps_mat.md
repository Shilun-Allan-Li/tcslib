# Matrix-suffix scan

**Claim.** Starting at the matrix-processing stage, the program terminates within the register bound and accepts exactly when the remaining matrix entries have equal aligned bits, the separator is $01$, and $K$ holds.

**Proof.** Proceed by strong induction on the number $n^2-i$ of entries remaining. At the current pointer, the program first checks that it is within the input and reads the two bits of the current entry. If the pointer is out of range, or those bits differ, it rejects; these outcomes contradict the asserted suffix condition. When the bits agree, it advances to the second bit and checks whether the row counter is already $n$. The quotient characterization of the terminal index (`div_eq_self_iff`) says this happens exactly when $i=n^2$. In that case, the current pair is the separator: the equality check forces its first bit to be $0$, and the next check forces its second bit to be $1$. The program then transfers to the supplied continuation, which accepts exactly when $K$ holds; the remaining-suffix condition is precisely the separator condition at this endpoint. Otherwise $i<n^2$, so $n>0$ and the current entry is a genuine matrix entry. The program increments the pointer twice and updates the row and column counters to the quotient and remainder of $i+1$ by $n$. The quotient-remainder successor rule (`divmod_succ`) gives these values: if the current column was $n-1$, it rolls over to the next row and column zero; otherwise the row stays fixed and the column increases by one. Apply the induction hypothesis to this next index. Its suffix assertion is equivalent to the original one together with equality of the current pair, since the original suffix begins at $i$ and the recursive suffix begins at $i+1$. The register-bound conditions follow from the given bound and the index constraints at each step.
