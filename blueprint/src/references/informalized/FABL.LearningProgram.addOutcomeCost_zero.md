# Zero Added Outcome Cost

**Claim.** Adding zero to the cost in any outcome-cost pair leaves the pair unchanged.

**Proof.** Write the pair as an outcome together with a cost $c$. Adding zero preserves the outcome, and the new cost is $0+c=c$, since each of the three natural-number components of the zero cost is zero. Therefore the pair is unchanged.
