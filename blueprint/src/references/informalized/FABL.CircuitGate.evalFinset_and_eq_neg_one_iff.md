# AND Evaluation Criterion

**Claim.** The AND gate applied to a selected set of signs equals $-1$ exactly when every selected sign equals $-1$.

**Proof.** By definition, the AND evaluation is $-1$ precisely when the condition that every selected index has value $-1$ holds; otherwise its value is $1$. Thus the two conditions are equivalent.
