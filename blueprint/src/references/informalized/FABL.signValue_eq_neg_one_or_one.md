# Possible values of a sign

**Claim.** For every sign $s\in\{\pm1\}$, its real value is either $-1$ or $1$.

**Proof.** A sign is either $1$ or $-1$. Evaluating each of these possibilities as a real number shows that its real value is correspondingly $1$ or $-1$, proving the disjunction.
