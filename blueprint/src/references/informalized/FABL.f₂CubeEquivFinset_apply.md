# Support of a binary vector

**Claim.** The finite set corresponding to a binary vector $\gamma$ is exactly the set of indices $i$ for which $\gamma_i\ne0$.

**Proof.** The equivalence sends $\gamma$ to its support by definition. That support is the set of indices whose coordinates are nonzero, as claimed.
