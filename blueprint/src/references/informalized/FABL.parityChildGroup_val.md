# Parity child group index formula

**Claim.** The child group index assigned to $g<r^q$ and $j<r$ has value $gr+j$.

**Proof.** The indexing equivalence first identifies the product of the two finite index sets with the finite set whose size is the product of their sizes, using the standard product indexing in which the first coordinate is the quotient and the second is the remainder. Rewriting that product size as $r^{q+1}=r^q r$ gives the value $g r+j$.
