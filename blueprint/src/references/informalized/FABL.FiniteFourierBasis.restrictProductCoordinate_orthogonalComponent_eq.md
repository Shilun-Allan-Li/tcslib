# Restriction preserves the lower-support component

**Claim.** Fixing coordinate $i\in S$ of the component supported on $S$ produces a function unchanged by projection onto the component supported on $S\setminus\{i\}$.

**Proof.** Let $g$ be the restriction of the component supported on $S$ obtained by fixing coordinate $i$ at $\omega$. The component depends only on $S$, so this restriction depends only on $S\setminus\{i\}$ (orthogonalComponent_dependsOnly and restrictProductCoordinate_dependsOnly). We prove equality by comparing Fourier coefficients, using injectivity of the Fourier coefficient map (fourierCoeff_injective). The component indexed by $S\setminus\{i\}$ retains exactly the coefficients with that support (fourierCoeff_orthogonalComponent). For a multi-index with that exact support, the two coefficients agree. For any other index whose support is not contained in $S\setminus\{i\}$, the coefficient of $g$ vanishes because $g$ depends only on those coordinates (fourierCoeff_eq_zero_of_dependsOnly). In the remaining case the support is a strict subset of $S\setminus\{i\}$, so choose a coordinate $j$ in the latter set but outside the support. The index at $j$ is the constant index. Projection onto coordinate $j$ annihilates the restricted function: restricting at the distinct coordinate $i$ commutes with that projection, and projection onto a coordinate in $S$ annihilates the component supported on $S$ (coordinateProjection_restrictProductCoordinate and coordinateProjection_orthogonalComponent_eq_zero). The Fourier coefficient formula for coordinate projection says that, since the index at $j$ is constant, this projected coefficient equals the coefficient of $g$ itself (fourierCoeff_coordinateProjection). Hence that coefficient is zero as well. Thus the coefficients agree in every case, proving the claimed equality.
