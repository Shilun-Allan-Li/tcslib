# Nonemptiness of a Binary Affine Subspace

**Claim.** For a linear subspace $H$ and vector $a$, the affine translate $a+H$ is nonempty.

**Proof.** The vector $a$ belongs to the translate: subtracting $a$ from $a$ gives zero, which lies in every linear subspace. Thus $a$ itself witnesses nonemptiness.
