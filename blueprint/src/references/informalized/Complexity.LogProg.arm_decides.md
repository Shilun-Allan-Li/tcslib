# Logspace Decidability by an Oracle Register Program

**Claim.** If a register program with oracle calls halts with the correct answer on every input, obeys its side conditions before halting, and keeps each register's binary length within a constant multiple of input logspace, then its language is decidable in logarithmic space when each oracle language is itself decidable in logarithmic space.

**Proof.** For each of the finitely many oracle languages, choose a logarithmic-space decider and a constant bounding its space use. Sum these constants to obtain a uniform bound for the finite collection. Compile the register program together with a bank of these oracle deciders; the compiled machine simulates the register computation and uses the bank to answer each oracle call. Fix an input $x$, put $n=|x|$ and $L=\lfloor\log_2 n\rfloor+1$, and use the assumed halting run and correctness to obtain its finite stopping time and answer. At every earlier configuration, the side conditions hold and each register has binary length at most $K L$. Monotonicity of binary length ($\texttt{length_bits_mono}$) also bounds the length of each register's actual binary word by this same quantity. For a call, the virtual input is assembled from the input segment and the encoded register arguments. The call-length estimate bounds its length by $2n+2+m(2KL+2)$ ($\texttt{length_callSegs_le}$); the side condition supplies the distinctness of arguments needed for that estimate. Since $L\le n+1$, this is bounded by a fixed linear polynomial in $n+1$. The logarithm of that polynomial is at most a constant multiple of $L$ ($\texttt{log_poly_bound}$). The chosen decider for the call therefore uses at most its constant times this logarithmic bound; the sum of all oracle constants bounds the relevant decider constant ($\texttt{Finset.single_le_sum}$). The bank runs cleanly within its advertised space bound ($\texttt{bank_cleanRun}$), and that bound can be enlarged monotonically when needed ($\texttt{cleanRun_mono}$). Applying the compiled-machine space simulation theorem ($\texttt{arm_space}$) to the bounded, side-condition-respecting register run shows that the compiled machine halts with the correct answer and uses logarithmic space. Finally, the fixed additive terms in the space estimate are absorbed using $L\ge1$, yielding a single constant times $L$ as required.
