# Unit Vector at Its Own Coordinate

**Claim.** The unit vector supported at coordinate $i$ has value $1$ at coordinate $i$.

**Proof.** By definition, the unit vector's value at a coordinate is $1$ when that coordinate equals $i$ and $0$ otherwise. At $i$ the equality holds, so the value is $1$.
