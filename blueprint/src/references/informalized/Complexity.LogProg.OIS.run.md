# Bounded-Counter Simulation

**Claim.** Under the stated oracle conditions, if the machine halts on $v$ after $t$ steps, then the compiled oracle program halts with the same output and has the asserted head bounds and call configuration properties through its halting time.

**Proof.** Choose the first time $u\le t$ at which the original machine halts. The first-halt result (`Turing.MultiTapeTM.exists_first_halt`) also gives that its configuration at $u$ is the same as at $t$. We prove by induction on $n\le u$ that the compiled run reaches, at some time $N$, a configuration representing the original machine's configuration after $n$ steps, and that every earlier compiled configuration is safe. At $n=0$, the initial compiled configuration represents the original initial configuration with counter zero; the zero-run identity (`Complexity.LogProg.rrun_zero`) identifies the run at time zero, and there are no earlier times to check. For the successor step, apply the induction hypothesis and then the one-step simulation result (`Complexity.LogProg.OIS.represented_step`): its oracle hypotheses are exactly the assumptions on the two oracle answers, and the original head bounds required there follow from `Complexity.LogProg.OIS.source_head_bounds` at steps $n$ and $n+1$. This yields a further compiled run segment reaching a representation of the next original configuration, with every configuration in that segment safe. Concatenating the runs using `Complexity.LogProg.rrun_add` gives the induction claim. At $n=u$, representation and the safety lemma (`Complexity.LogProg.OIS.represents_safe`) show that the final compiled configuration is safe as well. Its state is halting because the original configuration at $u$ equals the halting configuration at $t$; the same equality gives equality of outputs. Every time up to the final time is either earlier, when safety follows from the induction claim, or the final time, when it follows from the safety lemma. Finally, any call before the final time is among the earlier configurations, so the call properties follow from their safety.
