# Binary support membership

**Claim.** A coordinate belongs to the support of a function from the binary cube to the two-element field exactly when the function's value at that coordinate is nonzero.

**Proof.** The support is defined as the set of coordinates where the function is nonzero. Hence membership is equivalent to the value at that coordinate being nonzero.
