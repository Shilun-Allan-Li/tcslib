<a id="pdf-b9fb35a232af-p002-b001"></a>

The paper defines classes via time and tape bounds on accepting computations, proves representation results involving homomorphic images of the quasirealtime, context-sensitive, and deterministic linear-bounded-automaton language families, and derives a two-storage-tape result for time-bounded nondeterministic acceptors. For the families considered, the unscaled class is an AFL exactly when the resource bound is superadditive, and its scaled union equals the original class exactly when the bound is semihomogeneous: for every positive integer k₁ there is k₂>0 such that f(k₁x)≤k₂f(x) for all x>0. It also gives conditions for time-bounded classes to be principal AFLs and corresponding results for tape bounds.

**Definition 1.1.** An \(n\)-tape Turing machine is an \((n+6)\)-tuple \(M=(K,\Sigma,\Gamma_1,\ldots,\Gamma_n,\delta,q_0,F,n)\), where \(K,\Sigma,\Gamma_1,\ldots,\Gamma_n\) are finite sets, \(q_0\in K\), \(F\subseteq K\), \(n\) is a nonnegative integer, and \(e\) is a special symbol not in \(\Gamma_i\) for \(1\le i\le n\). The transition function \(\delta\) maps \(K\times(\Sigma\cup\{e\})\times[(\Gamma_1\cup\{e\})\times\cdots\times(\Gamma_n\cup\{e\})]\) into the finite subsets of \(K\times[(\Gamma_1\times\{1,0,-1\})\cup\Gamma_1^*\cup\{E\}]\times\cdots\times[(\Gamma_n\times\{1,0,-1\})\cup\Gamma_n^*\cup\{E\}]\). The machine is deterministic if, for all \(q\in K\) and \(A_i\in\Gamma_i\cup\{e\}\), (i) \(\delta(q,e,A_1,\ldots,A_n)\ne\varnothing\) implies \(\delta(q,a,A_1,\ldots,A_n)=\varnothing\) for all \(a\in\Sigma\), and (ii) for all \(a\in\Sigma\cup\{e\}\), \(\#\delta(q,a,A_1,\ldots,A_n)\le1\).

**Lemma 2.1.** For any function \(f\) and any family \(\mathcal L\) of languages, \(\mathcal S H_f[\mathcal L]\subseteq\mathcal F(H_f[\mathcal L])\).

<a id="pdf-b9fb35a232af-p009-b008"></a>

**Proof.** If \(L_1\in\mathcal S H_f[\mathcal L]\), then for some \(k>0\), \(L_1\in H_{f_k}[\mathcal L]\). Thus there is a homomorphism \(h_1:\Sigma^*\to\Delta^*\) and a language \(L_2\in\mathcal L\) such that \(h_1(L_2)=L_1\) and \(h_1\) is \(f_k\)-bounded on \(L_2\).

<a id="pdf-b9fb35a232af-p010-b001"></a>
<!-- pdf-source: page=10; block=1; confidence=0.95 -->

Then for any \(w\in\Sigma^*\), \(|h_3(w)|=k|h_1(w)|\); hence, for any \(w\in L_2\), \(|w|\le tf(k|h_1(w)|)=tf(|h_3(w)|)\). Let \(f\) be a superadditive deterministic running time and let \(g\) be the function defined for all \(x\) by \(g(x)=2^{f(x)}\). Thus Theorem 2.19 shows that the family of languages accepted by nondeterministic auxiliary pushdown acceptors operating within tape bound \(f\) forms a principal AFL. By Ref. [21], this shows that the family of languages accepted by nondeterministic (deterministic) stack automata is a principal AFL.
